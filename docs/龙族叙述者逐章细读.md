# 龙族叙述者逐章细读

本文记录对现有《龙族》原文的逐章阅读，重点是叙述者的态度、与读者的关系、连续行文和语言选择。分析不把人物发言直接认作叙述者或现实作者的观点。

状态：现有素材 91 / 91 个章节单元已完整逐段阅读并记录。完整素材为六个分部、91 个章节单元、26,443 个自然段、1,802,155 个正文字符。范围为《火之晨曦》《悼亡者之瞳》《冰海王座》及《黑月之潮》上中下，不包含此范围之外的续作。段号依当前本地原文快照，非出版物页码；正文不改写，来源重复等疑点单独说明。

跨全书的研究认识见[叙述者声音分析](龙族叙述者声音分析.md)，独立创作片段见[原创示例](叙述者声音原创示例.md)。本文保留逐章研究与稳定定位，不作为创作 Skill 的运行依赖；包内讲述方法及原文细读由独立文件承载。下文按章节展开，描述读到某处时的认识变化；涉及后文修正的结论按全书已知事实辨认。


## 第一部《火之晨曦》

<a id="chapter-00"></a>

### 第一幕：卡塞尔之门

阅读范围：第 1—740 段，章节 ID `2424ad26-5d6d-415d-b0c1-e223f5b4dc1c`。

叙述者在这一章里先作出一个情感承诺：眼前这个没用、胆小、有小聪明也有小恶意的男孩，值得有一扇门为他打开。随后的揭短并不撤销这份承诺。旁白允许读者看见他的懒、虚荣、报复心和身体欲望，也比周围人更早看见他对陪伴的需要。第 13—29 段游戏和天台里的等待，第 81—94 段渴望被直升机接走的想象，都不能仅解释为介绍性格；叙述者知道这种愿望难堪，却愿意把它讲得热闹而完整。

第 336—367 段是辨认叙述立场的重要位置。父母的来信被人当作肉麻的笑料，路明非躲去洗手间哭，旁白却明确承认那些话很感人，并替这个缺爱的孩子说出为什么爱需要说出口。随后误入女厕的窘事继续发生。幽默没有被永久关闭，感动也没有被宣布为愚蠢。这与始终站在外面观察人物自我感觉的冷幽默不同：叙述者会在必要时离开笑声，走到被笑的人身边。

第 521—522 段把同路的长短说成一般经验，随即发展为少年埋怨市政府没有把路修长五十公里；第 558—563、681 段由天台看车流如萤火虫，到本人进入车流，却仍然不知道出口在哪里。想象随着人的处境继续改变。第 628 段失恋的冷意一直抵达采蒲公英跑酸的关节，前面的认真准备没有被白写；第 647 段人蹲下去，字母也变了形，疼痛与笑感留在同一个动作中。第 676 段又明确指出，压过情敌的风头没有使他得到爱情。叙述者满足扬眉吐气的愿望，但知道这种补偿填不平失落。

这一章也表现出对美貌、昂贵物品和公开认可的明显迷恋。分析不能把这些统统洗成对消费社会的讽刺：文字既调侃它们，也认真享受它们。具体续写时应辨认叙述者当前真正在乎什么，不能只复制法拉利、女神和逆袭的外壳。

### 第二幕：黄金瞳

阅读范围：第 1—462 段，章节 ID `d1a6dad4-a082-4de2-a275-bf1ee7c8bab9`。

这一章把神话世界始终放在一个会饿、缺钱、害怕复读的人面前。第 15—19 段不是孤立地把路明非比成摩西，而是先虚构摩西找不到目的地的整段情境，再让这个摩西站在三明治店外计算二十美元。叙述者愿意沿一个玩笑走远，因为这个玩笑同时表达了被许诺又被遗落的处境。第 219 段承认，宏大世界没有复读高考那么切实可怕；这种落差不是要证明少年可鄙，而是让宏大使命落到他真正承受得起和承受不起的尺度。

叙述者也并非拒绝壮丽。第 137—144 段认真展开被杀黑龙与欢呼的人群，第 283—290 段认真欣赏战斗的速度、技巧和刀的力量，然后才让路明非用游戏经验插话。把所有壮丽立即解释为装腔，会破坏这里的双重享受。第 300—313 段又把对诺诺的信任解释为没有别的人可以相信，并让动作迟缓转成负罪感，说明战斗的推动力与人物私人需要相连。

第 274—275 段路明非借导师的身体装死，同时有一点难过。旁白没有为他修改成全然高尚的姿态。第 361 段却对两个宿敌倒在一起的亲密样子饶有兴趣。这样的观看有亲疏、有恶趣味，也会留意英雄不打算给人看的样子。结尾第 462 段从学院危机、血统与考试落回诺诺已有男友的失落：宏大经历未能使人的小小心事自动消失。

<a id="chapter-02"></a>

### 第三幕：恺撒

阅读范围：第 1—359 段，章节 ID `62d2b92c-7618-4aae-8f9b-0a9426dbc10b`。

芬格尔追问路明非是否想回国时，文字先写防御和生气，再让愿望直接出现。第 59—61 段的愿望并不高贵：想有人关注，想被女孩喜欢，想有可吹嘘的东西。叙述者没有急着给它补上正确的志向。紧接着肚子叫了，两个人吃饭、互相递鹅腿，关系在具体生活里继续。后来饭要付账、师兄高价卖题，先前的笑与关照也并没有因此全部作废。这是同时看见关心和占便宜，不是先塑造好人再揭露坏人。

第 104—122 段教授保护学生的理由，经过一场关于血统和危险的讨论，落到孩子收到来信后哭泣，以及他们自己曾被关在铁栏杆后的经历。第 112 段关于昔日抄作业的插叙还给讨论带来小小笑意，随后第 122 段才让电疗记忆进入身体。严肃并不要求人物突然失去日常习惯，善意也具有个人来路。

第 238—304 段地下机房里，力量、爱情、复仇和买可乐的零钱彼此相接。男人离开后，叙述并未跟着重要人物立刻走掉，而是留在哭泣的虚拟女孩和试图逗她开心的小机器人身边。刚才死攥着钱的机器人撒落硬币，女孩虚幻的泪也落在地面上。这里的关切越过人类身份和任务重要性，给了被留下的人以篇幅。第 353—359 段同样从全校热闹的赌博回到孤独背题的人：别人押的是他的潜力，他自己想见的是一个具体的人。

### 第四幕：青铜城

阅读范围：第 1—430 段，章节 ID `79ec5ab8-30c7-4efb-b17d-4b20137ef8ba`。

第 13—17 段把一个正式英文名、好天气和少年忽然觉得自己可以留下的心情连在一起，却没有武断地替他确定原因。这里既解释也保留摇摆。第 89—91 段则有明显的态度转折：路明非先用言情套话和男性亲密的玩笑躲闪，随后真正感受到路鸣泽的悲伤，文字不再帮助他把感情说成造作。

水下冒险拥有自身完整的声音：光线、水压、金属机械和不断减少的氧气建立了可以感知和判断的环境，人物的闲话也没有消失。第 263—272 段的婴儿既像神父与殉道者，也会在清醒后对着受伤的手指大哭。曼斯对他既有任务上的使用，也有照顾孩子的亲昵。第 231—238 段中，养母因诺诺的异常而拒绝爱她，导师却愿意称她为好孩子。不能把这一段只归纳为母爱缺失的剧情信息；它继续表明文本愿意替不合常规的孩子保留被爱的资格。

救援中，第 393、416—428 段把路明非的参与落实在他记得亚纪的笑、觉得这两个人死了可惜，而非突然接受拯救世界的理想。游戏作弊的经验成为越过禁忌的行动入口，黑羊的想象也从解释秘籍变成了眼前的选择。叙述对这种不那么守规矩的急智带有亲近。

### 第五幕：龙影

阅读范围：第 1—363 段，章节 ID `5136a497-d353-4b23-b232-e8c06beace07`。

第 10—36 段没有用完美情人取代危难中的搭档：叶胜游泳课上拍屁股、笑亚纪腿短的样子进入她的回忆，又进入告白之后的神态。关系的珍贵来自这些有点可恶却只属于他们的共同生活。第 38—43 段则先让船长得意地跳舞，再发现氧气计算遗漏；希望被认真地提供，又被实际条件击碎。这种疼痛不能简化为“快乐都是为了反衬悲伤”，因为人物当时确实相信自己的努力有用。

第 114—118 段刚让塞尔玛说愿意用满分交换同伴回来，紧接着便让她被拖入水下，曼斯的反击还可能伤到她。叙述并不保证关心他人的人获得好结局。第 197—220 段的学生欢呼、白鸽与白手帕，随后被第 239—258 段真实的全军覆没重新解释。成年人希望学生暂时仍把屠龙当热血事业，这是曼斯与昂热的决定；文本同时让读者看见了他们隐瞒的代价，不能只拿他们的发言概括作品的立场。

死亡前，曼斯想刻在墓碑上的是妻子的名字，而不是研究结论；前文遗体空运保险的玩笑在此成为实际的后事。与此同时，第 259—262 段仍让错误俚语流入教授的哀悼。严肃与滑稽相邻，并不必然意味着叙述者不尊重死者。第 228 段又将楚子航低垂眼睛从高冷改写为避免吓到别人，随后仍容许路明非误解他的邀请。读者与人物之间的认识差，未必总服务于嘲笑，也可以使读者先一步理解别人。

### 第六幕：星与花

阅读范围：第 1—612 段，章节 ID `96b7c328-d440-4f40-ac9d-724d4cc460df`。

第 10 段直接回头解释两人为什么跳舞，能听到一个愿意讲来龙去脉的人。第 15 段对恺撒的判断同时包含臭屁和优雅，文字并不要求二选一。舞会的滑稽被充分展开：黄鼠狼、迫击炮、抢舞伴和失手都在动作中延续，而第 31—32 段又让路明非对“穷但努力”的体面评价产生反感。被笑的人有可笑之处，笑他的人也并不天然拥有判断权。

零的舞蹈被认真赞美，第 126—128 段将被信任落实在路明非必须握稳那只手，否则女孩会失去平衡。这份价值具体得很小，却能使人郑重。第 134—137 段紧接着让他不会还礼、说出烂话，掌声又恰好掩住烂话；人物可以短暂地好看，也可以继续笨拙，不必每次都受到公开羞辱。

山顶对白不只解决爱情关系，还容纳音乐、车、身体怕冷、旧同学、生日时刻和旅行方式。第 339—343 段从礼物的羞怯写到擦脏的手帕，让浪漫愿望与日常狼狈共处。诺诺关于配得上、相处舒服和不懂喜欢的解释，不能简化成她口是心非地等路明非追求。第 485—486 段也承认被救过一次不代表有权要求对方再救，偏爱主人公并未剥夺别人的独立。

第 460—463 段用白纸和头发丝调侃路明非理解的浅，第 499—501 段却让他把眼前生日礼物与父母来信、叶胜亚纪错过的时机接起来。第 533 段，他看见威风女孩的孤独。烟花被写得绚丽，最后镜头又转到收工谈钱的工作人员。读者知道奇迹背后有安排，但两个人刚才的开心并没有因此失效。

### 第七幕：弟弟

阅读范围：第 1—418 段，章节 ID `c06ac7cd-b969-4ea6-9bfe-22315e089a07`。

这一章反复把威风人物的另一面交给读者。第 72 段从恺撒自己的心里说明，他送出输掉的车也会紧张；路明非感受到的压迫是真实感受，却不等于恺撒的一切动机。第 187—195 段写老唐进入水族馆，从陪女孩看海龟转到被动物畏惧的童年，超常能力带来的首先是“我是否招人讨厌”的困惑。叙述者愿意为一个刚才还在自夸的赏金猎人解释这种难堪。

第 109—138 段再次出现导师对好学生的保护。施耐德指出曼施坦因会袒护身边的人，并以这种看似没有立场的特质托付学生。此处有关偏爱的明确表述属于人物判断，但它与此前多处场景共同构成一种值得追踪的作品倾向：抽象分类不足以取消具体相处形成的责任。

第 142 段的音乐收藏被展开为背篓拾物、倒出东西随意翻看，显出对杂驳趣味的容忍。第 157—169 段让打杀、租来的正装、流行歌、跑车与绝影想象共处；叙述者提前知道他们跑不过时光，却没有删去拍照时捏鼻子的鬼脸。快乐不是因为不知道后来才显得愚蠢，它本身就是值得记录的生活。

叙述同时有鲜明的消费与情色兴趣。第 239 段愿意为财富会所铺陈一整段任性需求，第 245—253 段公开欣赏麻衣的身体。第 340—353 段换到寡言的楚子航与零，还会嫌他们的对话乏味。这不是中性摄影机，而是有自己的观看快感、偏见和闲谈欲望的讲述者。后续提炼声音时，应辨认这些具体取向，不能只保留抽象的温柔。

### 第八幕：哥哥

阅读范围：第 1—612 段，章节 ID `a9b03d7a-8ffc-40e9-9279-d4a875242b26`。

第 17—28 段先将龙族兄弟的谈话写成老唐听不懂、甚至嫌弃的古老台词；到第 468—481 段，几乎同样的话成为他恢复的记忆，叙述贴近他的内心，以直接向弟弟说话的方式承认认出太迟。理解的迟到没有被概括为一句人生道理，而是改变了前面已经读过的话。

第 402—410、450—481 段尤其重要：被追逐者认为是鬼的龙类，先显露成瘦弱、礼貌、寻找哥哥的少年；路明非因此不忍准确开枪；弟弟又张开双翼替哥哥挡下枪弹。叙述越过了屠龙者的身份分类，让读者看到被杀者的私人感情。第 483—497 段却不以相互理解结束冲突：昂热承认对方是“他”，仍决定利用至亲死亡把龙王逼入绝境。作品给人的复杂感，部分来自这种理解与行动并不一致。

恺撒与麻衣也获得了不同于出场姿态的说明。恺撒替女友挡险，生日礼物是花半年写的书；麻衣留下保护昏迷的部下，又不肯用纯粹牺牲精神解释自己。人物不必放弃骄傲才能关心别人。危险中的酒店收费、信用卡、浴巾、宵夜与泳池闲谈，同样延续了叙述对庸常生活的兴趣。

第 583—612 段由路明非直接问师兄为什么对自己好，转到以为要死而留下信用卡。芬格尔没有忽然改说庄严励志的话，而是要马上刷卡，把路明非逼得自己承认也许能够活回来。动作仍沿着两人此前占便宜、斗嘴、吃夜宵的关系发生，鼓励因此属于这两个具体的人。需要学习的是理解他们为何只能这样说，不能把“用反话安慰”机械套给所有角色。

### 第九幕：龙墓

阅读范围：第 1—489 段，章节 ID `8a6be312-0a37-4f4f-a30e-aced933da327`。

第 8—28 段让龙王与久别的龙侍重逢。先铺写超出传说的狰狞与威严，随后让庞然大物温顺地低头，接受抚摸；普通游客听不懂的吼声又被说明为撕心裂肺的悲伤。叙述已经给敌人以私人情感，再进入学院部署屠龙的场景。因此，后面的作战说明始终不能完全占据读者对龙王的认识。

第 34—81 段让严肃部署被胆小者的内心闲话不断穿过，零的生理期、路明非照顾她的真正动机和即时的报复又组成一个完整的小波折。第 123 段直接用反问邀请读者想象血管里充满气泡的危险，说明文字既能贴着人物想，也会转身向读者解释。第 181 段从怕蛇想到衣冠楚楚的蛇，再到行礼的读书蛇，笑意由同一个观察持续生长，并非另插一个与现场无关的笑话。

第 254—300 段依次让水滑梯变成摩天轮，让寝宫预期里的盘龙柱、水银和王座落到小屋、两件衣服、枯花与一张桌子。叙述愿意花篇幅认真看这些居住痕迹。诺诺通过倒水、递葡萄逐渐接近兄弟的生活，路明非从怕她发疯到接住想象中的葡萄，情感理解也经过了身体参与。读者不是只被告知龙王有亲情，而是暂时坐进他的家。

第 311—329 段仍然要炸掉这座家。诺诺留下宫灯的愿望，与她执行毁灭任务同时成立；灯又从纪念物变成主人刚离开的证据。一个物件连续承担生活、惜别与危险，不需每次另找一个意象。第 358—362 段诺诺的安慰有自己的羞耻经验，也保留开迈巴赫的虚荣比方与粗口。最后第 469—488 段把龙侍的温顺推进到牺牲，麻衣的悲伤、恶心和电话另一端的忠诚解释并不一致，分析不能挑其中一句当作唯一的叙述结论。

<a id="chapter-09"></a>

### 第十幕：七宗罪

阅读范围：第 1—438 段，章节 ID `49b804fb-cb58-4af2-9930-481aa55feca0`。

第 19—29 段给先前死去的叶胜补上最后的行动：尸骨没有氧气瓶，氧气留给了亚纪。人物只用简短的“酷”来承认他，叙述不需要替换成庄严悼词。第 49—56 段则先让路明非嫌诺诺踹他，随后看见她正用头与双手支撑青铜壁。判断随着所见翻转，希瑞的童年想象又暴露现实身体的脆弱。关键时刻，叙述允许他承认自己也会发疯，没有强迫他先成为平静、成熟的人。

第 84—90 段在救命时仍保留少年对女孩身体的惊艳。这是这一段的具体观看倾向，不宜抽象成所有小说都应如此。第 144—172 段另一组人物从直面龙王的英雄姿态，进入听力受损后用手语闲谈的私人时刻。零照镜子与自己说话的经历，被恺撒接成身边有个有趣新生的感受；他没有正式宣布同情，却与她一起拉住绳索。关照可以落实为愿意陪伴，而非评价受苦者的台词。

第 231—239 段由路明非亲口讲被忽视的生活，连续反问既向路鸣泽争辩，也使读者面对那些轻易点评他的人。第 311—312 段又承认，他尚未充分了解诺诺，喜欢未必就是爱，却仍想让她活。这一区分保护了感受的真实尺度，不靠把关系夸成命定爱情来证明付出值得。

第 390—399 段是连续叙述的重要证据。先问屠龙理由是否够分量，再把很小的理由展开成园丁守着望远镜看火星上唯一的花；接着实际听声辨位又成为天文学家寻找天体；最后确认来袭方向，被写成孩子终于看见花开。比喻从愿望进入判断与行动，叙述者参与了这种自认不值一提的渴望，把它认真讲到尽头。这里的二人称不是一般性道理，而是把读者拉进“如果这是你唯一拥有的东西”的处境。

第 409—421 段发现敌人是老唐后，宏大的胜利立刻被两人未能实现的灰狗旅行取代。第 422—432 段获救女孩与恋人相拥，路明非仍挂在船边，无人拉他上去。叙述承认恺撒的眼泪，也继续听见路明非的苦涩小声，不把其中一人的感情当成另一人的虚假。这一收束既让付出成立，也没有给予主人公以付出兑换爱情的保证。

<a id="chapter-10"></a>

### 尾声

阅读范围：第 1—198 段，章节 ID `40132819-69cd-4031-a5d0-ace792845fd7`。

第 17—35 段并置了昂热的异族战争解释、路明非对兄弟的怜悯，以及照片上明亮而没有威严的老唐。路明非点头接受说明，文字却再次盯住照片：即便知道那是龙王，也看不出相应的模样。这是讲述在表面服从之后留下的抵抗，不宜只摘校长的话作为作品价值观。

第 65—128 段把英雄回归写回新闻照片、买啤酒、借胡椒粉、做饭与巧克力。贵公子切菜仍然面无表情，威风并未消失，只是进入生活中的另一种用途。路明非收到巧克力时的兴奋先被充分承认，再让他发现它来自拼着恺撒名字的巧克力墙。叙述愿意陪他高兴，也愿意看他难堪，停留时间和用词都带着熟悉他的亲近。

第 145—169 段用客服式短信通知生命已被扣走，随后才让诺诺认真道谢。两种声音紧邻，因而轻松重逢里始终有别人不知道的代价。第 165—167 段从一次守诺认出对方也是执拗的孩子，带着惊讶而不是预先安排好的成长总结。最后路明非想与喜欢的人一直住隔壁，叙述保留愿望，也保留背后意义未明的笑声。

第 187—198 段日记把结尾再带回欠款、作业、烧到同学头发，以及看见白色芭蕾裙后的开心。作品没有停在一种统一的庄重情绪上；孩子仍要过明天的日子，也仍会把大冒险后的生活称作乏善可陈。这些重复而具体的生活对象，是持续声音的一部分。

## 第二部：悼亡者之瞳

<a id="chapter-11"></a>

### 序幕：雨落狂流之暗

阅读范围：第 1—338 段，章节 ID `dd339af0-766d-427b-b324-5bb22efd16f8`。

第 13—18 段贴着楚子航的感受评价成年人：孩子想安慰母亲，母亲却没听懂；继父负责、守诺、有教养，他却仍不愿求助。叙述没有把物质充足等同于情感已经得到满足。第 25—30 段又让他看见柳淼淼对不同男孩的区别，想捎上被拒绝的路明非却未能开口。后来人物之间的照顾，有了更早且未被对方知道的来路。

第 37—160 段用了很大篇幅讲父子之间的烦躁、炫耀和不肯直说的期待。奢侈品、换车道、听错歌词、热牛奶、家长会和观影计划都有各自的生活内容，随后才汇成孩子对失职父亲的愤怒。第 104—105 段直接向父亲追问，话却只发生在心里；第 143 段从好学生的公开形象转入刻薄话的私人来由。叙述不要求孩子先懂事，才肯承认他想要一个父亲而不是司机。

父亲显露力量之后仍然话多，会开荒唐玩笑，也会害怕；第 193 段一个护住头的动作使杀戮与童年旋转木马相接。第 221 段仍答应去家长会，第 294—295 段仍夸自己的大招和九百万的车。威风从原来那个爱吹牛的男人身上长出来，没有换成一套标准英雄腔调。第 296 段第三个能启动车辆的人得到答案，使此前未被认真听的话成为预先留下的照顾。

第 309—315 段重新解释歌曲与父亲退让的生活，并直接追问死亡是什么。这里没有回避抽象说明，而是把它落实在再也握不到的手和说不出的道歉上。第 321—328 段忽然用城市公共叙述讲台风假期与无人伤亡，再留住等不到父亲的孩子。公开的好消息无法包含他的损失。最后母亲与闺蜜仍然热闹，他继续热牛奶、背记父亲；讲述没有责令所有人一起哀伤，却认真维护那个只有一人守着的存在。

<a id="chapter-12"></a>

### 第一幕：生日蛋糕就是青春的墓碑

阅读范围：第 1—255 段，章节 ID `d1b0b523-64fe-4b97-9c38-ed5634410a87`。

第 5—38 段用烦人的暑假报告重新介绍世界，把术语、学院规则与孩子嫌作业碍事的口气连起来。说清必要信息不等于暂停声音。第 32—42 段认真让路明非预演衣锦还乡的微笑，回家却仍买盐切萝卜；第 44—66 段的三问连续削掉他关于钱、爱情与父母的自我安慰。这里的声音会跟人物一起抱怨，也会笑他把拯救世界当作免做家务的资格。

第 50—55 段补充了第一部对父母来信的认识：信里的爱曾让孩子感动，现在他希望父母亲自回来证明那不是落款和修辞。迎接父母的想象被完整演了一遍，连如何忍住哭、如何淡淡说话也包括在内。叙述既承认信的意义，也替他保留向缺席者提出更多要求的权利。第 79—84 段先说生日无所谓，又紧接着认真写楚子航的短信带来的意外，被忽视者的逞强无需由作者另行诊断。

第 99—194 段转入教授值班，仍然有一个会抱怨加班、揣摩同事、嫌经费麻烦的讲述位置。巨型地球投影的权力快感被铺陈后，落到曼施坦因不想值这个班；金额、警报和责任不断升级，玩笑具有连续的处境。古德里安的偏袒在重复推荐学生中显出固执，而非一句抽象的爱护学生。

第 203—206 段先说楚子航无趣，再说明篮球与父亲的联系，并纠正恺撒关于苦修僧的判断。第 220—247 段容许母亲和闺蜜们有自己的消费闲话与喧闹，儿子订饭、调空调、收窗帘、熬药则都是具体的照顾。第 239—242 段将他的啰嗦与父亲留下的牛奶习惯连起来：不肯放弃过去，通过每天还能做的小事继续存在。随后取下美瞳、启动跑车，温柔与危险属于同一个人。

<a id="chapter-13"></a>

### 第二幕：同学少年都不贱

阅读范围：第 1—354 段，章节 ID `4a8e9e1f-f14b-47c1-b4d3-4be7e6bb917b`。

第 18—40 段借同学眼中的传说重讲主人公，别人以为他杀气逼人，他却只在练习重逢的微笑。第 54 段留下柳淼淼在玻璃上弹琴的光影，说明人物对一个人的看法可以因一次具体观看而改变。第 87—99 段由炫表转到情侣短信，再想象两个人共有的小世界；这里优美的亲密图景后来被短信真相推翻，但它仍真实表达了路明非渴望什么，不能当作叙述者已经确认的两人关系。

第 166—171 段尤其能辨认讲述者与读者的关系。文字先替报复心编出很长一段可能的冷笑，还向读者逼问，难道不会幸灾乐祸；随后路明非只是叹气，看到女孩已经很累。叙述者熟悉刻薄的乐趣，也能够主动离开这种乐趣。它并不把人物写成无私榜样，仍称其怂、滥发同情，却把真正的篇幅和注意力交给不忍心。

第 197—218 段在满桌欢腾中看见一个人的坍塌。路明非在心里把抗议说得豪迈，真正出口的很少，又因顾及陈雯雯而吞下解释。第 207 段用他看电影时也会因别人难堪而换台的习惯，给这次出头以跨场景的性情依据。第 262—267 段没有因师兄撑场就宣告他成长完成，他仍觉得自己无能，最后折回去拿的是马桶圈。

第 244—253 段先认真写柳淼淼看楚子航的雨中记忆，再告诉读者他其实在等父亲。相同的姿态容纳两个人完全不同的心事。第 273—303 段由女孩哭得丑写到仍想保护她，楚子航的冷硬提问又逼出路明非看不得人受委屈的理由。读过序幕的读者知道，“你不懂委屈”是主人公的误判，讲述不必马上插话纠正。

第 317—338 段转入陈雯雯自己：先容许赵孟华的烦躁说完，再让她从已经消失的约会，想到被扔掉、不会哭的无嘴小猫。想象连续经过地点、食物、物件，最终把对自己的怜惜移到小猫身上；她甚至后悔当初买它，成为一种具体又不合算的悲伤。第 343—354 段师兄回来救场，仍以杀手般的送信方式制造荒唐。前面的痛苦无需使整章从此只剩悲伤腔调。


<a id="chapter-14"></a>

### 第三幕：悬赏

阅读范围：第 1—312 段，章节 ID `cb366420-c5fb-4903-aa70-9fb3f9ffe812`。

第 30—34 段的论坛有聚会、课程、毕业和闲话，各人的日子不是只为主角的任务而存在。第 39—91 段认真欣赏恺撒的钓鱼、猎隼与贵公子姿态，同时写他明白别人的调动手段，却仍愿意帮忙。叙述没有用“有钱所以浅薄”省掉理解他，也不因此取消他的自负。第 185—221 段甚至替唐威追溯第一次进快餐店的惊叹，展开他退休、养父与享乐的愿望。对一个人的兴趣可以先于是否赞同他。

第 235—241 段说明婶婶在家族比较中的受挫，给偏心以具体来由，但没有将其改写为合理对待路明非。第 259 段送转换插头的想法来自路明非自己初到美国时的狼狈；礼物不贵，却记得别人以后可能遭遇什么。第 290—296 段一面让他感到朋友的重视，一面仍让他留好插头，又盼望蛋糕能写自己的名字，哪怕只是用来砸人。宏大的身份变化，最后要经过这些小愿望才能触及他本人。

第 299—311 段刀与铁的宣言带着人物当时不想再受伤的愿望。后文他依然会心软，因而不能单摘这段作为全书要求人冷硬的准则。分析连续声音，需要保留一段话之后，人物有没有真的按它生活。

<a id="chapter-15"></a>

### 第四幕：炎魔刀舞

阅读范围：第 1—423 段，章节 ID `fafadea6-6ce9-450d-bd6b-365799c5cac7`。

第 26—31 段没有掩去唐威欺负人的过往，又承认父亲对他不可替代。第 368—380 段临死时还想着钱、签证和父亲的荒唐旧事，也还保留对父亲外貌的不体面嫌弃。叙述没有因为即将失去一个人，便替他把整个人生修饰干净。第 392—405 段父亲照片使楚子航停止杀戮，随后唐威仍用原来的世俗经验猜救命者身份，恐惧与笑话属于同一个人。

第 99 段楚子航关心普通人的伤势，第 314—327 段血统力量却使他将人看作蚂蚁。这个变化不能概括成作品推崇强者俯视弱者。第 350—365 段施耐德谈武器，又惦记学生的牙病；第 417—421 段严厉要求之外，竟希望学生无能些，好让自己能够保护他。保护与使用之间的矛盾在人物身上继续存在。

第 252—267 段恺撒的反抗从母亲的手与温度长出来，家族的荣耀不能替代这段具体关系。第 63—76 段的刀舞则认真容纳威风与围观误解；第 413 段危险结束后回电话，话题又是吃饭。叙述能够欣赏英雄姿态，却不把所有人在重要事件中的说话方式统一成英雄宣言。

<a id="chapter-16"></a>

### 第五幕：蒲公英

阅读范围：第 1—405 段，章节 ID `c3a924d2-20e1-4624-be29-422f7271a2c1`。

第 12—32 段让路明非承认轮到自己享受高级餐厅时也很开心，叙述熟悉他的虚荣，没有急着替他找正当理由。第 33—87 段楚子航受伤回家，看见母亲、伤口与食物。母亲并不因此成为合格完美的照料者，饺子也确实难吃到被吐掉；但是家之于他的意义仍被认真承认。年份醋的说法借用上一场高级餐厅的口吻，笑意和依恋有共同的生活来路。

第 127—190 段用权力与纸巾的比喻诱惑路明非，把喜欢的人变成可以拾取的东西。他拒绝了这种看法，却没有从此停止心动。第 223—227 段干枯的蒲公英终于作为亲手准备的礼物送出，这份心意无需由爱情成功证明。第 254 段师兄借记者报复的孩子气，又与他后面关于想被爱的体谅共存。第 285—291 段把请拉面与父亲开车接在一起，随后楚子航因自己说得太煽情而加速，感情没有迫使他忽然擅长表达。

第 293—330 段两个女孩从性感、刮腿毛聊到喜欢、结婚与户口，各自有好奇、戏谑和犹豫。书与阅读的长比喻属于诺诺对爱情的疑问，不能当作叙述者已经证明的爱情定律。第 339—342 段恺撒也承认自己在乎可能失去的富裕生活；第 344—367 段求婚短信与冒雨行动交替，他一度钦佩自己的文采，真情并不因此作废。两个女孩随后拿求婚信像战书来开玩笑，也真切感到它动人。

第 378—398 段创伤记忆冲淡求婚的快乐，诺诺迟疑是否发出生日歌。第 400—405 段路明非却在飞机上猜想她正依偎恋人，劝自己不要再想。读者知道的内容比他多，因此能够同时看见他的自嘲和误解；讲述不需要当场揭穿他，也没有用诺诺的犹豫保证他会得到爱情。这种距离使心疼发生在连续阅读中。


<a id="chapter-17"></a>

### 第六幕：防火防盗防师兄

阅读范围：第 1—200 段，章节 ID `d90681a2-a871-4dc1-ad20-bfec344e1aba`。

第 8—11 段从热爱罢工的政治答卷转到自己出钱时的肉痛，讲述熟悉人物的矛盾，也笑得具体。第 20—26、54—60 段对夏弥的美有长时间、毫不掩饰的欣赏，偷可乐也能被写得曼妙。这一观看带着明确的少年男性欲望与偏爱，不是中性的“人物很美”，更不是所有人都受到同样目光。

第 78 段听不懂学术的状态被展开为佛前蛤蟆盼望有人翻成自己的语言；第 114—123 段学术讨论、旧歌联唱和校园闲话不断相接。叙述最后才从未来回望，希望这个看似浪费人生的下午长一些。前面已让人实际待过这段时间，后面的留恋才有内容。第 132—136 段又让女生夜谈中数睫毛的愿望，经过路明非与楚子航同床的玩笑，落到楚子航看夏弥的睫毛上。同一个细节在不同人的心事里接力，最后才显出时间的意味。

第 151—200 段导师们烧毁档案，偏护并非抽象口号。古德里安为了证明学生不危险可以说他怂，发现没有可疑记录又称他是天才；曼施坦因看重规则，却也加入。接着用可乐、字典和表情管理遮掩证据，关照通过一场具有具体手忙脚乱的共同行动呈现。叙述让人喜欢他们，也没有把这种偏袒包装成毫无矛盾的公正。

<a id="chapter-18"></a>

### 第七幕：群龙的盛宴

阅读范围：第 1—364 段，章节 ID `d9fbc995-c2be-4896-995c-91325e23488c`。

第 8—50 段先从没有睡痕的床与过于整齐的房间写出陌生感，再用早餐、触碰和凌乱的生活痕迹恢复亲近。豆腐脑被认真称作继续过日子的理由，魔鬼的触碰也被允许温暖；紧接着辣椒恶作剧使眼泪变得滑稽。这些变化不自动证明前面的亲情是假，也不保证魔鬼没有危险。

第 85—97 段校长的衰老与飙车没有各占一种庄重、轻松的腔调：寿命不多，反而成为任性开快车的理由。第 129—149 段认真铺陈旧式城市、服饰与歌剧院，再让路明非在人群中觉得自己丢了。第 216—218 段名刀重现，别人的珍宝仍是他杀死朋友的阴影。物质魅力与私人不安同时成立。

第 251—275 段用房子和游戏碟衡量巨额财富，从自认学不会微积分的大猩猩，讲到不甘心的火苗。第 291—302 段真正刺激他的，是他在那些笑声中重新听见公开朗读成绩单的羞辱。雪茄在第 304、319 段先脱离烤肠般的窘态，随后又蔫了；第 320—325 段威风沿着港漫联想长大，再随如厕后的清醒退去。变化经过连续的身体与想象过程，不只用“他又怂了”作结。

第 342—364 段转到幕后者，仍讲衣服、薯片、账本、牛仔裤与游戏。操纵重要事件的人也会彼此嫌弃、操心花销，有自己的消费兴趣。阴谋信息没有把他们压成只负责交代秘密的传声筒。

<a id="chapter-19"></a>

### 第八幕：康河上的叹息

阅读范围：第 1—247 段，章节 ID `8fc7ebce-7332-48f7-ae78-6d5c72a3a4ae`。

第 41—48 段旁白将谈判者从受过训练的精英逐渐称为垃圾债券经纪商，评价倾向直接进入称呼。第 51—75 段昂热以烤肉、炖汤的俗笑抵抗对死者的标价，再说明自己身处战场，无法从高处把熟悉的人看成蚂蚁。这里的叙述明显贴近他的怒意，但第 82 段也留下汉高照料受伤年轻人的动作，没有把对方阵营所有人写成同一张恶脸。

第 95—132 段先认真铺陈来客的优雅与脚步，随后才揭出头上的快餐纸袋；喝酒撕孔、转动纸袋、撞上门柱又继续发展这一处境。笑意来自讲述者愿意跟着看完，而不是一句反差设定。第 153—190 段父母的话题则让路明非不再轻易说烂话，随后又沿葫芦娃、蜘蛛侠和耗血游戏角色继续想下去。昂热要求他原谅父母，属于人物的劝说，分析不能据此抹掉此前关于缺席的事实与感受。

第 195—212 段看女生裙下小腿的往事，与后来探访那些女孩墓碑的深情接在一起；路明非甚至直接吐槽这种混合。昂热知道复仇不能令故人回来，依然要守住可供缅怀的地方。最后一块奶油蛋糕将大义缩到个人仅剩的珍贵之物，缩小尺度反而使坚持更可理解。第 201—207 段路明非关于强者装孤独的判断之后，叙述又拉开时间，指出他当时还不明白某些东西，不能把他的全部抱怨直接等同于作品结论。

第 230—247 段飙车成为昂热不断赴死的人生形象，路明非却仍在狼狈地寻找自己舍不得什么。他嘲笑童年幻景的台词，眼泪仍流下来；校长递纸巾，却允许他不讲原因。末尾对于别人享福、自己卖命的不满没有被觉悟消除。讲述接纳感动，也保留人物算不平的账。


<a id="chapter-20"></a>

### 第九幕：中庭坠落

阅读范围：第 1—219 段，章节 ID `9353a992-dfe7-4880-b863-9df1be287eb2`。

第 10—23 段让楚子航的知识盲点具体落实为过往约会的误会。第 27—44 段夏弥讲哥哥，爱与嫌弃、后悔与护短同在；希望哥哥没有出生，是她不愿他受苦的感叹，不能不加区分地归为作品对病弱生命的判决。第 45—50 段楚子航不想听别人的私事，却开始想象自己当时在场，拦住施暴者，让女孩与哥哥沿长路回家。封闭的人已在替别人重想一段时间，随后又退回公事式口吻，没有突然变成善于安慰的人。

第 75—86 段两个男孩怕过山车，白雪公主与小熊维尼成了最后的退路。第 145—158 段怕出事而提前查资料，又成为楚子航实施救援的知识来源；昂热也承认借陪孩子的名义满足自己玩乐的愿望。人物可笑的部分与有用的部分相通，不是各贴一项缺点、优点。

第 169—196 段从玫瑰与鼻血写到普通乘客的脸，再看一个父亲徒劳地抱住孩子。叙述知道这个拥抱抵挡不了撞击，仍仔细讲他的难看笑容如何给孩子一点勇气；楚子航因而想到父亲，采取行动。第 184 段临刑大笑的想象，到第 190 段成为灾难逼近时脱口而出的话；第 209、218 段骂英雄傻，话里却有眼泪与后悔。已有的粗话、动画经验和笑法继续承载强烈感受，无需另换庄严语言。

<a id="chapter-21"></a>

### 第十幕：守夜人

阅读范围：第 1—324 段，章节 ID `62884f0c-a61e-4dfe-9633-1578b25e8706`。

第 6—21 段同一群科学家，在古德里安眼里是偶像，在曼施坦因眼里是献身科学的疯子，旁白还加入相当尖酸的形容。声音不是始终温柔的旁观。第 119—121 段讲梅涅克做饭，将战争传承落实为穷师弟穿好衣服却饿肚子、师兄请吃鹅肝，未来再给下一位师弟做饭。饮食有实际照料的内容，不只是接下来谈大道理前的布景。

第 125—165 段病房长谈贴着楚子航的疲倦，让他反复嫌夏弥话多、盼她离开。他刚为安静而惊喜，才看见她睡着，护士补出她四十八小时没睡。此前的烦躁没有被删掉，读者与他一起修正对陪伴的认识。第 190—193 段也留下弗罗斯特对帕西的温和关照；第 195—224 段校长的严厉警示则由削梨开场、叮嘱吃梨结束。关心与危险处于同一场对话中，而第 249 段揭出的未告知催眠，又保留校长使用学生的另一面。

第 230—233 段把衣着考究的人来脏乱阁楼见朋友，展开成直接对读者谈损友的经验。第 247、270 段又能郑重进入呼吸如巨大肺腔、万物已死的神秘世界，不被闲话耗尽想象力。第 291—324 段昂热将毁灭说得美，守夜人指出他已走上只求复仇的绝路。最后的性别玩笑并未回答这一质疑。对人物的亲近可以允许他回避，但不等于讲述替他驳倒了反对者。

<a id="chapter-22"></a>

### 第十一幕：婚约

阅读范围：第 1—256 段，章节 ID `2aa57cf2-0079-4b77-ac9a-78d602d56ee8`。

第 6—24 段先让安德鲁的自我想象充分膨胀，再由第 25—57 段的花车、宴席和参观逐次打乱。他嫌帕西不直视上司，读者却已知道长发遮眼的缘由；这一认识差使他的判断显得可笑。叙述会明确带读者等着看某些人出丑，不能只提炼它理解弱者的一面。

第 93—165 段同时陈列楚子航确实造成的破坏、保护者消除证据的手段，以及新闻部成员希望讨回借款的动机。这里的亲近不要求行动毫无污点。第 183—190 段帕西的异色眼睛在楚子航的观看中像猫，与此前令人想起恶鬼的描述不同；具体观看者会改变同一外貌的意义。

第 232—256 段听见婚约后，并不马上让路明非流泪。先是空白、误听的侥幸，再是希望别人不要把人生过程推进得太快，最后才有身体的疲倦与疼痛。他把纸巾用于擦嘴，否认自己配有悲情主角的侧脸；手臂发沉，又被想成刘备或丢了香蕉的猴子。熟悉的自嘲仍然运作，却挡不住独自跑进厕所。

回忆也不全挑高光：买夜宵、跑腿、记咖啡口味先出现，随后才有电影厅、烟花和救援。第 254 段明知把别人留在初遇时刻有些贪心，仍认真讲他舍不得的每个人。叙述没有立刻命令人长大、祝福或放下，暂时停在镜前揉脸；这份停留本身就是可辨认的偏爱。


<a id="chapter-23"></a>

### 第十二幕：龙骨十字

阅读范围：第 1—365 段，章节 ID `380300a5-3a47-428c-ba3a-bad9854956d5`。

第 5—14 段探病的花从近似悼亡布置变成奶油蛋糕，笨拙的关心与路明非一整天的发呆并排。第 19—49 段先让他以为师兄拿自己的失恋取笑，再发现对方是真的来问感情。他自己不好过，仍想师兄能开心一些；叙述甚至写他觉得这也算功德，没有把善意净化为毫不自觉的高尚。第 63—76 段关于银耳羹的挑剔、抱怨与认真追问，也各有实际内容。直到听到婚约消息，楚子航才明白路明非之前的神态，理解发生得有迟有早。

第 83—95 段承认自己不通达，再从儿童迷恋海报、动画与歌手，写到长大之前喜爱之物已先改变。第 135—153 段楚子航用花与冰下的鱼为无结果的喜欢辩解，途中想到父母，讲完又后悔自己演讲太久；夏弥将比喻接成凿冰捞鱼煮汤。认真、尴尬、玩笑与再试一次的可能，沿同一个想象连续变化。第 156—179 段芬格尔想给师弟一点希望，也因他自己经历过失去；与光和空气握手的动作，让幕后照料者具有自己的孤独。

第 185—214 段地下世界的金属藤树、血与水、音乐得到大幅度铺陈，随后复生失败，让龙骨重新成为一个被怀抱的死者。第 241—260 段麻将的座位关系进入战术，再被压倒性的杀戮打破。第 301—317 段敌手在灾难中等电梯、想交换名片、互相救命，日常语言使临时亲近显得自然，事件结束仍各自逃离。第 322—365 段转入赵孟华的恐惧，现代设施逐项退回旧时代；叙述给情敌完整的受困经验，没有只把灾难当作供主角观赏的报应。

<a id="chapter-24"></a>

### 第十三幕：血统契约

阅读范围：第 1—267 段，章节 ID `e87b5530-04ab-4ae0-a787-1e4b38efaf05`。

第 11—28 段废墟上的两层床被不同人物用不同话题围观：有人问候，有人嫌酒，有人想到心理研究，还有人先要早饭。同一个荒唐场面容纳众人的生活习惯。第 30—60 段校长逐项认出损坏的鱼缸、花园、金字塔，副校长再揭开保存完好的龙骨；而面对可能帮过他们的龙，副校长提醒那按昂热自己的逻辑仍是敌人。事实与信条的缝隙被留下。

第 63—89 段赵孟华发现手机没电，从分手后失去的充电习惯，想到饭馆、电影、博客和短信。叙述没有要求他因此否定分手后的全部生活，甚至承认他仍可结识更漂亮的女孩；但危难中记得的号码来自旧恋人，记忆最终被写到曾亲吻过她的嘴唇与舌头。情敌也拥有这种身体里的过去，不能只用自私标签解释完。

第 91—160 段听证会的喜剧建立在明确知道有人造假之上，旁白并没有把保护者装成无瑕的公正方。第 162—219 段路明非再次见到诺诺，刚决定的退避很快被想靠近的心思打断。他承担责任既为师兄，也为让女孩笑。第 217 段全场装作听懂笑话，又让群体的热烈带着可笑的从众。

第 252—267 段同学放下对立的团结是真的，路明非发现只有自己没被告知默契的孤单也是真的。诺诺从曾经救他的人变成欢腾的“他们”之一，讲述承认这次主观变化，却另让楚子航越过人群看见他。路明非尚不知道这道目光，随后师兄申请与他同行。照顾在另一人的行动里发生，不靠旁白立即宣布他其实并不孤独。


<a id="chapter-25"></a>

### 第十四幕：罪与罚

阅读范围：第 1—265 段，章节 ID `d75259b6-dd3f-483e-997a-935104b04d89`。

第 37—75 段把古刀的美、破坏力、校长对桌子的心疼放在一处，又借神话铺陈力量与悲伤。这里既有真诚赞叹，也有惜财的喜剧，不能把后一种情绪当作对前一种的撤销。第 113—129 段，承受力量的人又必须面对寿命、失控和能力极限；楚子航帮助芬格尔拒绝任务，昂热自己也不愿试刀。强者对脆弱的了解分别进入行动。

第 182—196 段苏茜用楚子航的秘密换取保护，不要求他以爱情回报；但这并未被讲成她从此不再难过。随后她仍提醒恺撒给诺诺戒指。第 198—223 段家族长辈对恺撒的爱与利用并存，孩子不听话的日常烦恼并未洗掉计划中的伤害。

第 225—249 段，楚子航重新称认父亲只是司机，也继续给路明非准备眼罩、耳塞。关心有前文留下的习惯。第 254—265 段又进入恺撒与女友的冒险愿望，读者看到他尚未看到的危险；叙述允许他认真期待这段生活，并没有因为它会令路明非失望就取消其快乐。

<a id="chapter-26"></a>

### 第十五幕：幕后的人

阅读范围：第 1—227 段，章节 ID `ab8fb981-f0e4-43f8-aa12-42e7d761b3a0`。

第 19—53 段对酒德麻衣的身体与姿态有明显的欣赏，随后又写两名女性对妆容、工作与彼此的抱怨，以及她们迫使路明非执行任务的冷酷。人物既有日常趣味，也有不能简化为善意的行为。第 86—104 段，网吧的脏乱与游戏中的风姿可以同时成立，叙述并没有规定后者必须被前者揭穿为虚假。

第 111—149 段认真讲游戏战术、饮料和高手的家庭生活。对手输了也可以诚恳请教，路明非也能在这里得到具体的尊重；但这份胜利没有自动解决他在别处的孤独。动画台词的记忆、成年后的质疑、操作时的投入与突然想到诺诺，在一段思绪里连续出现。生活中的兴趣有自己的内容，并非专门替悲伤铺垫。

第 155—186 段楚子航承认自己曾拖累同伴；芬格尔对感情的刻薄议论，则被他自己的经历和楚子航的反问抵住。结合此前他暗中想给路明非希望的行动，不能抽取一句话当作人物或叙述者恒定的爱情观。第 188—227 段地图被想象成湖面和鱼泡，具体寻找工作在比喻中推进；同时芬格尔装忙，帮楚子航接受约会。幕后的人也各自藏着愿望。

<a id="chapter-27"></a>

### 第十六幕：It's a Beautiful Day

阅读范围：第 1—203 段，章节 ID `c6c320cf-bb81-46a5-b510-a9fb5b5958fd`。

第 7—99 段愿意陪恺撒坐三轮、逛鸟店、模仿电视剧中的说话方式。老北京街景与奢华器物一样可以使他高兴。叙述直接辨认他的中二，却亲近这种认真又有些幼稚的兴致。第 101—154 段借天气连接散落各处的人：有人洗澡打闹，有人试衣，有人带东西回家。明亮不只作为景色，而成为讲述对尚有机会的共同期待。

第 129—140 段先写诺诺对悲剧安排的愤怒、她对路明非的真实感情以及求婚前的犹疑；第 155—172 段再给苏茜放手的短信，以及诺诺过生日时未被满足的期待。俗气歌曲也可以被认真听出难过。叙述进入诺诺自己的恐惧，解释她为什么需要有人在场，而不是只根据她是否回应路明非来裁定她。

第 173—203 段恺撒的救援与求婚同时容纳认真、打趣和夸张。记得旧伤、愿意陪她胡闹，使关心具有对象；鸟笼里的粗话、摄影团队与花瓣，也没有消解拥抱的郑重。这里的爱情属于主角之外的人，讲述仍肯给它完整的光彩。因此，有偏爱的叙述不等于只准主人公拥有值得珍惜的生活。


<a id="chapter-28"></a>

### 第十七幕：悲剧舞台

阅读范围：第 1—216 段，章节 ID `7933e19a-64cf-4278-b6bf-3dfd1a141efc`。

第 10—28 段写楚子航反复查看旧新闻，父亲消失而他成为最后的遗留；暴雨的牢笼不是单纯的痛苦意象，他自己也不肯离开。对感情的迟疑又与寿命相连，不能只把他解释成不会恋爱的木讷人物。第 50—81 段网吧高手认真享受被打败和学习，旁观者的生活兴趣仍有具体内容。

第 101—123 段路明非终于握住曾经渴望的手，却是因为陈雯雯来求他救另一个人。陈雯雯记得自己的共同生活，路明非没有这种经验，却仍点头。叙述既给她的记忆与恐惧，也写她看到路明非颓唐后对其能力的怀疑。她走后，路明非脸上的关切缓慢消退，像胶水一丝丝剥开；这个表情过程比直接宣布他委屈更充分。第 127—133 段，他承认恺撒求婚的苦心，同时无法阻止自己的难过。

第 137—188 段小魔鬼先陪他淋雨，再用火柴与生命的交易，铺开一场越来越激烈的独白。路明非逐渐发现对方也在悲伤，并接住扑来的孩子；但第 189—209 段立刻写暴力快感与他自己的恐惧，理解不等于洗去伤害。第 211—216 段又揭出受袭女孩并非陈雯雯。前面随人物感知写出的场面不能直接当作事实终点，更不能据此得出陈雯雯弃他而去的判断。

<a id="chapter-29"></a>

### 第十八幕：迷宫

阅读范围：第 1—380 段，章节 ID `5fd00d82-c865-4355-a12b-9c336289834f`。

第 5—88 段把耳塞、地铁、化石的意义逐次改写：耳塞既是师兄的照料，也使危险的声响无法被听见；看似不能上的鬼车实际保护乘客；美丽纹路里又藏着死物。路明非对自己的智慧很有把握，旁观者却知道其误解。叙述可以邀请读者替他接一句话，也可以让同一件东西改变情绪方向。第 32—43 段夜间商场的具体设施与正常保洁工作并存，而约饭成为楚子航流水般任务中难得不一样的一件事。

第 186—205 段短信、拖鞋、黑箱逐步带出关心，楚子航并没有先把体贴说完整，夏弥的误会与纠正都由动作条件产生。第 219—273 段高幂与女友牵手会减少逃脱筹码，仍愿意牵。他随后被揭出想赢走别人的机会，却最终交出自己的机会。赠花被转卖、牛排要打包的往事，让选择发生在一对有小脾气的恋人之间。路明非对高幂的判断必须随之修正。

第 283—319 段荷官突然会弃牌和讲电影台词，熟悉的喜剧语气在此变得阴森，不能将一切笑话都归为安慰。万博倩主动回到恋人身边，临走还抱怨他的前任关系；难得的美没有要求她先成为无瑕的人。她远去的脚步越来越快，路明非虽看不见，却想象她奔跑如独角兽，愿意认真看待与自己无关的爱情。

第 344—364 段兔子般的思路与笔直弹道般的思路解释两人的相处。关于重逢的漫画话题，走到没有朋友的童年，再走到想摸摸她的头；二人称的提问邀请读者靠近这种经验。随后的过夜误会又回到夏弥的说话方式，玩笑没有使此前的理解失效。

<a id="chapter-30"></a>

### 第十九幕：耶梦加得

阅读范围：第 1—395 段，章节 ID `34369d54-2471-49bc-a0af-4986d57df09e`。

第 5—26 段给恺撒与诺诺的爱情充分的光彩，连路人都乐于为他们让路；紧接的第 27—37 段则让路明非在黑暗里重述神话，联想到武侠、童年英雄幻想和无人等待的自己。长串胡思乱想被明确写成他支撑着走下去的办法。两边的感受都成立，没有用主角的失落否定另一边的幸福。

第 52—94 段龙从庄严威武的巨兽变成小心拿薯片、摆电视的孩子。瓶盖为何珍贵，电视为何轻拿轻放，都让其生活具有自己的价值次序。第 110—129 段他先将收藏藏在身后，战斗中电视碎片仍落到路明非身边：受损的是已经被讲述过的生活。第 141—165 段天使与黑龙的油画姿态十分鲜明，但后续事实又使这幅善恶图景无法成立。

第 193—226 段夏弥爱哥哥，也准备吞噬哥哥；楚子航没有让悲伤成为免除追问的理由。第 297—333 段以梧桐树、舞蹈、影院和水族馆恢复共同往事，她自称一切只是伪装，又承认观察中的同情。文字还进入她看楚子航眼睛时的感受，不能只按她的一句否认就宣布过去全无真实。

第 345—353 段两人先像要一直做仇人，随后钥匙被交出，最后只来得及道别。叙述写女孩被埋葬，同时明确留下她的野心与残暴。第 364—365 段楚子航给遗体盖衣服，路明非才发现自己看到的花瓣并不在别人的视野里。第 377—395 段对芬里厄吞噬妹妹、完成复仇的解释，须与下一幕第 349—354 段合读，不能停在此处作为最终事实。

<a id="chapter-31"></a>

### 第二十幕：凡王之血必以剑终

阅读范围：第 1—378 段，章节 ID `e89b5ae9-7e2f-40a9-a054-e98d6d332cd7`。

第 19—47 段在末日危机中仍写邻里送别、商场播音、网吧误以为需要提神饮料的生活。第 69—102 段诺诺自行作战，先前可笑的旅游团也成为留守者；他们的勇敢没有要求叙述删掉之前的二百五与快乐。第 118—122、338—343 段恺撒要求家族道歉，然后主动留下当诱饵，战后又明确欠的是帕西本人的人情。主动承担与服从利用被区分开来。

第 160—217 段诺诺打电话让路明非逃，路明非仍先想到生日的落空与自己被排除在外；他也反驳楚子航的爱情建议，认为师兄自己并未做到。直到找回生日短信，才重新判断诺诺做过的事。第 267—268 段补出小魔鬼的干预。这不是女孩忽然给出爱情回报，而是人物纠正了自己对已有关系的理解。

第 233—254 段楚子航仿佛被父亲接住，实际接住他的是路明非，背后又有小魔鬼承担撞击。关怀先成为身体之间的动作。楚子航解释自己曾看见路明非看不见的孤独表情，又为过分的话道歉，仍以师妹的玩笑收尾。路明非最后答应交换，理由并不宏大：不愿仅有的人与事失去。

第 270—322 段对权力的陶醉、华丽的杀戮与审判得到充分展开，不能把全书声音净化成安全的柔和。第 349—354 段却推翻先前解释：芬里厄没有吞噬妹妹，只将她藏在嘴里，仍叫她醒来陪玩。故事已经发生许多变化，他却不懂这些，只带着她往外走。路明非嘴上仍刻薄，眼泪已经落下。

第 365—378 段救援地铁的到来引出连续而热烈的英雄想象，最终落到粗直的欢呼。路明非劝师兄活下去，先说绩点、女朋友、一起得瑟，再说自己朋友不多。楚子航握着夏弥钥匙的手终于松开，这个动作承认了他没有说完的感情，也使此前坚持划清身份的说法显出无法穷尽的部分。


<a id="chapter-32"></a>

### 尾声：每个人的心里都有个死小孩

阅读范围：第 1—89 段，章节 ID `f4c83789-6ad4-4dfe-8261-469edd2ffce6`。

第 15—39 段给大难归来的生活保留普通的误解、吃喝与玩笑。路明非祝福复合的两人，随即想到柳淼淼是否难过，故事并未把这一对的圆满写成所有人的圆满。芬格尔关于伴郎的笑话仍会使路明非不快，不能一律解释成保护情绪；而他饿时想起夏弥会带吃的来，使离去的人留在一项日常期待中。

第 41—58 段旧房附近有人炒菜、教育孩子，老太太惦记买房，世界没有统一进入悼念。楚子航有能力打破门锁，却仍觉得门沉重。窗帘、过期酸奶、收好的校服、像松鼠般并排的袜子和落灰的内衣，都让那个声称自己不存在的人重新具有生活。叙述从这些物品生出关于孤夜的推想，并以人物的问句保留理解的限度。

第 59—66 段楚子航重新听见夏弥谈孩子的话，从当时的冷硬中理解到孤独。她对空房说回来了，呼应第十六幕中的返家场面。他最后在这里完成每日回忆，又增加几件不愿忘记的事；没有重逢，但记忆的习惯已改变。第 74—78 段肯德基先生解释帮助弱者像在帮助自己，这与多个角色的行为相互印证，但仍是特定人物的说法。第 83—89 段家族对婚姻的控制继续存在，不能以关怀的主题替全书消除支配与算计。


## 第三部前传：冰海王座

<a id="chapter-33"></a>

### 楔子

阅读范围：第 1—10 段，章节 ID `84cc4012-6563-48c6-b24d-291229f8283b`。

第 3—8 段黑蛇毁坏建筑、打碎铁门，雷娜塔却不是惊恐而是期待。叙述先借毁灭的壮观吸引目光，再让自由成为孩子对同一场面的理解。教堂与魔鬼的符号没有替她决定谁是救援者；庄严的黑蛇也并不迁就她的每一次亲近。宏大的威严与小小的愿望从开端就彼此连接。

<a id="chapter-34"></a>

### 第一章：钦差大臣

阅读范围：第 1—80 段，章节 ID `f3b091a7-3349-4aec-aa56-d5a46486eeef`。

第 6—21 段先以阳光、补给船、暴雪与来客的举止建立极地生活。男人的体态、威风和军事工业的力量得到真诚欣赏，点烟与赠打火机又使能力进入很具体的观察。第 25 段衰老面孔像逐渐剥落的壁画，审美并未先按善恶分配。

第 50—65 段孤儿院似乎照料周全，博士像父亲，女孩辫上的黄色蝴蝶使环境显得暖和。第 68—80 段却从雷娜塔的经验逐项改写这些印象：撒谎与不哭是避开责罚的办法，小窗的设计用于囚禁，蝴蝶是惩罚标记。这里的叙述不是先给一段温暖再突然转暗，而是让同一物件在不同处境中暴露不同意义。

第 71—75 段她所期待的自由很具体：读书、拿面包、想停留多久就停留多久。毁灭世界的黑蛇对她有吸引力，因为眼前世界首先是一座牢笼。这个孩子的愿望有自己的生活依据。

<a id="chapter-35"></a>

### 第二章：末代皇孙

阅读范围：第 1—153 段，章节 ID `1aef4415-0218-4ea4-82f4-77c2dcc4e0f0`。

第 16—31 段通过隧道里的年份、距离、姓名与军衔，让漫长施工成为被消耗的生命。叙述理解工兵对未知的恐惧，邦达列夫却在死者痕迹旁自拍；轻佻在此显出人物的冷酷，并非必然让人亲近。第 32—38、115—129 段以历史传闻和嵌套讲述构成神秘感，封门者留下的自我说明又被后来的故事改写。这些历史、宗教与科学说法在本文仅作为小说叙述材料，不据此认定现实事实。

第 48—50 段认真欣赏冰杯、烈酒与礼服，第 94—99 段认真描写龙骨的雄伟。反派的审美并非假装有品位，残酷也不妨碍他们欣赏美。第 137—153 段关于能力、价值与回报的高论最后落到孩子的身体上，必须结合其实际用途理解，不能抽出几句激昂的话当作作品的普遍主张。

<a id="chapter-36"></a>

### 第三章：零号

阅读范围：第 1—171 段，章节 ID `d3ba6084-e724-40b8-aa22-49e82a3f8172`。

第 3—20 段雷娜塔既依赖布熊守夜，也会偷偷扔墙皮逗睡着的孩子，巡视夜间走廊像小女皇。叙述给受苦者留下调皮和兴致。无人回应的求救使她绝望，黑蛇打开门又使她重新相信有人会听见；希望被讲得十分直接，并不因救援者具有魔鬼形象而撤回。

第 31—76 段她先给受拘束的男孩捧水，再慢慢接受朋友的名分。她不舍得赠送布熊，也不认为刚认识就足够亲密，这些顾虑没有被批为不够善良。零号的眼神使她想起被杀死的小海豹，比喻由她确实经历的失去生出；而她听不懂的话，后来又被识别为书中的戏剧台词，孩子当时的理解与后来的认识并列存在。

第 89—123 段零号的讲述使她对成长的羞耻有所松动，牵手时的伤痕又让她第一次认真在意另一个人的痛苦。没有镜子看见自己的哭，与有人为自己哭的关系，使孤独成为可感知的经验，随后才扩展为冰川与雪崩。第 153—171 段保护计划却使用了会使她恐惧的暴力表象，护士的羞辱也真实发生。后文解释用意时，不能顺带删去这段恐惧。

<a id="chapter-37"></a>

### 第四章：誓言

阅读范围：第 1—163 段，章节 ID `d2c91e17-bd6b-457c-813a-4587f6a04f9f`。

第 20—22、137—145 段博士先因喜欢一朵鲜活的小花而留下雷娜塔，后来因将去温暖的地方而认为不必带走她。同一个比喻完整暴露了偏爱中的占有和可替代性：她的存在取决于对他的用途。人物说话温和，并不等于叙述在为他担保。

第 47—98 段，枯花、金箔、黑蛇的舞蹈和屋顶暖气共同构成两个孩子的夜游。遥远世界的壮丽与烟囱的实用温暖并存。雷娜塔说父母不管她，她仍想他们；零号自信可以取代，女孩却知道并不一样。她把他叫小海豹时，读者知道这个称呼背后的记忆，零号自己未必明白。

第 102—118 段逃亡誓言得到郑重表达，紧接着却是成年人按用途挑选孩子。第 162—163 段零号同样在背后限定承诺，只愿带她到她失去用途为止。此处特意保留保护者与利用者之间令人不安的相似，不能预先将前者的一切解释为纯粹温柔。

<a id="chapter-38"></a>

### 第五章：燃烧的圣诞夜

阅读范围：第 1—183 段，章节 ID `16bdf89d-6572-409a-8d14-f5fbfade7afc`。

第 2—23 段的暖气、衣服、食物与升学期待，使庆典有真实的诱惑。第 24—39 段逐项准备工具、武器和雪橇犬，后续逃亡依赖这些已经发生的行动。第 51—58 段策划者将普通人的愿望说成低贱和愚蠢；第 164 段叙述却直接把他们杀死孩子的行为称为屠杀。角色的强者论与讲述的判断并不相同。

第 69—120 段停住的钟、封死的门和压过呼救的音乐，将节日变成牢笼。文字贴近雷娜塔受侵犯时的恐惧，也留下救援后的迟发恐惧。零号能挡开施害者，却不能靠声称她没有损失来使眼泪停止；后来逗她笑与陪她跳舞，也不等于前面的伤害没有发生。这里既有对女孩的维护，也有保护者自身粗暴、占有和缺乏理解的一面。

第 130—176 段无所不能的零号在现实中需要雷娜塔带着逃走。她自己也想被抱住，却因这时更有能力而尽力保护他，关系由等待救援转为彼此承担。第 167—183 段雪橇犬寻找母亲、救援同伴，黑蛇则在离别时仍为她打开道路。希望通过先前建立的关系与行动兑现，不只是临危出现一句鼓励。

<a id="chapter-39"></a>

### 第六章：王的裁决

阅读范围：第 1—119 段，章节 ID `8034dd42-311e-4982-aaf5-65c8fc5d0275`。

第 23—33 段逃出牢笼仍不意味着知道去向。零号没有醒来，雷娜塔只剩狗群陪伴；危险出现时，她不曾计算这样做是否高尚，只想让同伴逃走。第 37—46 段飞行员想到自己的女儿而迟疑，随后仍决定执行杀戮。短暂恻隐并未取消其选择的后果。

第 38—67 段雷娜塔想靠近零号，又怕暴露他，最终独自留下。她的誓言进入一个代价明确的动作，而零号原先按用途计算的誓约因此受到冲击。他承认自己是坏人、讨厌负债，重新缔约时却仍保留用途条件。这并不是保护者忽然变成无条件良善的人。

第 47—76 段叙述明确偏向这个尚未体验爱与幸福的生命，能力觉醒却没立刻使她获救。零号最后以她等了一生的生日礼物来质问追杀者，将极小的个人愿望抬到与军事力量对抗的位置。第 72—119 段又把救援写成宣示拥有、行使权柄与残酷裁决；它的壮丽与占有同时存在。

<a id="chapter-40"></a>

### 第七章：新约

阅读范围：第 1—176 段，章节 ID `e223b244-20f5-4101-a7fd-e07ff8228737`。

第 15—73 段父母的争吵、攀附与两次选择，逐渐让家庭愿望失去依托。零号的杀戮既被他说成不让雷娜塔难过，也牵涉自己无法兑现承诺的难堪。他没有将事实交给她选择，随后用谎言安排解释。不能因为他确实照料女孩，就把这份支配删去。

第 87—114 段获得能力、衣服、舒适生活与身体恢复，都没有使雷娜塔不再怕被丢下。车站的两杯热咖啡和先搓暖手再摸头，是很具体的照料；但零号越来越像权力掌握者，反复强调她必须有用，也是真实的距离。第 129—139 段他谈南方鲜花时又像孩子，宏大的逃亡落到雪里走路、脚上血泡与背着同伴前行。

第 152—176 段谎言被识破后，零号详尽解释父母不值得，雷娜塔仍为不被爱而哭。叙述直接承认能力不能使心无懈可击。零号不耐烦地宣称不需要爱，并没有让眼泪停止；女孩看着他的恼怒，又觉得他像个孩子。最后不是一句道理解决悲伤，而是带着占有意味的新名字、简短应答和继续背着她走。照料、依赖、残酷与未被解决的难过共同留在结尾。


## 第三部正传：黑月之潮（上）

### 第一章：世纪婚礼

阅读范围：第 1—78 段，章节 ID `c3c541d7-2a8a-46f3-bc0e-d2f8ffe10c68`。

第 6—25 段对婚礼、金钱、性别与身体的说法颇为粗直，不能概括为对所有人的温柔。婚礼事务所的本领通过空投教堂、移动冰山等具体方案逐层展开，昂贵不是一个孤立标签。策划师根据新娘身材猜测她如何获得爱情，属于这个人物的判断，叙述随后让他的多次猜测落空。

第 29—48 段策划师误以为客户追求更高的品位，实际恺撒仍想以极其夸张的方式向全世界炫耀自己娶到她。虚荣被直接指出，而海上航行、不同婚纱与夕阳中的笑容仍写得令人向往。调侃没有要求把愿望里的真情撤掉。

第 50—69 段双方继续用各自的现实理解同一计划：恺撒相信自己与新娘的战斗能力，策划师还要考虑自己的妻儿。好笑来自持续展开的分歧，并非只在华丽描述后补一句讽刺。策划师最后也觉得计划有些可爱；第 74—78 段未解释的日本之行、尚未求婚与诺诺失踪，又使热闹留下新的疑问。

### 第二章：无解之结

阅读范围：第 1—195 段，章节 ID `2212d5af-3532-4ee8-ab02-3200ed9b415e`。

第 3—53 段从楚子航每天给母亲写饮食、课程的邮件展开。真实校园正在爆炸，师长们仍上网斗嘴，邮件中的美化与论坛中的混乱形成长时间并置。楚子航并不只是冷静能干的人，他细致安排母亲能够看到的生活，让她安心；母亲的粗心和他对她的照顾也同时成立。

第 75—117 段用夜宵中不好开口、推过去的煎蛋与柳橙汁写楚子航的关切。旁白知道他把命交给别人也未必陪人闲聊，所以此刻特意来找路明非才有分量。恺撒的自负被调侃，他对诺诺的忠诚却得到承认；路明非痛苦，也不因此拥有破坏婚礼的理由。亲近主人公不等于替他的愿望判胜。

第 123—164 段没有把楚子航的励志故事作为最终答案。他练剑、反击、得到母亲维护，路明非却在类似冲突后被迫道歉，并再次确认自己可能无处可去。两人的经历使“勇敢”成为具体处境中的问题。路明非醉后的性别概括带有怨气，不能直接当作作品认可的社会事实；叙述者对痛苦的理解也不要求认可每一句话。

第 168—178 段楚子航留下钱，让服务生不要打扰路明非睡觉，自己又摸到夏弥的钥匙。他也有力量与希望无法挽回的事。旁白另讲一小段师兄劝学弟旅行、自己却从未成行的故事，把劝告背后的遗憾说出来。第 179—195 段则揭示路明非正在付出生命，修正他对自己的懦弱判断。路鸣泽搂护他，又故意用婚礼刺激他、提出杀死恺撒；亲密与支配在同一动作链中存在。

### 第三章：战鼓之心

阅读范围：第 1—135 段，章节 ID `5976b956-43fd-4256-9b36-766f02c2f04d`。

第 3—26 段的笑话有持续发展的局面：香水被描述成饭菜，末日避难计划因全是男性而受阻，补救方案又通向女生宿舍。人物会回应、修改和坚持自己的逻辑，幽默不是旁白在信息段落结尾附加一句吐槽。清洁癖、垃圾食品与工程师的自负共同构成这群人的生活。

第 28—38 段在危机前认真写昂热每年重访酒吧、与老调酒师寒暄的享受，随后让龙的心跳变成战鼓，让他握紧折刀。享乐者与战士是同一个人，不需要删掉前一种状态才能获得后一种威严。

第 69—117 段的技术会谈始终通过人物行为推进：研究员用笔和拟声表演爆破，昂热打断他；点头摇头无法沟通，昂热索性捧住对方的脸；一句口头感叹又被误听成亲自下潜的决定。民族与科学说法是小说中的表述，本记录不把它们转写为现实知识。第 118—135 段众人用连续拥抱亲吻逃避出差，最后才落到日本分部如黑洞般的危险。章节允许滑稽和不安各自充分展开。

### 第四章：黑海白月

阅读范围：第 1—99 段，章节 ID `f0c29781-fc3e-45b1-9c4a-26a0fc2008bf`。

第 3—12 段先给出冰海与白月的宏大景象，再让围巾、手炉和酒改变路明非对景色的感受：身体暖起来，他才觉得并肩钓鱼也好。美不是悬在人物之外的形容词。路鸣泽用自己也需要这些东西解释照顾，建立兄弟之间的相似感。

第 18—37 段区分能继续生活与不再难过，也区分得到一个人和获得她的爱。路明非并未因为拒绝强制占有而失去欲望或变成端正说教的人，粗话、色心和严肃判断仍在一起。第 39—72 段他先舍不得路鸣泽离开，又识破业务员式的苦肉计，最后丢下温暖的物件。真切的照顾不使诱惑自动正当；“不心动”逐渐变成“不能心动”，也保留了选择的困难。

第 74—81 段把钓起巨龙、讨论烹饪、月光化作洪水连在一起，奇观在日常口气与恐怖之间变化。醒来后芬格尔将离开、诺诺将结婚、路鸣泽将休假，孤独来自关系整体的松动。第 85—99 段又回到袜子、词典与替他收拾好的行李。写真从欲望对象转向一个人的童年和成长；其中也保留男性占有欲与路鸣泽的诱导，不能只提炼成无条件赞美的爱情观。照片里反复独处的诺诺进一步拥有了需要理解的过去。

### 第五章：日本分部

阅读范围：第 1—398 段，章节 ID `1132fb7d-1439-4c3d-856b-5e2ee13186d7`。

第 2—64 段先跟随医生的恐惧，让他像无辜受害者，随后揭出他的罪行。执法人用儿歌和施工口气谈酷刑，产生的是残忍的黑色幽默，不能一概解释为替人物保留温度。医生的自我辩护被打破，暴力实施者也并未因此变成温和的人。

第 69—148 段进入樱井明被长期隔离的成长：他给云起名，第二天云走了，自己仍在原地。叙述给他的孤独很大篇幅，也让他在听女孩讲猫时仍然谋划伤害她。女孩的故事逐渐进入他的想象，他自己也觉察到这一变化。有关自闭症的解释属于小说表述，本记录不将其作为医学知识。

第 184—231 段他在凶狠的内心辱骂中生出怜惜，最终让女孩离开；变异的手不能拥抱，形成具体的不可挽回。但他又明确说不后悔杀害那些女人，源稚生当面反驳。叙述愿意承认他残存的人性，却不以这一次放手注销其他人的死亡。蛾与光的比喻不仅表达孤独，修辞超出樱井明平常能力这一点也成为疑问。

第 265—291 段揭示女孩是成年执法人的伪装，猫的故事并不存在。樱井明被触动的感受仍然发生过，但读者必须重看相遇。源稚生先以一见钟情解释放手，练习本中的少年冒险故事又提示另一种理解：他舍不得的也可能是过去的自己。源稚生口头要求不必理解猎物，随后却重复了对方的蛾与蝴蝶之喻，行动和语言没有完全服从他的职业要求。

第 298—368 段源稚生想休假、喜欢铁路终会通向有人处、只为取暖看打刀、梦想卖防晒油，让强大者有不想继续承受的生活。第 370—398 段又让弗罗斯特从雍容的权贵立即变成担心恺撒安危的长辈。身份的威严反复被日常愿望打断，但其中的牵挂并非笑话的牺牲品。

### 第六章：王牌组合

阅读范围：第 1—237 段，章节 ID `aebf7b47-0e1a-4b2f-858c-9c83b71d32ca`。

第 14—44 段借恺撒想象同伴睡相、三个人对日本的不同期待写关系。恺撒努力礼贤下士，也确实把别人当作下士；他欣赏自己、想接近同伴和难以忍受楚子航，可以同时成立。路明非望东京灯火想到少年时仰望的城区，已经获得身份与地位，却仍希望某个人看见自己。星辰意象沿着这一愿望延伸，随后文字直接承认他尚未真正想通。

第 58—107 段不是简单的本部英雄压倒日本高手。机师将源稚生的不动看成赌命，叙述随后说明他相信樱的安排；源稚生以为对方故意无视威慑，读者却知道楚子航只是戴反美瞳，其他人也没理解刚才的危险。多个误读持续作用，产生笑意。豪华礼物、替同乡合并运送遗体以省钱的说法，也延续了每个人自己的日常语言。

第 124—185 段对于日本分部的残酷行为，源稚生与路明非的尺度明显不同。前者觉得可以处理的小事，后者会想到电影、购物与法律，越听越不安。叙述允许这些比较充分展开，没有将所有人写成共同认可暴力的冷酷团队。

第 188—229 段将持刀武士遇上挥扇跳舞者的想象延续到整场接待。源稚生以为赢得赌局就能恢复主动，恺撒却本来已经订好夜店，也真心欣赏樱的身姿与本领，忙着拍照修图。幽默来自相处方式与关心事项的不同；动作场面仍得到认真赞美，并未因好笑而丧失魅力。

### 第七章：黄泉之路

阅读范围：第 1—192 段，章节 ID `9ef8ea8c-0a4a-43d7-a394-d44365152477`。

第 29—48 段奢华接待既满足享受，也因三间卧室精确投合各人喜好而成为调查与监控的线索。恺撒举杯想庆祝，无人回应；他犹豫着是否邀请楚子航，最终收回手，给诺诺发出的短信也未获回应。叙述在路明非之外保留了另一个人的落空，未靠贬低情敌换取对主人公的同情。

第 59—83 段乌鸦为源稚生遮掩喝酒、提醒漱口，同时担心自己的前途。源稚生卖防晒油的梦想也落实为购买、研究产品的实际行为。随后他用手蒙住眼睛，试着体会蛾子的黑暗；原本可以写成英雄斩鬼的事件，在亲眼所见的死亡面前难以成立。他要求自己少想，恰好暴露了思考与职责之间的抵触。

第 84—121 段庄严家族会议被游戏占据，文本认真写招式与胜负，使人物的投入有具体内容。最后才揭示源稚生接过手柄赢下关键几秒。他让绘梨衣等开完会再玩，并答应陪她；部下对少主的赞叹，又转为对其酒量和撒谎本领的评价。威严、兄长的照顾与调侃并存。

第 133—192 段需要辨认演说和叙述的区别。橘政宗从被隔离孩子的可悲讲到消灭全部敌人，这是一次有方向的动员；不能因为话说得感人就当作作者最终判断。源稚生仍想到无法见到新时代的死者，却因不忍看养父孤独出战而投下赞成票，绘梨衣又因依恋兄长跟随。改变集体命运的选择来自具体关系，并未与演说的大义完全重合。

### 第八章：极乐天都

阅读范围：第 1—104 段，章节 ID `e1c8a33b-3b5a-4eb7-af4b-35c600128a30`。

第 3—25 段既渲染赌场的华丽与诱惑，也用妖花、红莲说明它危险的性质。真仲英树并非只有一个复仇动机标签，妻子、工厂、抵押、母亲留下的钱组成一段完整生活。第 27—50 段牵手的温暖和体贴的服务恰恰引向杀戮。人物被安慰与被引诱可以是同一个过程，不能见到温柔动作就认定叙述在赞许救援。

第 65—91 段认真描写歌舞伎之美，也写小暮为取悦男人付出的学习、疲惫与屈从。她在楼下掌握他人命运，在楼上却把自己的价值系于能否使一个男人安宁。讲述明确区分他的索取与她的感情，没有用美感消除关系的不对等。

第 98—104 段一张合照又被叙述者重新解释：看似搭讪其实在换包子，恺撒皱眉是因为缺咖啡。画面中的人拥有不等于表情标签的具体事情。男人从照片里看出路明非的悲伤与潜藏力量，则留下另一种理解他的目光，尚不能仅凭这一刻的欣赏认定对方是他的同路人。

### 第九章：源氏重工

阅读范围：第 1—221 段，章节 ID `dec58a03-3286-4e22-bb97-d812543b9a5c`。

第 3—28 段路明非用游戏道具理解参考书，用两房姨太太冷战理解同伴争执。楚子航看城市秩序，他看女孩，两个人认真凝视的对象和问题并不相同，旁白还继续讲出另一个类比。声音的活跃来自思路持续展开，而不是简单为每段添一个俏皮词。

第 35—76 段办公室的贷款、奖金、师生礼物、福利和组织管理都使用熟悉的职业语言，却与暴力业务相接。滑稽中含有阴暗，家族的福利也没有取消其控制。第 100—143 段茶道先被认真写得优美，再被三人误当成需要破解的较量；他们烫得不敢说话，源稚生却早已看出。最后又提到老人希望在漂泊后找到家，使半吊子的仪式不止剩一个笑点。

第 169—221 段地下工程的巨大与水流的美得到充分欣赏，深潜器又带出家族荒唐旧事。知道收藏动机可笑，不妨碍承认机器是技术奇迹。路明非关于古董可靠性的担心有具体理由，恺撒的购物计划也确实重要；同一任务没有把三个人改造成只谈使命的统一声音。

### 第十章：每只象龟心中都有一处温暖的水坑

阅读范围：第 1—285 段，章节 ID `960c685d-c827-4961-bc4a-ed8182214253`。

第 3—45 段盛宴、购物和名刀都获得具体描写，但人物未必按照主人希望的方式欣赏。源稚生认为三人不懂料理意境，叙述又说明恺撒确实吃得出美味。父亲留下的断刀让交流越过冷淡的表面，几人的家庭经历构成实际的共同话题，中途粗话和玩笑没有使这一联系失效。

第 47—70 段象龟比喻是一段改变理解的对话。恺撒先依据叔叔的表现，怀疑源稚生放不下权势；源稚生继而讲象龟被要求延续种群、自己却可能只想回到水坑的处境，让恺撒作出选择。恺撒已经说出自己要爬回故乡，路明非才指出他进入了象龟的想象。这个比喻让人暂时获得另一种生活，不只是给孤独贴上漂亮的名称。随后恺撒的出走建议也被认真写得动人，源稚生却仍然走不了。

第 104—205 段玩具店的女孩有攒大学学费、照顾奶奶的生活，混混有漫画、同伴地位与羞于承认的暗恋。路明非会主动端茶，也会借身边的权势发作。樱的威吓在路明非看来有姐姐式的照顾，在两个当事人看来却真能伤人。不能因为后来揭示暗恋，就将此前所有恐惧写成无事发生。源稚生也第一次意识到，习惯当作可靠助手的樱有自己尚不了解的人生。

第 207—263 段楚子航提出等雨，恺撒接纳速溶咖啡，游戏话题带出他的童年，并使飞机上的冲突得到澄清。握手时控制力量、离店时摘掉门铃，都用很小的动作写相处。笑话继续存在，但没有替代这些动作。路明非仍因自己的失落难过，伙伴的坦诚并不让所有人同时痊愈。

第 268—285 段离开玩具店后，刀压住的帮派冲突最终爆发。温暖的水坑仍不可抵达：一次调解、一个恋爱故事、几个人的友谊，都没有消除外面的利益冲突与暴力。源稚生的疲惫因这段实际后果而可信。恺撒道谢时仍保留冒犯人的口气，人物没有为了结交朋友突然变成圆熟得体的人。


<a id="chapter-51"></a>

### 第十一章：格陵兰阴影

阅读范围：第 1—211 段，章节 ID `b3826fbb-7b10-4467-b736-0d012741f737`。

第 51—112 段送药、抽烟和气管里的怪声，使施耐德的旧伤先成为当下相处的一部分，再进入救援学生的回忆。十一年前的苦难值得认真倾听，但第 122—162 段没有让这份苦难自动证明他现在的选择正确。曼施坦因直接质疑：被牺牲过的人，是否又在把不知道实情的学生送入危险？施耐德愿意一起付出生命，也不能结束这场质疑。关于噬罪者的宏大说法属于人物的自我解释，文本同时保留反对他的声音。

第 166—187 段副校长和儿子的通话转入煎蛋、房租、升职。父亲愿意听这些小事，儿子又急着催他留下的话，构成被错失过的亲情。儿子故作轻松，并不说明他从未在意父亲；父亲的爱也没有抹去他对他人造成的伤害。讲述允许同一个人既有真切的爱，也留下无法凭一句话结清的亏欠。

第 189—211 段楚子航在雨中的少年形象迫使施耐德承认，学生不是没有生命的武器。最后达成的合作保留了安全、尽力和不得已的条件。若只摘取前面的牺牲宣言，就会把一场尚有抵抗和限制的争论改写成作者对冷酷的赞许。

<a id="chapter-52"></a>

### 第十二章：亚种

阅读范围：第 1—300 段，章节 ID `9aae38b3-8afb-4709-9eb5-b9598acb8539`。

第 11—47 段磨刀、背手册、聊天和发微博都是同一次下潜里的行为，却各自对应不同的需要。路明非写下对花的感受，又改成炫耀，旁白替读者保留了已经被他删掉的心意。楚子航不回母亲的邮件，却逐封阅读，还想到给她带礼物；沉默造成的误解与沉默背后的在意同时成立。声音通过这些内外距离，使不善表达的人仍可被理解。

第 63—127 段摸头、收走游戏机、夜里背手册和后台的警告，把管束、努力与照顾落在动作里。恺撒并非天然无须准备，只是愿意表演得从容；揭开这层表演也没有否认他的勇气。绘梨衣受到疼惜，同时仍被当作兵器安排。麻衣与薯片的玩笑发生在实际危险之中，两人的工作强度和对路明非的担忧不因口气随便而消失。

第 152—193 段险情中，路明非将恺撒的迟疑想象成贵族的自我牺牲，随后才知道对方忘记密码。讲述会让人物先把生活编得壮烈，再以具体原因拆掉自己的误会。这种拆解针对当下的误判，不能反过来证明恺撒此前所有认真都只是笑话。

第 204—300 段深海鱼群、巨鲸和光点先被充分写出美感，捕食又改变了对同一景象的认识。漂亮不等于无害，拥有力量也不自然获得正当性。源稚生由海中的规则想到自己是否也是该被抹除的暴力，老爹则让他不必思考、由自己担罪。父子般的亲近与命令关系相互缠绕，不能把替人承担罪名直接当成正确答案。


<a id="chapter-53"></a>

### 第十三章：葬神之所

阅读范围：第 1—154 段，章节 ID `02d88e80-06be-4d51-b9bd-55df46765344`。

第 6—37 段玩笑、酷热与脱衣的狼狈，紧接着发现古城的震撼。叙述明确说明恺撒也需要说话来抵御心理压力，又认真赞叹古城经得起时间考验的美学。日常口气没有取消宏伟，宏伟也不要求人物先成为毫无杂念的专业讲解员。

第 43—51 段巨塔使路明非想起路鸣泽被钉住的幻象，历史遗迹因而也成为私人痛苦的入口。第 76—98 段施耐德要求返航，信号却被切断；恺撒基于相处中认识的象龟，选择继续信任源稚生。读者看见下潜小组不知道的信息，这使源稚生后来假传施耐德的命令不能被误记为教授的真实决定。先前建立的亲近感，成为信任被利用时的实际损失。

第 107—154 段恺撒仍想到任务后可以喝香槟吹牛，路明非仍会质问。发现不是只有一枚胚胎，又推翻了人物先前关于心跳共振的解释。叙述既陪伴他们探索，也让读者看见他们的知识和判断都可能不够用。

<a id="chapter-54"></a>

### 第十四章：王的血祭

阅读范围：第 1—93 段，章节 ID `d9d3b564-093f-4578-9f17-b20523f23794`。

第 12—27 段用午餐肉般的色泽、伤口和血管写出怪物的生理质感，麻衣又哀叹王成为另一位王的祭品。生活化比喻不必负责制造笑声，也能把恐怖拉近到可感的身体。

第 29—49 段源稚生没有说出激昂的动员辞，只能鞠躬。他的疲惫得到说明，象龟比喻延续到此刻的负重；与此同时，樱说明自己因为信任他，所以能利用别人对自己的信任杀人。摸头的温柔与服从的暴力出现在同一场对话里，不能只保留其中好看的部分。

第 73—93 段三份不同的遗言构成三种关系。恺撒愿意承认自己谈过别的恋爱、害怕婚后厌倦，又希望诺诺带着一件男式唐装继续旅行；真切的爱没有把他的虚荣、占有欲和恐惧净化掉。楚子航感谢继父，安排母亲继续生活，甚至不愿给母亲留下一段会被反复播放的煽情录音。路明非则想不到应当对谁说。讲述不要求他们用同样漂亮的方式告别，而源稚生正听见自己准备牺牲的人的声音。

<a id="chapter-55"></a>

### 第十五章：潜龙升空之海

阅读范围：第 1—337 段，章节 ID `d727683b-298f-4dc2-a256-a56e5fe1c2da`。

第 5—54 段明确揭示生还概率被隐瞒，隐秘改装还造成了未被自检发现的故障。恺撒用象龟的愿望反问源稚生，并不因对方也愿意牺牲就接受他的道理。他仍选择出舱，楚子航在他的眼中看见阳光：作品确实敬重这种骄傲，因为此刻它约束的是本人，让他先承担危险。

第 57—80 段安全索被比作血缘，恺撒的听觉带出童年里只有母亲理解的音乐，并展开一小段僧侣与红发少女相逢的幻境。幻境让他倒在肺螺中，却不使童年的感受变假。楚子航准备救人时，把欺骗指挥者、保全路明非的方法交代清楚，还主动解除幸存者的负罪感。照顾体现为替对方留下可行的活路。

第 138—205 段魔鬼的演说不能直接当作作者立场。路明非确实孤独、嫉妒，也有不体面的欲望，但他明确拒绝报复世界，拒绝把诺诺当作可抢夺的物品。他需要的不是把女孩关进牢笼，而是知道别人的幸福发生时，自己能在哪里生活。生日卡片又让魔鬼露出预先准备的帮助；帮助没有取消契约的危险，番茄酱恶作剧也没有让他变成纯洁的安慰者。

第 209—260 段救援的力量来自被改变的命运，文本对此有明确解释，不能全部归结为恺撒意志坚定。麻衣的血和一句无人听见的师姐称呼，让后台救援也有自己的代价。源稚生听到三人还活着，真切高兴并冒险启动绞盘；同伴讨论英语班、谁保护背后，保持了他们原有的相处口气。

第 272—305 段安全索进一步成为母子间的脐带，随后救援又被牺牲命令截断。源稚生想救他们，与他参与的背叛同时存在。留下的雪茄和对几天相处的怀念，使亏欠具有具体对象，却不能代替救援的结果。

第 315—337 段告别先落在认识彼此很高兴，随后进入路明非对红发女孩的误认。叙述让读者看见绘梨衣先举刀、再好奇、最后抱住他，而路明非只抓住诺诺的名字。黄色橡皮鸭来自绘梨衣自己的生活；她此时的行为不能被直接归并成诺诺的复制。被人没有放弃的感觉已经发生，但两人的认识仍然错开。


## 第三部正传《黑月之潮》中

<a id="chapter-56"></a>

### 第一章：风与潮之夜

阅读范围：第 1—172 段，章节 ID `674daab9-0fe0-4b62-b847-3560105b1db4`。

第 5—32 段官邸的庄严与昂贵被写得认真，随后的维修费、网上交易、猫主人却完全进入日常生活。木村浩不是可随意替换的接待者：他有职业骄傲、期待被赏识的心，也为自己守着空宅衰老感到虚无。讲述愿意花时间陪这个配角理解一件在他看来荒唐的事。

第 42—96 段木村浩从服装推断主人身份，从慵懒推断权势，都是他依靠职业经验作出的解释。撑伞时把自己想成武士，使章首建筑如黑武士的比喻进入人物行动。苏恩曦的从容得到欣赏，但她握住老人颤抖的手腕、让他按键，也将保护写成合作中的具体事情。

第 87—157 段对白海豚遭猎杀的描写明确带着怜惜，战舰又被拟人为决死冲锋者。苏恩曦凭布置应付危机，不是身体无敌；近距离袭击时，她也必须依赖下属的射击和木村浩的动作。第 159—172 段猫的反应揭开另一层身份误会，薯片与烟囱的玩笑延续她平时的兴趣和口气。危险结束没有要求人物以宏大总结谢幕。

<a id="chapter-57"></a>

### 第二章：浩劫的轮回

阅读范围：第 1—176 段，章节 ID `90628c5f-e527-4e31-8135-a4698e9bfa87`。

第 24—64 段庞贝跳伞登场，既不符合问罪家长的预期，也没有立刻进入父亲失去孩子的标准悲痛。美貌、茶叶判断和各类玩乐的经验确实受到欣赏，他的不负责任又被反复追问。对加图索家所谓仁道的讽刺尤其明确：碾压别人之前打个招呼，并不因此成为仁义。

第 79—146 段正事不断被木乃伊、语言和女友带偏。叙述不只说庞贝不正经，也解释为什么旁人容易被他带走：他谈这些事确实博学而有趣。转入灾难研究后，鸡蛋、方糖、建筑模型帮助听者进入想象，他还需要昂热在适当处追问。长篇说明也是人物之间争夺话题、安排听众反应的对话。

第 150—176 段庞贝带来情报和帮助，迫使昂热重估他对儿子的关心。他随即又用遍布世界的女友解释人生理想，还被自己进门时留下的降落伞绊倒。认真与荒唐都属于这个人；叙述没有要求真情出现后就永久收起缺点。副校长对学生的嘲讽也被昂热直接反对，亲近的朋友并不始终说同一种话。

<a id="chapter-58"></a>

### 第三章：老板

阅读范围：第 1—152 段，章节 ID `d19965da-039a-4ed7-99fc-ac57206c8104`。

第 8—10 段直接写出苏恩曦心里的言情小说，女孩、男友、跟班各有台词，故事还继续拐到假装过平民生活。她对豪华环境的淡然因此有了不同于木村浩推断的原因：实际掌握资金与权力，未必能满足她的生活趣味。讲述不是只给她贴上宅女标签，而是真陪她想了一段。

第 18—65 段麻衣看似妖娆的步态实际来自重伤，外部美感需要内部身体经验重新解释。苏恩曦让她念男友名字，既在救命，也会真的为八卦吃惊；她怕失去朋友时想到的，是以后不再唠叨公务机和超支。麻衣恢复后仍损她，熟悉的刻薄反而证明朋友回来了。生死没有将两人的关系改写成陌生的庄重口气。

第 71—127 段老板准备酒、食物、和服、暖浴巾，愿意等助手舒服后见面，这份体贴有具体偏好和节奏。但说到辞职，叙述也明说她们没有可结束的雇佣合同，只有契约。温柔、喜爱、占有和安排他人命运在他身上并存，不能从准备暖袜直接推导出无条件的善意。

第 135—152 段关于绝望、幸福与魔鬼的说法，是老板理解并控制路明非的方式。他看过戏剧结尾，因此连美好的初遇也会感到悲伤；他希望路明非开心，同时希望对方继续沉睡。他说无人能替代另一个人，与楚子航遗言中可以替代的说法形成分歧，随后又同意安排新的恋情。文档需要保留说话人、目的和随后行动，不能只抽取其中最响亮的一句。猫的亲昵与被叫错名字的前情相接，最后又回到他对拥有物的记忆和感情。


<a id="chapter-59"></a>

### 第四章：檀香味头发的女孩

阅读范围：第 1—800 段，章节 ID `7595f6a4-4e6d-46b3-9d1a-0de1f5a97ba9`。

第 1—23 段恺撒从街上的食物气味里感到回到人间，又被老太太当作落魄的人塞了面包。他以为自己在宽容地回应平民的要求，却不知道自己的外表已需要别人照顾。网吧对他与路明非也完全不同：一个不懂为何需要专门上网的地方，另一个曾把付费独占两小时的座位当作自由。江湖被翻译成骑士集会，误解里有各自生活的来处。

第 103—185 段麻生真记得的是风雨中让她安心的人，恺撒起初却因工作场所而躲开她。她解释擦鞋、读大学与照顾奶奶，并不是向读者提交清白证明，而是在努力挽回一个在意之人的看法。文本直接指出穷不是错，恺撒做了蠢事。玩具店辞退她，又说明上次帮助并未带来童话般的完整善果。她谈野田寿时看见他的努力和好意，不只把他当衬托贵公子的失败者。

第 180—217 段善良的称赞带出母亲和恺撒童年的三次反抗。他对真提供奖学金，照顾奶奶的需要，也明确提到未婚妻。但他的想法仍有贵公子的优越：可以施舍一次落日，把容易理解的女孩看成薄薄的宣传页，还会被自己的潇洒打动。讲述既看见他的好意，也让这些不够体面的判断留在场内。

第 261—380 段虚拟人格会拿合照打趣，路明非相逢时能自然称赞真的衣服，恺撒却一直尴尬。逃亡中的说笑有各自的用途和局限。路明非越怕越要讲烂话，叙述还用童年打针时的笑话给这习惯一个生活依据。换衣时真整理领口令他动心，恺撒帮穿袜子又打断他的遐想；可笑的处境没有取消照顾，也没有要求每个人感动得整齐一致。

第 401—519 段刀术交锋最终认出熟人，旧日竞争成为实际可辨认的默契。三人一边限制杀伤，一边会下重手、踩伤人、为报复痛快；不能把没有立即杀人改写成完全无害。真对骑士的期待被叙述认真呈现，又说明他们并非应召来救她，而是被追赶回来。随后恰是她看出铲车盲区、带人穿过员工通道。恺撒把女性视作需要保护的花瓶，与她实际救他的能力形成距离。

第 487—552 段破败更衣室和隐蔽通道，补出了客人眼中性感服务背后的工作环境。真临危仍塞进几张工资和小费，知道这几个男人没有钱。小黑猫遭射杀时，叙述明确说它本该是被主人搂在怀里的宝贝；动物的死不是纯粹用来解围的机械机关。楚子航认为暴徒不会再骚扰真，后来事实证明这个判断不可靠。角色说得笃定，不等于叙述担保结果。

第 598—692 段三人回去救真，谈判、潜入和突击都有具体安排，但仍失败。恺撒如命定骑士般明亮的一段，贴近女孩终于不再害怕的感觉；随后坠落与车祸打破的正是这种期待。旁白没有因此嘲笑她愚蠢，也没有把恺撒补写成爱上了她：他们没有充分了解，承诺的奖学金也未兑现，可她不该为这份短暂的憧憬付出生命。童年三次反抗随之重现，第二人称把恺撒带回那种始终没有改变现实的无力。

第 693—723 段路明非不能跪下，不是因为忽然取得抽象的英雄觉悟，而是刚刚看见同伴和女孩遭遇的一切。他的烂话在这里成为主动刺痛施暴者的反抗。恺撒驾铲车出来救人，学院为他鼓掌，叙述认真承认这一刻的担当。

第 733—800 段恺撒重新拿到力量后，却用实弹造成残疾，并接受家族关于犯错应付代价的解释。场面明确写出暴力反过来压倒暴徒的力量，不能为概括温柔而删掉这一面。路明非挡枪又建立在对目标的误判上，但不因此抹去他的行动。抚恤、追查、惩罚都开始了，真仍然没有回来。这个章节让读者认识过她的生活和主动选择，分析也应保留这些，不能只把她写成男主角成长的成本。


<a id="chapter-60"></a>

### 第五章：荆棘丛中的男孩

阅读范围：第 1—618 段，章节 ID `fa77aa43-5c98-45cb-9500-0dfa940e7754`。

第 1—143 段绘梨衣会看出哥哥不开心，想让他赢，纸上告别也有她自己的亲近方式。源稚生从少年渴望扬名，到不愿再以正义之名杀人，变化由年龄、旧事、海鸥困在城市的观看连起来。橘政宗许诺让他远走，又要求做完最后一件事；父亲的爱、家族的需要与限制没有在这里分开。源稚生认他为父是真实感受，不能据此认定父亲的全部解释可靠。

第 145—180 段柜员熏并非见到俊脸就失去判断。她做了多年服务工作，见过许多好看的人，真正打动她的还有昂热的言谈、音乐与自在。她害怕黑帮却仍放旅客离开，短暂出场也有自己的处境与小小勇气。

第 235—303 段橘政宗根据资料解释昂热，将他的亲密关系一概说成利用。文本同时提醒档案有拼接和未必准确的部分，读者不应把人物提供的履历直接升格为全知事实。源稚生给部下安排法国房产、让樱代管财产、答应免费拉面，照顾落在这些符合各人习惯的事上。夜叉讲儿时被父亲拐着带走、长大才理解雨伞的故事，让父子亲情有身体记忆，也影响源稚生看待自己的父亲；它并不担保所有父亲都值得信任。

第 304—530 段昂热的压倒性力量、刀术之美与教育者身份，都受到认真欣赏。他也羞辱犬山贺，打断对方的请求，公开其痛苦历史，借悲愤逼出更强的攻击。犬山贺的畏惧、屈辱、嫉妒与敬仰并存。后文承认师生之情，不能倒过来删掉这里的强迫，概括成毫无伤害的慈爱。

第 531—555 段十六岁的犬山贺保护才认识的妓女，是因为她们的处境重新刺痛了家破人亡的记忆。昂热把施暴的水兵打倒，给女人手帕，也在后来坦承利用学生控制日本分部。可是他此次来访的目的又只是看看阿贺。橘政宗所说的纯粹工具关系因此不够解释实际行动；利用是真的，牵挂也没有被利用取消。

第 559—579 段犬山贺拔刀扑来，先被写成可能的进攻，随后才说明他在保护心脏，让自己能活着替老师挡弹。他请求拥抱，昂热答应、摸头，并相信他不知道暗枪的事。直到最后昂热才明白学生一直在设法警告自己，强者也有来不及理解的人。叙述用一生才懂老师的话作概括，却又让那个满怀怨念的学生、来迟的理解和此前的伤害一同留下。

第 578—618 段旁白明确说犬山贺做完了他能做的一切。昂热一边骂愚蠢，一边想按平他眉间的皱纹；女孩们停工、夜总会歇业，把死亡扩展为关系中的空缺。随后的砸车有暴怒，也有司机计算修车费、最后嫌破车不肯搭乘的笑处。笑没有替丧失收场，只让这个仍会粗鲁生气的人继续活在丧失之后。


<a id="chapter-61"></a>

### 第六章：男人的花道

阅读范围：第 1—418 段，章节 ID `72bab295-898c-4e43-8ddb-4ebcdcb976ca`。

第 1—40 段所谓天堂和美女陪浴，最终是恺撒给昏迷的路明非烧水。性别误认与奇装打扮带来笑，六十多个小时的照顾却是真的。路明非由一生只有少数重要的人，想到恺撒的订座、买单、出舱，也解释为何不能接受魔鬼抹掉这个情敌。对方的虚荣和颐指气使仍在，没有先改造成完美朋友，才允许珍惜他。自骂此时不该伤春悲秋，是情绪中的转身，并未否认刚才的感受。

第 51—175 段牛郎店被写得荒诞、性感而热闹，身材与异装也遭到直白嘲弄，不能统称善意幽默。藤原前辈的履历和另一种威严，随后修正初见时的轻视。广告车像疲惫登山者遇见熬牛肉的小店，给逃亡者以真实的安慰；后文揭示它是有意布置的接应，不取消被收容时的感受。恺撒珍惜自己赚的钱，又擅长把经历包装成心理服务，既能做事，也会给自己找漂亮说法。

第 180—209 段楚子航指出恺撒留下是要报复，牛郎生活里的快乐并不意味着已经忘记麻生真。切到昂热，他不愿参加熟悉得疲倦的葬礼，却在远处点亮打火机，让送葬的人看见。他说没有时间哀悼，叙述仍给了读者这次目送。

第 238—312 段三人回答呈现不同的经历与表达方式。恺撒谈海，楚子航谈顾客，路明非说得结结巴巴。不能将其中对女性和心理的泛化判断当作可靠知识或作者的统一主张。尤其楚子航所谓压迫式营销，后面被苏恩曦直接指出是在榨取女性的钱；店长赞成，并不足以消除问题。路明非心里想到的爱，比他实际说出的二三十字更完整，店长的大段发挥则另有原因。

第 317—407 段读者看见幕后保护者，才知道偶遇、合格与花票都有人安排。店长承认对路明非的赞美违心，却又提出自己的花语解释；苏恩曦、酒德麻衣轮流质疑，麻衣最后选择实际出钱保护。店长关于女老板驯服美少年的故事只是猜测，和三十辆广告车这一实际安排不能混为一谈。叙述会让人物的解释连贯展开，未必每句都标注他在猜，分析需要保留上下文。

第 408—418 段最终回到路明非独自在露台上的感受。他仍认为源稚生想卖防晒油是真的，却又确实被对方抛弃。小黄鸭让救援成为摸得着的事实，也带出他回答问题时真正想到的诺诺。强吻、替换、赴死属于他重写往事的想象，并未实际发生。此处不应只摘取店长的爱情定义，跳过男孩的羞惭、渴望和对自己退缩的厌恶。

### 第七章：樱花与红莲

阅读范围：第 1—192 段，章节 ID `68b72d0e-c1de-4111-ac17-52dfa015c950`。

第 1—36 段盛装迎客与火灾并置，樱井小暮把最后的礼仪留给末日。十二单、血色和服、燃烧的蝴蝶都很美，地下室曾有血迹和隐秘暴行也没有被抹掉。战争的说明区分投靠的帮会与无处投降的鬼：前者可以改换门庭，后者面对死亡或终身监禁。所谓以最大暴力终结所有暴力，是此时权力扩张中的判断，需要与实际的伤害一同读。

第 53—110 段源稚生因歌声走进火场，愿意许诺自由与更好的生活，小暮却追问自己同类的命运，以及他是否有资格逐一询问被杀之人的遗愿。她不配合一个令人宽慰的临终和解。乌鸦把龙化的身体当作可以继续伤害的恶鬼，樱却从狰狞的眼睛看出妩媚。最后贴近膝头的动作，也应结合此前认错人及后续兄弟线索理解，不能擅自写成她原谅了源稚生。

第 111—126 段父亲拒绝收尸，源稚生仍说她是他的女儿，并给她盖上风衣。回到车旁，他看出樱的烫伤，涂药、剪去焦发，也给乌鸦点烟道谢。照顾不只留给情爱对象，笑话和嫉妒又让几个人的关系保留具体性格。

第 128—175 段源稚女在街头耐心配合陌生人合影，在车里却可以立刻拔刀。王将用食物解释所有死者，又以女性的爱推算小暮会留下；这些冷酷解释遭到当面反驳。王将认为源稚女只是任性地为一个不重要的女人发火，叙述随后进入源稚女自己的回忆，证明这种判断没有说尽他。

第 180—192 段源稚女直到小暮死去，才认出当时心里那点温暖。他留药作为信物，其中仍有邀人一同赴死的危险愿望，不能净化成无害的爱。初见时女孩自报姓名、他介绍自己喜欢唱戏，把两个人从职位和美色中还原出来。最后危险药液没有伤到他，他却哭了；强大的身体承受得了药，也不能替他承受失去。

### 第八章：进击的老鼠队

阅读范围：第 1—221 段，章节 ID `4d7dce43-a198-4e3e-aa63-16236f2134bb`。

第 1—80 段工作中的路明非被呼来喝去，藤原前辈帮他解围，律师客人误以为店里雇了童工，还给他买了一张票。叙述没有让他完全无人照顾，却也有大量针对客人身材、年龄和欲望的嘲笑。随后恺撒等人用药酒令客人昏睡、伪造照片，不能只用兄弟嬉闹概括这些行为。对人不使用特定杀伤子弹的限制仍然成立，但并不把此前的欺骗自动变成无害。

第 90—106 段顺利得过分的入口让路明非想到被操纵的小白鼠。他借动画故事想象英雄的代价：获得最强的身份，也可能失去原有的人生。叙述明确指出，他拥有得很少，却更怕失去渺小的现在。随后被泥螈吓得忘了伤感，并不推翻这个认识，而是让思绪服从正在发生的处境。

第 117—160 段恺撒给紧张得想说话的同伴棒棒糖，又拒绝交换已经入口的薄荷味；照顾与小小的不让步在同一动作里。游戏比喻展开成连续的虚拟战斗，带读者亲自感受双方差距，不只是给敌人贴强大的标签。路明非枪法好却扛不住子弹，恺撒及时拉住他，也不告诉他刚刚被鲨鱼盯上的事。个人的能力、胆怯与受照顾的需要没有被合并成单一评价。

第 157—201 段潜入者没有完整计划，甚至争论时忘了电梯仍在上升。楚子航靠观察搬箱子的数量找到脱身办法，恺撒先走则因为最容易被认出来，叙述补足了这个容易被误会成自私的顺序。不过这也不是每个冒险决定都正确的证明，前面的失策仍被写得清清楚楚。

第 203—221 段恺撒见到源稚生的杀意接回夜夜重复的噩梦：真在怀里化成沙，母亲去世时的无力也回来。复仇因此有持续侵扰生活的具体原因。路明非听说昂热到了东京便安心，英雄的名声在这里也是一个学生可以倚靠的人。

### 第九章：神国画卷

阅读范围：第 1—455 段，章节 ID `aa65b513-4cf6-4549-8c30-bfc91cbd11b3`。

第 1—76 段壁画的美与现场血腥同时进入视野，暴力、妖艳与悲哀被叙述真切欣赏。推理过程中，颜料从氧化铁被进一步识别为含血的物质，理解会改变。恺撒承认宿敌知识胜过自己，愿意替他打灯；但得知源稚生可能有更高贵的血统，又先受伤于自己的优越地位。知识说明和人物的虚荣并行，并非暂停故事来展示资料。

第 77—100 段地下男孩像独自看白鲸的孩子，用激光逗人面鱼，场景随即转成同类撕咬。他说世界丑陋，玻璃墙崩塌又被写成末日般的美景。这类段落说明作品的审美不只指向安慰：毁灭、诡异与残忍也可以被认真写得令人着迷。

第 117—149 段进化成龙的诱惑被楚子航和恺撒各自用父亲、母亲的失望挡住。壁画的艺术价值又引出恺撒对父亲的怨恨，楚子航察觉到这种怨恨超过了一般的不屑，没有立即替他解释。两人处理残片的方法不同，楚子航也承认有时直接取走比继续拍照有效，彼此并非永远固定在聪明与愚蠢的位置。

第 160—276 段各人的限制不断被实际状况改写。恺撒想触发电梯刹车，设备却没有按预想停下；源稚生被简单的绳索绊倒，又凭力量反击。橘政宗要继续封锁保守秘密，源稚生则想到普通员工的逃生，要求限时开门。他给父亲披衣、说自己也曾是父亲的累赘，是此刻真实的亲情表达；不能因此替父亲担保全部动机。源稚生承认犯错，却说仍要继续，信任的破裂没有靠一句道歉解决。

第 279—325、384—410 段神奇快递有极端日常的手续、制服和广告词，魔鬼的安排则精确得令人害怕。路明非用钥匙开门救人，确有这次行动和得到感谢的快乐；但所谓逃生导航随后把他困进禁区，迫使他开最后一道门。得到帮助和被操纵同时发生。见到红发女孩时恐惧消退，又明显连接诺诺的记忆，尚不能当作对眼前这个女孩充分而独立的认识。

第 342—383 段刀术之美、传承和凶险被大篇幅铺开，楚子航的少年宫课程与发光玩具礼品却突然闯入，把两人拉回具体的成长经历。源稚生自己的视角又显示他同样没有必胜把握。关于古流剑术的讲述从薄樱式审美转向人命贱如纸，保留美感，也揭露美感下面的杀伤。

第 414—455 段贵族、皇与精英滚在地上，连漂亮的招式也用不出。恺撒的怒火有正当的追问，也被楚子航提醒不能只顾泄愤。近身开枪先让人以为他失控杀人，随后说明是麻醉弹；他仍区分直接开枪者与源稚生的责任。最后源稚生望着死去部下露出的哀凉，确实缓解了恺撒的怒气，说明愤怒中断言友情全是错觉，也没有穷尽他们能够看见的彼此。

### 第十章：正义的朋友

阅读范围：第 1—533 段，章节 ID `798a2465-1233-48d3-878c-aba7a826f089`。

第 1—50 段路明非先把面对尸体刷牙的绘梨衣理解为冷漠的怪物，后来又看见她一闪而逝的哀凉。抓头发的动作原来是为了认出海里的他，危险的能力与辨认人的笨拙相邻。奢华住处被看成不适合年轻女孩生活的囚室，路明非设想自己在此生根成树，关心由生活如何被度过产生。他理解她想去更外面的地方，也仍怕自己只是被女王拎着的火腿。

第 51—137 段源稚生先拉住刚刚还在交战的楚子航，再坦言共同御敌之后仍可能抓捕他们。他将职责置于恩义之上，恺撒则无法接受一个人放弃自己的正义；合作最终成立的条件是保护无辜者，而非彼此恢复信任。武器库里的背影又让源稚生想到深海中照自己命令赴险的两个人，威武的战士被比作努力划水的小鸭子，他并非不知道自己背弃了怎样的人。

第 138—163 段绘梨衣绕路是为了避开家人，不只是迷路。路明非无法理解那么强大的人为何不能自己出去玩，能力与自由之间的距离因此具体可见。听到柜中女孩哭喊，他想到自己被困潜水钟的绝望，想救却不敢冲上前。绘梨衣因他不喜欢死侍而动手，两人的救援动机并不相同；随后路明非找急救箱交给女孩，也补上了能力之外可以做的事。

第 207—255 段绘梨衣抓紧时间看城市，因为出去一次已经值得；路明非才明白自己以为失败的出逃，并不等于她毫无所得。叙述由此展开与死亡比偷跑的想法，再回到热咖啡、雨珠、外套和求情。披衣之后的深情凝视最终接上怕挨打的恳求，喜剧没有使咖啡和外套失去温暖。远处窗内的亲吻、游戏、面膜和电话，是屋内人并不知道有人在向往的普通生活。导游扮警察救援又带来夸张的热闹，绘梨衣依然只看城市。

第 265—337 段恺撒断言龙没有感情，随后意识到触及夏弥而补充解释；这一断言不应当作作品统一的情感法则。王权令死侍下跪，最初像它们自愿臣服，进一步观察却说明那是不能抗拒的重压。火烧死侍时，人类的残酷被比作火刑，敌人的危险没有让叙述停止描述它们的疼痛。听见货运电梯还能运转，恺撒首先高兴的是路明非可能活着；楚子航这才知道他一直记挂，没有说出口。

第 344—405 段楚子航主动承担诱敌，是因为深海中上一回由恺撒先去，承担有过往次序，而非临时宣讲勇敢。恺撒装子弹压住焦虑，把不能失去的对手说成不能玩坏的好对手。楚子航让他走，源稚生也准备关门，正义于是成为当场要作出的选择。恺撒回身救援；楚子航原本把固执既看作优点也看作与人隔绝的缺点，见到来人时却笑了，因为至少还有一个人和自己同样固执。

第 407—430 段从源稚生看，两人仿佛隔着黑烟发光；燃烧的纸页又使他想到小暮和自己杀死她的那一夜。他羡慕这种孩子气，终于用自己的血引开敌人。恺撒却误以为他再次逃跑而向他开枪，读者知道的救援并不立刻换来当事人的理解。逃出火场以后，源稚生仍思考如何抓捕两人，也没有因为一次牺牲就变成毫无立场冲突的朋友。

第 435—459 段更尖锐的选择随即到来：射穿源稚生的颈部可能救其余人，恺撒却在他的脸上重新看见一个虚弱将死的人。他想起雨中点烟、曾以为交到朋友的一瞬，自己的正义也反过来要求自己。旁白承认他欠缺理性，而非把风险抹掉。最后源稚生自己作出牺牲，说明想当正义的朋友仍是他没有完全消失的愿望。

第 460—511 段此前捆住源稚生的绳子救了他，施药、点烟与继续绑着交谈又把敌意和照顾放在同一场里。源稚生承认先前确实想抛下楚子航，也把所谓鬼说回更容易变成死侍的同类。倒吊的皇唱儿歌，本来应当滑稽，却没有人笑；叙述让读者看见当年挺起胸膛相信正义的孩子。源稚生说牺牲他人和自己能使族人活得更好，恺撒仍坚持坏事不会因此变对。理解一个人的苦衷，不等于替他的行为免除判断。

第 513—533 段源稚生终于在自己楼里找到豢养死侍的设施，将疑问指向一直信任的橘政宗。要谈判、要烈酒的同时，他还要求给死去的兄弟盖白布。重大秘密与对尸体的这件小事并列，使权力危机没有完全吞掉具体的死者。


<a id="chapter-66"></a>

### 第十一章：末代皇帝与最后一个克格勃

阅读范围：第 1—298 段，章节 ID `6b6a970d-9075-4372-a758-4de0555b7f85`。

第 1—45 段上杉越劝年轻食客追女孩，把粗俗的身体欣赏和多年以后会怀念的大酱汤气味说在一起。旁白明确说这番话令人心动，不能把它清洗为全无欲望的青春感悟。昂热来后，两人谈昔日地位，也争论酒该怎样喝；加一块叉烧是顺手做出的招待。得知一直替自己缴税的犬山贺已经死去，上杉越擦桌子的手只停了一秒，却不是没有悲伤。

第 46—206 段橘政宗穿军装、备怀剑，讲述自己的出身、贪欲、女儿与罪责。叙事把这场告白写得连贯而沉重，但其资料主要出自当事人，不能因此预先认定全是真的。源稚生追问为什么同样的方法没有救下弟弟，也怀疑药物是否被故意散发，最终却再次把自己认作父亲手里的刀。砍掉五指既是惩罚，也保全了继续服从的关系；这一结果需要后文检验。

第 110—146 段两位老人用色情光盘谈古籍的价值，随后又真正肃然面对神话时代的皇帝。叙述认真写出那些死去名字的辉煌，并不因前面的淫贼玩笑就取消敬畏。第 165—166 段源稚生回忆给病床上的绘梨衣一台新游戏机，想象没有游戏的病房生活。他对女孩的照顾也含有失去弟弟后留下的位置，不是无背景的普遍善意。

第 219—253 段上杉越说自己的故事。昂热先拿人格、父亲与胚胎开玩笑，谈及自己已经没有什么可拿来发誓时，两人才忽然沉默。皇血的尊贵被改从生育者的死亡、父亲的厌恶和被迫分离讲述；家庭之爱不再等于顺利在一起。母亲在灯下给所有孩子讲故事，而他知道那是自己的妈妈，共同得到的照料与不能公开的私情叠在一起。

第 254—288 段上杉越承认自己曾享受支配，把妻子当玩具，也为侵略战争祝福。权力隔绝真实世界解释了他的无知，却没有令他的行为变得无害。母亲之死击碎他对战争的说辞；更残酷的是，愤怒又使他杀死无辜妻子。最后一个女人为自己辩白的声音被保留下来，复仇没有因此成为正义。母亲最后诅咒的是自己，这是上杉越回顾中的理解，不能写作她已亲口明确的意图。

第 269—298 段昂热停止插科打诨，替对方斟酒；收尾留给社区教堂、法国巧克力和雨中的旧街。叙述容许一个有重罪的人仍想念母亲，仍有一点平安喜乐，也没有宣布他已经被赦免。对人物的亲近与对他行为的判断可以同时存在。

## 第三部：黑月之潮（下）

<a id="chapter-67"></a>

### 第一章：源家次子

阅读范围：第 1—209 段，章节 ID `5a1dfd48-0b3a-4d66-bf3e-9d83fe5d25a8`。

第 1—60 段高天原的客人索要道歉，确有牛郎下药离店的前因；其羞辱人格的行为并不使前因消失。叙述以身材和外貌持续丑化她，随后又为血战归来的两位主角失去耐心作解释，这里的偏爱相当不平均。藤原勘助护住座头鲸时，旁白一方面承认男派花道有美化职业的成分，另一方面指出恺撒能结束体验回去做贵公子，座头鲸却只有这一生的职业可供自尊。知道那层说辞并不完全真实，仍有不忍拆穿的理由。

第 62—109 段风间琉璃的传说由他人的期待铺开，煎蛋却来自哥哥教过的手艺。早餐并未好吃到必须落泪，是被珍视的经历使客人感动；指出名望的作用，没有取消感动确实发生。男孩在晨光里清水般美好，恺撒后来再看其眼睛，又看见深潭的黑。温柔与危险来自同一个人的不同可见层面。

第 113—152 段三个人挤在胶囊房里观察绘梨衣，脸贴玻璃、身体互撞，沙丁鱼的比喻直接接在动作上。绘梨衣认真摆放不合常规的玩具，也不了解窗外会有人看见。这里明确以男性对年轻身体的欣赏冲淡对怪物的恐惧，属于叙述的具体欲望和价值偏向，不能统一改述为超越外貌的同情。

第 156—201 段医学风险、身份判断和调侃交错。路明非想起老唐再也不会亮起的头像，不愿绘梨衣成为故事结尾需要被杀的对象；这种担忧有已经失去朋友的经历。另两人既把看护任务推给他，又交出所有现金，让他尽量使女孩高兴。人形兵器的称呼、任务安排和朋友式照顾仍同时存在，尚未被整理成一致的温柔立场。

第 204—209 段路明非认为绘梨衣像诺诺，恺撒却强调气质不同。相似带来的悸动和害怕属于路明非的感受，并未得到所有人物一致确认；分析不能先将绘梨衣的存在收缩为另一女孩的替身。


<a id="chapter-68"></a>

### 第二章：东京爱情故事

阅读范围：第 1—209 段，章节 ID `9095197f-bdb9-4980-8443-8273c52c92d0`。

第 1—39 段源稚生的急切先被部下解释为妹控，他却担心整座城市。全城动员与房内吃火锅交替，路明非的悠闲来自不知道外界，也不知道昂贵赠酒是人为安排。读者知道危险和设计，人物仍能认真享受食物；两层知识没有迫使温暖变成假的。

第 40—86 段酒德麻衣把撮合两人比成照料熊猫，比喻继续展开到配对、竹子和互殴，再回到两人只顾吃饭的事实。幕后导演及专家组的忙碌本身也成为一场戏。他们对恋爱效率的自信属于角色的方法，尚不能作为文本已经证明的爱情规律。

第 89—117 段绘梨衣说去洗澡，路明非先想起陈雯雯结束聊天的惯用话，后来才发现她真的要洗澡。旧经验能使人误读正在相处的人。电视剧被讲成大叔大婶的小情小调，路明非却记得里面的阳光、雪人、食物和承诺，无法接受那些具体的相爱竟可以不算数。芬格尔关于人会改变的辩论又使他想象多年后的麻将桌：自己也许幸福，诺诺也许坐在恺撒身后，而陌生妻子的脸令他害怕。他怕的不是一个抽象道理，是自己会把现在舍不得的东西放下。

第 125—163 段路鸣泽把女孩称作钥匙，建议控制不住就折断，又在同一条消息末尾提醒准备热牛奶。体贴与工具性的威胁来自同一人。浴室里的响声引起路明非误判，他冲进去跌倒，才发现绘梨衣正看灯亮起来的天空树。巨塔使城市有了能够望见的方向，女孩只说想去玩，他答应明天带她去，然后出门买奶。关怀没有排除身体欲望，旁白也揭示他仓促离开时在流鼻血。

第 164—209 段读者随后得知电视剧重播与天空树开灯都是人为设计。专家团短暂相信自己真的在帮助一场幸福婚姻，酒德麻衣却知道任务的荒诞；苏恩曦又认为老板是在替路明非争气。最后七天期限和可能的死亡使礼物显出毒性。不能只摘取其中一层，把老板概括成纯粹的慈父，也不能因布置是假的就否定两位当事人看见城市时的感受。

<a id="chapter-69"></a>

### 第三章：古事记

阅读范围：第 1—92 段，章节 ID `695d2dbb-c5c3-46d8-8823-6e9c752efa67`。

第 1—19 段绘梨衣带刀出门是因为好看，路明非便用外面的饰品劝她放下。美容店的过分热情被他解释为漂亮同伴提升了自己的待遇；旁白也承认，他无法拒绝全世界赞美同行女孩的满足。读者知道服务经过安排，但女孩变得明亮、柔软，以及他的惊讶，并不因此消失。

第 20—49 段幕后的调度与前面的购物相互切换。苏恩曦能做巨额交易，却因不懂恋爱只能坐在一旁，仍想参加这场热闹。绘梨衣看镜子时的欣喜、穿高跟鞋时的小鸭子步态，让路明非与酒德麻衣先后动心。麻衣随后发现她越来越像诺诺，指出老板审核过造型；这给眼前的美蒙上阴影，却仍需区分布置者的意图和路明非尚未确定的感情。

第 50—78 段剧院经理以为年轻观众证明古老艺术复兴，职员指出她们来看明星，叙述却又肯定演出本身的艺术水平，反转没有把作品一并贬低。恺撒只记得过去观剧时女伴的裙子，如今却认真被男性演员呈现的女性美震动。舞台前父亲与孩子欢舞，帷幕后被遗弃的女人哭泣，空间直接组织了谁拥有幸福、谁只能看着的关系。

第 79—92 段屠蛇原本应是英雄壮举，演出让观众持续看见被砍杀的女人；剥下蛇袍之后，她像一片落叶。旁白同时保留两项判断：复仇的行为邪恶，遭受过的痛苦仍使人不忍。人物的受苦得到讲述，不必以其所有选择都正确为前提。


<a id="chapter-70"></a>

### 第四章：黑天鹅港的幽灵

阅读范围：第 1—217 段，章节 ID `1e4e844b-e148-41d2-8638-5f0e2f2da020`。

第 1—60 段猛鬼以礼貌武士的模样出现，源稚女也谈自己选择牛郎生活是为了与孤单的人交换故事。身份先前带来的想象被具体生活补充。死侍养殖照片令恺撒不忍：清除危险生物是一回事，看其活体被肢解又是另一回事。楚子航同时指出照片不能独自证明养殖地点，感受可信不等于证据链已经完整。

第 63—118 段源稚女说没有正义，恺撒立即反驳；关于吃人与被吃的理论，也被明确称作恶心而疯狂。源稚女为自由歌舞的宣言获得真实赞叹，却紧接着用媒体照片把两人逼入合作。叙述能欣赏一个人的愿望，又暴露他的算计，不能只取其中一种面貌作为人物本质。

第 119—132 段演出情绪出现后续修正：恺撒与楚子航判断现场使用了致幻剂，叙述进一步说明其作用，上一章的感动因此不能全部归因于自然的艺术感染。这是故事中的设定，不是现实药理依据。源稚生赶来时，人已经离开，空衣、气味与旧合照却使屋里处处有弟弟的痕迹；不在场的人反而充满了空间。

第 135—156 段恺撒与楚子航从是否合作谈到将来的婚礼。恺撒讲与女孩在城市里疯跑，认为没有走到一起也不取消共同度过的好时刻。楚子航随之承认诺诺有理由选择恺撒，叙述转入第二人称追问：愿意牺牲、拥有力量，并不自动使对方想要那份爱。这一判断并非作者从场外突降，而是从朋友听见另一个人的相处经历长出来。

第 157—162 段两个人像熊一样挤在小窗前，随后看见绘梨衣为爱惜新靴子而赤足涉水。脚步、裙摆和脚踝上的链子使迟到的夏天仿佛到来；视线再扩展到樱花、食物、游客和不用考试的闲暇。危险并未消失，但他们暂时愿意相信还有好故事可发生。希望是真实的当下感受，不是对结局的保证。

第 163—217 段给钱、卖肾的玩笑、买女性日用品，与劝路明非同绘梨衣建立暧昧的安排连在一起。路明非离开后，恺撒才说出已经付钱安排退路，要送两人离开风暴中心，自己与楚子航留下。先前像是在获取人形兵器的计划，又显出保护朋友的动机；但这种揭示也不应使其中操纵女孩感情的手段消失。

<a id="chapter-71"></a>

### 第五章：井中枯鬼

阅读范围：第 1—99 段，章节 ID `319dc0f4-6c39-4cb1-932a-5ab69508f3bf`。

第 1—27 段源稚生带橘政宗回山，途中仍扶着刚被自己断指的人涉水。两人的钱包分别藏着父子与兄弟的照片。源稚生反复说弟弟已经死去，却未觉察自己重复；他在对外讲述中删掉弟弟，不等于记忆已经不再疼痛。

第 34—45 段井中燃烧的是旧衣，形象却像少年再次受刑。橘政宗以正义必须付代价解释过去，源稚生记起的却是那个浑身是血、仍欢迎哥哥回家的人。具体关系打断抽象分类，但尚未将弟弟的罪行抹去。

第 47—81 段回忆补足杀弟的前因：失踪者都是源稚生认识的人，出发时他本来还想带游戏机探望弟弟。曾被当作正义朋友基地、可供受伤后疗养的地方，后来成了藏匿受害者的空间。源稚女表演时的认真与残酷并置，美与天才都未使受害者不存在。

第 82—89 段弟弟认出哥哥后从戒备转为惊喜，刀已经贯穿身体，他仍说出原本准备好的欢迎。哥哥拥住他的手和握刀的手同样用力，动作无法拆成单纯的爱或单纯的恨。源稚生多年后承认，正因为弟弟没有把自己当作敌人，自己才可能杀死他。

第 90—99 段源稚生说杀弟使自己不再为斩鬼感到罪孽，却仍反复梦见自己困在那口井中。他宣称不后悔，只为弟弟难过，并准备再次动手。作品此时呈现的是他用来维持自己的判断，以及始终无法被判断消除的痛苦，不能将其直接提炼成叙述者认可的唯一出路。


<a id="chapter-72"></a>

### 第六章：真红之土

阅读范围：第 1—215 段，章节 ID `bb54fd7a-4263-443c-97e5-43ae892fd973`。

第 1—39 段昂热再次来吃面，肯学猪叫，也说东京的旧友只剩上杉越。接着他仍拿出要询问的资料。想见一个人和需要利用他的知识可以同时成立，调笑也使两位老人暂时脱离上一场告白的沉重。古文明的勘探说明中，昂热又想到神独自行走在废墟里会多么寂寞，知识讲解里仍有人的想象。

第 40—111 段樱井雅彦起初是负责勘探的研究员，随后不得不开枪阻止感染者逃出，包括一直照顾自己的前辈。叙述在这一场明确说明某些处置是为了减少痛苦、阻止更大灾害，也直接呼唤守住人类的责任。雅彦最终亲自跳进火中，以文职人员的身体多守住十五分钟，获得正面的英雄评价。这与其他场景中拒绝牺牲同伴的选择并存，不能将作品归纳为无条件支持或反对牺牲少数。

第 119—177 段家主们从橘政宗断指推断源稚生残酷而有权威，读者却知道那一刀也保全了性命。宫本志雄眼中的新领袖如山岳，能调动整个家族，会议结束后樱看到的却是难以融入家族、连续三天没有休息的人。同一个身体因观察者不同，同时承担着强权形象与疲惫现实。

第 178—215 段源稚生回忆绘梨衣曾在第一个路口因世界太大而哭。他理解她不愿终生做武器，又继续扩大搜寻；他准备自己先去赴死，最后仍可能把妹妹投入井中。把照顾称作擦拭刀剑，是他的自责与角色认识，不能倒推所有生活里的关心都毫无真心。樱没有替这一切辩护，只说他们同样被当作凶器，源稚生才临时改变独自远走的计划，邀请她同行。结尾不是英雄宣言，而是他终于睡着，她在旁边撑伞。

<a id="chapter-73"></a>

### 第七章：怪兽组合

阅读范围：第 1—97 段，章节 ID `92a9c451-b759-4c25-8222-f96a434c4361`。

第 1—17 段路明非和绘梨衣讨论炒饭、拉面、披萨和追番，旁白称这些话没什么营养，却用它们呈现关系变得自在。她会坚持自己的口味，他不再始终小心侍奉。跑远买冰淇淋后看见她仍坐在原地等，才使他放心短暂离开；信任来自经历，不只是抽象宣布两人相投。

第 18—40 段专家团却认为三天进展近乎为零，把不能归类的性格丢进怪兽类。职业理论无法自动说明两个人已经发生的变化，双方孤独也不意味着会立刻相爱。建议愈来愈转向制造性关系，酒德麻衣对所谓专家的评价也随之改变；老板再把真正的家人引入这场布置。

第 41—67 段叙述大幅进入婶婶的日常账目与比较心理。酒店收费被她看作地雷，尽量带货是为了省回旅费，为儿子婚事又能忍痛付钱。她想象路明非一家在海外豪宅团聚，读者知道这种想象与他的生活相距很远。竞争心并未被证明正当，但枕上的眼泪和一定要促成婚事的决心都被认真展开。家庭妇女被比作迎着箭雨的将军，既有戏谑，也承认她把这些事当作自己的人生战场。

第 68—97 段战争准备转成庞大的运输与工程奇观：孩子惊呼高达，成年人畏惧，假湖面裂开，武士在巨大机械旁举刀相敬。叙述真心欣赏规模与力量，也在井盖最后合拢时看见飘入的山樱。细小美感不只出现在柔情场景，也能嵌入工业和战争的宏大画面。


<a id="chapter-74"></a>

### 第八章：家庭晚宴

阅读范围：第 1—515 段，章节 ID `12057a59-c984-440a-aff5-b8e8f3f447ab`。

第 1—48 段免费画像、抽签与过分周到的服务终于使路明非察觉有人操纵。他不是单纯拒绝好处，仍想保留送餐与折扣，却愤怒于自己用尽力气生活，在别人眼里只是一场秀。企鹅被摄像、被解说、被观众加油的想象持续展开，给这种愤怒一个可以看见的处境。和尚确实受雇拉客，却说签是两人自行抽中，也确实住在寺里；生活未被切成全真或全假的两半。

第 49—93 段老板仍留摄影组监视，路明非却以为魔法已经完全消失。堵车和年老司机让城市重新显得巨大而不迁就自己，绘梨衣仍专心看窗外。麦兜去不了真正的马尔代夫，却曾在替代旅行里得到快乐的故事，使路明非想到女孩有限的世界。能轻易哄她听话并未使他得意，反而想到自己要把她送进另一座牢笼。摸头时的怜惜很快又被人形兵器的认识打断，随后她不抗拒的动作再次唤起亲近。

第 95—144 段路明非本来准备维护自己的订位，见到婶婶却立刻怯下来。曾参加拯救世界并不使家庭中的位置自动改变。他主动把冲突说成自己记错了，替双方找台阶。这里的行动目标并非以成功羞辱过去的亲人，而是希望关系还能恢复。

第 145—205 段路明非压低自己的学校和生活，努力称赞堂弟，绘梨衣却因熟悉法餐而自然成为众人注意的中心。她看出需要好好招待大家，表示自己会听话；他在心里替她分清，被针对不是她不够乖。她召来总经理，也接受较低一级的食材，只叮嘱不要通知哥哥。先前被当成没见过世面的女孩，在熟悉的秩序里有自己的行动能力。

第 186—238 段路明非想和解，是因为六年的饭食和假期无处可去的现实；他担心用叔叔电话会给家人引来危险。读者随后知道总经理已经报信，悬赏又吸引全城黑道。老板承认计划出了问题，酒德麻衣第一次失去对其绝不出错的信心，幕后安排并非全能保障。

第 242—291 段路明非紧张得发抖，绘梨衣按住他的腿，告诉他哥哥还没到，再举杯维持席面。她早就听见外面的危险，却在配合他的家宴。路明非为撮合堂弟编造女友，话里不知不觉全是诺诺；陈夫人对他的称赞则另有打算，是借更高条件的例子拒绝联姻。人物说出口的话、真实愿望与他人听见的意思不断错开。

第 292—332 段婶婶在比较与账单面前失态，路明非被砸却理解她不甘心一生只围着灶台转。他从自己曾想闪着光出现的愿望理解她，仍未能因此被她接纳。叙述容许他同时有同情与受伤，不能把他的自责直接改写成受伤者应当忍耐的规则。权力地位的获得在此像是失去旧家，但这还不是本章的最终认识。

第 334—354 段绘梨衣担心自己做错了，他先安慰她。叔叔追来时，他以为又要被质问，叔叔却塞给他一万日圆，再把零钱也给了他。路明非口袋里已有更多的钱，真正使他想哭的是这个怕老婆、爱显摆的人仍要他平安回家。旁白保留叔叔可能攒钱买色情光盘、啰唆自以为是的旧样子，没有把他净化成完美长辈。路明非握着这点钱重新开始逃亡，才从野狗想到家犬：危险未变，是否有人等自己回去变了。

第 355—430 段梆子声唤起恐怖幻觉，电话里一句粗话却像咒言一样恢复清明，黄花与不相互抛弃的誓言把当下同冰海经历连接起来。他搀扶绘梨衣时，记忆中的女孩曾撑住两个人的世界，如今轮到他。逃生跑车既快又不适合雨天，帮助也有来不及周全的现实；酒德麻衣用狙击阻路，仍避免直接用重型枪械射击普通追逐者。

第 431—476 段保护滑向占有：路明非撞伤追赶者时感到欢欣，把绘梨衣当作争夺中尚未丢失的猎物，甚至为控制她而弄伤她。叙述明确写出魔鬼意志的侵入，没有把所有凶狠都美化成英雄气概。女孩的哭声把他唤回来，他重新记起她是活人，自己应当保护她。这次修正靠看见对方正在受什么苦，而非增加一条抽象道德。

第 477—515 段超自然力量使他不断愈合，却没有取消疼痛与耗竭。他最后想到的是若换一个更有能力的人被她信任，她就不必如此害怕。绘梨衣随即以残酷力量反杀，眼中有杀戮的喜悦，外形也不再只是美少女；路明非仍先害怕她要杀自己，下一刻却被紧紧拥抱。结尾把凝视与拥抱交给第二人称，让读者进入靠抱住某个人确认自己仍活着的经验。


<a id="chapter-75"></a>

### 第九章　我们都是小怪兽

阅读范围：第 1—210 段，章节 ID `1acfb5b5-cff5-46a3-8811-9a73e4a8ef86`。

第 1—45 段婚礼梦把归属的温暖与无法拒绝另一人的召唤并置。路明非松手之后，新娘变成失去生命的傀儡，这是梦的恐惧，不能据此认定现实中的绘梨衣只是替代品。第 61—77 段同一张脸既能令杀戮者恐惧，也会流露受害者的恐惧；路明非自己也在发抖，没有凭一句保证便治好她。她认出海里的小黄鸭，才重新露出笑容并抱住他。对别人是怪兽，对她却是同类，叙述直接提出观看位置如何改变故事类型。

第 79—116 段专家看见浪漫画面，读者知道此前的恐惧与暴力。麻衣提出可能是爱情也可能是同病相怜，保留不确定。苏恩曦先给她热食，再谈被安排的人生；两人关于历史、爱情与老板的说明仍是人物意见。下一章苏恩曦还会承认，自己说过的话有一部分只是为了安慰她，不能把这些漂亮说法全当作作者的定论。

第 138—180 段身体的鳞片与坚硬没有因拥抱而消失。电视里的事件又被权力改写：画面中的活人受威逼配合，记者仍愤怒追问，路明非的叔婶也在镜头前维护家人。叔叔的粗话与婶婶的捶打并不体面，却延续了前章送钱的真实牵挂；路明非不联系他们是怕把危险带回家。

第 183—210 段把绘梨衣送往中国的计划同时意味着药物维持、拘禁与处决风险，路明非无法再把自己看成毫无责任的旁观者。他想到战争中没有真正朋友，又用自己的旧日记忆给这种判断添上重量；这只是此刻的认识，后两章同伴的行动将使它发生变化。


<a id="chapter-76"></a>

### 第十章　迎着阳光盛大逃亡

阅读范围：第 1—325 段，章节 ID `4d03f9d1-6e64-40a4-b951-1c4da0af7ea1`。

第 1—40 段洗去人工造型后，绘梨衣重新像她自己。丝袜与手套原来是在遮掩龙化，外出不是毫无代价的任性。她知道自己给人添了麻烦，也懂得回去的后果，仍庆幸这几天的自由。她曾说世界好厉害，路明非这次则认真赞叹她能觉察旁人的喜恶。两人的理解从单方面照管转向相互看见。

第 41—110 段准备最好的衣服、擦亮鞋子、查路线，把最后一天落实为行动。麻衣也会饿，会因阳光与樱花暂时舒展。苏恩曦承认自己说过的爱情道理有安慰成分，叙述允许感动成立，又不把解释变成不可反驳的真理。恺撒拿出最后的钱却装作随意，楚子航边争论边帮忙；车子连续故障的原因要到下一章才完整显露。

第 111—196 段大海从恐怖场所变成平静风景，取决于他们怎样来到这里。路明非事先查过资料，诚实承认自己会被旧电视剧打动；绘梨衣认真聆听，没有笑他。落日、树海、小摩天轮与过时的影视记忆共同构成他认为最美的地方。她对世界的理解长期来自游戏和动画，医护人员记录稳定指标，却没有耐心解释现实。她提出许多问题，他结结巴巴地回答；普通世界之所以温柔，不是被删掉危险，而是她终于能够理解并接近它。

第 197—231 段绘梨衣说世界不喜欢自己，路明非先因自己的经历而沉默，随后明确否定她的自责。他从熟悉的人和地方讲起，把过于巨大的世界缩回实际关系。中间插入当年演讲失败的长回忆，解释他为何不相信自己的话值得被听见；女孩认真追问，使他这次终于郑重地说话。金句不是凭空降临，而是在双方旧伤与眼前回应之间慢慢获得分量。敌视全世界的嚣狂念头仍伴着恶魔的冷笑，不能把占有与保护完全等同。

第 232—241 段女孩缓慢靠近，随时准备被拒绝；路明非想躲，却不忍让她失望，以近乎坐禅的姿态硬撑。动作既可笑又认真。拥抱使他意识到她的喜欢，也同时想起自己在梦中选择了别人。远处观看的麻衣认为眼前很美，并未因此保证结局。

第 242—301 段当地饭食、鲜鱼、瓷娃娃、寄居蟹和借来的运动鞋把旅行写得具体而可眷恋；叙述又切到暗处的枪口，使读者知道安静的月台仍处于杀机之中。路明非最后突然下车，前面的路线、时间与车辆选择才被重新理解为完整的逃生安排。他不是临时被一句情话激励，而是已看见她的身体支撑不住，决定承担违背组织的后果。

第 302—325 段保护愿望中仍混着魔鬼式的占有冲动，叙述直接承认这部分阴影。绘梨衣低头并非只有伤心，她正在赶写询问姓名与重逢地点；路明非用牛郎的烂话告别，避免把自己变成庄严的救世主。老板终于让她离开，既有放任路明非自主选择的一面，也仍以力量许诺迎战。最后路明非打电话通知哥哥接人，原来从开始就没有给自己买车票。


<a id="chapter-77"></a>

### 第十一章　来自北极的故人

阅读范围：第 1—236 段，章节 ID `b95b384b-df39-4cb1-9a63-8ce46ce5cb8b`。

第 1—16 段旅馆老板娘为两人掩护并留到深夜，普通配角没有被默认写成冷漠的城市背景。她把路明非的害怕误认作失恋，他又把她的同情误认成守忌日，两边善意在错位中产生笑声。他担心的是组织惩罚，叙述没有要求做出勇敢决定的人随后就不再害怕。

第 17—30 段离开的人通过散乱玩偶、购物袋、被褥痕迹、漏水声与尚存的气味留在房间里。房子变大不是建筑改变，而是习惯的陪伴消失。叙述仍保留他的色心、迟疑与想撒谎减轻处罚的念头，没有为使离别感人而净化人物。

第 31—69 段枪口与沉默先使他以为审判到来，邀请吃夜宵却改变了这场景的性质。他承认责任，仍会求饶；同伴未承诺结果一定正确，而是接受人在不能预知一切时仍须作出选择。回叙揭示恺撒故意弄坏冷却系统，早已用行动帮助逃亡。恺撒以夏弥的旧事逼楚子航面对另一种选择，栗色眼睛重新显露，使强硬者暂时成为受伤的少年；这次说服并不只是漂亮的领袖演讲。

第 70—144 段芬格尔的狼狈外形、求职表演、讨饭与谄媚接连展开。三人仍先拿毛巾、倒温水、让厨房重开；他恼怒他们说话太多却不给饭，又使温情免于端着姿态。饥饿是真的，贱话也是真的，不能把整段只归为插科打诨。夜店客人的缺爱与交易同样被写出，但男性感觉优越、把女性当作施舍对象的叙述也确实存在，不宜改写成处处平等的温柔。

第 145—210 段芬格尔带来的情报看似无用，却使同伴知道学院还有其他安排；当源稚女现身，吃面声又实际缓和了对峙。调酒、加酱油、递蒜头酥与潜藏杀机处在同一张桌子上，日常不是战斗之外才出现的附属物。

第 211—236 段源稚生先怒斥下属把伞举错了人，随后回想车站接妹妹。她疲惫却不准备为快乐的旅行道歉，哥哥看出她已经长大，以迎接回家代替责问。微笑之后她倒下，使心愿与身体极限同时真实。橘政宗接电话时短暂恢复另一副神情，又让读者与仍信赖他的家人拥有不同的信息。


<a id="chapter-78"></a>

### 第十二章　无天无地之所

阅读范围：第 1—132 段，章节 ID `4e85f5fd-bea1-4c4e-be11-789e2be0fe71`。

第 1—50 段窃听录音把阴谋铺开，芬格尔却因辣椒流汗而不是因恐惧流汗。对东京塔的理解既是行动条件，也是王将俯视并焚毁城市的欲望；风间琉璃谈杀人时越像得到糖果的孩子，路明非越感寒冷。可爱与危险在此不互相抵消。

第 51—69 段绘梨衣的治疗使用死侍胎血，进一步暴露所谓能否获救也取决于资源分配：另一些鬼被杀，是因为那样更廉价。源稚生坚持等她醒来，明确担心她孤单，同时会因她或许更喜欢路明非而失落。厚重玻璃、监控与接触限制让关怀和囚禁仍然并存。

第 70—108 段行动计划通过空间、距离、角度、体重与分工逐层形成，玩笑参与人物协商。芬格尔被赞有牛郎潜质之后又发现对方看中的是技术，会顺势纠缠；路明非怕担重任，也确实未被同伴直接当作可靠的冷峻杀手。后面的爆发因此不是所有人物早已一致认定的隐藏强者表演。

第 109—132 段源稚女把路明非的眼神理解为收藏杀气，叙述随即进入路明非内心：他想藏住的首先是自卑、疏离和不该显露的感情。他讨厌真实的自己，希望烂话能使自己稍微讨人喜欢。这段没有立即用强者身份纠正他的感受，而是让受伤的经验独立成立。源稚女以绘梨衣安危施压，最后从桌面倒影看见可怕的凝视，证明危险存在，却不能反过来抹掉之前那层敏感与无奈。


<a id="chapter-79"></a>

### 第十三章　刺王杀驾之夜

阅读范围：第 1—381 段，章节 ID `f48ffc86-b9a3-482e-bfaf-8cb8c99a96e5`。

第 1—24 段东京塔既有巨人的雄伟，也有骨骸的衰败。源稚女谈城市的华丽牢笼，芬格尔却要求别忘了自己正在挨冻；实际身体处境打断宏大议论。广告飞艇来自前面被监视的经验，新的行动办法并非与日常情节无关。

第 25—98 段旧敌的对话、酒杯、衣着、距离和武器检查被写得华丽而精密，叙述确实欣赏他们的技巧，并未因为人物危险便削弱其魅力。但关于权力的谈话随即连接到龙族吞噬至亲的规则，再进入路明非对自己受魔鬼影响的惊惧。权力之美与其代价在这里明确并置，强大不是自动正确。

第 99—152 段橘政宗的交易使源稚生认定自己受骗。叙述进入他对父亲般人物的信赖，把有限的亲近关系比作手指，再让失去其中最重要的一根变成可感的伤害。他原本监听是为了确认对方值得信任，事实却暂时指向相反结果。这些认识随后仍会变化，不能把贴近人物的肯定句一律当作不再修订的全知结论。

第 164—235 段橘政宗预藏武器并突然进攻，改写先前谈判的意义。战斗详细交代优势、弱点与空间，愤怒叫喊也可能是故意伪装。他声称为爱与正义而来，王将坚持所有人最终只为欲望；双方价值通过真刀与肉身后果相撞，关于父亲的辩词仍须结合后文判断，不能仅因感人就认定全部事实已揭晓。

第 236—318 段芬格尔像体育解说员，同伴却在水里苦战，笑话来自行动位置与信息差。源稚生仍不由自主地担心刚被自己判为敌人的老爹；樱的出现带来信赖。进攻瞬间源稚生以为橘政宗放弃挥刀、用生命制造机会，第 319 段才补出断刀其实承担了格挡。角色当下看见的壮烈解释与实际动作并不完全相同。

第 319—353 段以为已无路可逃的王将又登上飞艇，芬格尔坠落。路明非想到尚未归还的钱、世上只剩自己一个废柴，亲近关系通过不体面的共同处境出现。他愤怒并准确打中一枪，随后却因距离、天气与急躁再难命中，叙述没有让强烈感情自动保证每次成功。

第 354—381 段源稚女先给出明确目标，再表示相信路明非。被信任使他安静下来完成射击，之后他也把剩下的结果交给对方。漂亮的杀戮表演确实被正面铺展，但源稚女事先隐瞒飞艇的退路，说明合作与不信任仍并存。得手后的大笑既夸张又悲凉，复仇的舞台不等于已经获得安宁。

### 第十四章　樱之坠

阅读范围：第 1—276 段，章节 ID `b092ac8a-ba44-455b-bfbe-4c54459ba458`。

第 1—39 段短暂胜利立刻转为死侍围困，家臣只关心源稚生的性命。恺撒与楚子航撞见满屋怪物后共同撤退、流汗，吐槽并不是掩盖万能的姿态。武器、援军和退路的限制逐项兑现。

第 40—110 段源稚生准备以只能使用一次的言灵换同伴离开，樱首次明确反对他的命令。直升机被毁、体力耗竭、摔倒与电梯门共同挤压行动空间。樱给他固定伤处再割开腕部，他一瞬间误以为她背叛；随后才明白她是在拿皇血引走死侍。叙述先让误解真实发生，再补出动作的目的。

第 112—152 段回忆写樱因饥饿而杀人、因不合群而被弃置。源稚生先反感旁人的猥亵议论，再从她身上看见自己若无血统地位可能遭受的廉价对待。他希望给她尊严，却仍以漂亮手下、归属和服从来组织关系，不能把这层关系净化成毫无权力差异的救助。多年学语言、学角色、学驾驶使她的承诺拥有时间与劳动。以为她笨、不会离开，最终被改写为她其实不愿离开；他能接受牺牲许多东西，却无法支付失去她的代价。

第 153—175 段救援来不及，只有路明非远处有限的枪声仍在帮助。樱在瞄准镜中由利落的随从成为肆意盛放的人，叙述给她行动的从容与美，同时逐发耗尽子弹。她最后向帮忙的人道谢，再跃下高塔。路明非先赞叹她仍能选择自己的结局，又因为这么好的人竟然死去而落泪；赞叹没有替死亡结账。

第 176—222 段乌鸦原来就是当年口出猥亵议论的人，他用流氓口吻掩饰喜欢，后来也真心希望她和源稚生好。这不是对旧话的无条件开脱，而是粗俗与眷恋共处。源稚生在绝路上想她坐在副驾驶和自己相视一笑，随后橘政宗救他、似乎牺牲；新娘与父亲的位置在片刻间同时空缺。宣称为战争付出一切的男人，此时几乎失去意志。

第 223—245 段源稚女清洗妆容、选棉衬衣与球鞋，喜欢自己平庸的样子，说明华丽并不是人物唯一向往。看门老人有自己的帮会过去，能理解盛装杀人的心情，也提醒用血难以洗净血。老人收钱又保密，既非纯粹圣人，也不只是供主角通过的道具。

第 246—276 段体面的接车仪式变成重返控制的邀请，梆子声把曾经强大的源稚女击碎。老人被杀后，叙述一度说世上无人能救他，紧接着三人撞车救人；这个绝望判断跟随当时的处境而非最终命运。恺撒与楚子航也害怕，没有信心杀敌，仍有办法抢回同伴。被救者的肉身尚活、精神却像被夺走，脱险并未立即治愈伤害。

### 第十五章　鬼之路

阅读范围：第 1—218 段，章节 ID `838dd07d-c9ea-43cb-a954-e6307e4563e3`。

第 1—38 段芬格尔竟已回店和座头鲸谈玄，荒谬的装扮使死而复归的喜悦先以骂声出现；绳索与淤伤补足幸存的实际过程。路明非认真拥抱他，刚想到世界没有那么残酷，马上又想起樱确实死了。一个人的归来不能冲销另一个人的失去，喜剧没有强行把上一章的死亡变成虚惊。

第 39—79 段阳光清亮，新闻却抹去了他们所见的伤亡。众人讨论是否强迫源稚女开口，芬格尔声称应当舍小我，真正面对安静的病人时却先说有权保持沉默。急迫的任务理由没有让他们轻易消除眼前人的脆弱。平庸的少年面貌逐渐取代舞台上的诡艳，叙述把真实与华丽区分开。

第 80—112 段源稚女自述羡慕哥哥、偶尔嫉妒却并不想压倒他；王将利用他希望有一位专属老师的愿望。杀人回忆被他感受为梦，细节与责任却没有被删去，他承认恶鬼与自己是一体。路明非从中想到自己的暴虐状态，先把两种情况联系，再由对话发现两者并不相同；相似经验不能代替具体理解。

第 113—124 段恺撒愿意带早餐、保护盟友，同时明确若对方再次在眼前杀害无辜，仍会阻止。源稚女认为保护承诺轻率，又道谢；怀疑和需要这种承诺可以同时存在，关系不必先被证明绝对可靠才发生。

第 125—160 段绘梨衣开始能够自己出门，源稚生改变照管方法，让她在风险中获得一点自由。他把送花理解为不知悲伤、只懂礼数，这是他的判断，不能直接替女孩裁定内心。随后回忆橘政宗：可乐不是随机的温情道具，而是源稚生喜欢却因贫穷不肯承认的东西。对方不追问便看见这种需要，才使他把对方当成可能的父亲。关于离开黑道去国外生活的许诺，仍需保留此时回忆者的信息范围。

第 161—190 段排斥、被当仆人、独宿体育馆与没有喝彩的毕业典礼逐层积累，橘政宗盛大到来才获得意义。源稚生希望凭成绩而非暴力证明自己，却最终在黑道权势的迎接中找回位置。可乐、同行与极简短的答应使宏大的势力变成私人关系，不宜只摘出该来的人总会来而省去前因。

第 191—218 段源稚生说没有什么可后悔，也认可共同事业；刚一想起当年询问对方有没有孩子的自己，却仍痛彻心扉。叙述让接受现实的道理与未被安抚的疼痛相邻。未完成装饰的刀成为遗物，又把他推回弑神使命。他最后提出下一代幸福值得这一代流血，这是丧失之后的人物决心，后文将检验它的代价。

### 第十六章　神陨

阅读范围：第 1—452 段，章节 ID `b3c93134-f7ff-4119-801e-273ee7bbc753`。

第 1—77 段工程机械与防御安排先把屠神写成可操作的现代工程，随后内部背叛使部署失效。阿须矢把力量与杀人看成美，甚至把少年宫想象成大师隐居地；这种强者想象首先属于他。被认为平庸的龙马家主在无法说话时以敲击发出消息，反而使敌人也承认他的觉悟。价值不是只由履历、锋芒或自我宣称决定。

第 78—133 段宫本志雄起初慌乱，辨清问题后才进入自己的专长。考试习惯说明他为何在倒计时中更能思考，却没有使他免于遭暗杀；他仍需要另一个人的实际救助。他为最好的点子没有热情听众而略感遗憾，给悲壮的自我牺牲保留了小小虚荣。女孩直接说他将死，他仍郑重报上姓名、送出长刀，短暂的并肩不因结局已知而失去意义。

第 134—207 段脱衣麻将用亡国式的夸张讲内裤危机，楚子航却在具体牌局里替恺撒承担损失。广告把玩笑场所变成围困地点，芬格尔的吃与烂话也是害怕时让自己不崩溃的办法。源稚生看穿两个事件同时发生的目的，仍选择去红井，并授权必要时杀弟；使命的选择有明确对象和代价。

第 208—268 段零的战斗先通过阿须矢的审美呈现为舞蹈，对手不在意同伴受伤，关心的是能否看到更漂亮的杀法。他执着排名，零却以为在问绩点。突如其来的暴力膝击打断他期待的仪式，喜剧来自双方认知与目标差异，不是旁白任意插入笑话。

第 269—297 段宫本志雄开井时的欢呼并未让后续场面全然成为胜利庆典。旁白明确称龙族亚种的死亡为屠杀，又说明放它们进入人类世界也会形成灾难；源稚生能从龙的角度想到被圈养的痛苦。零流鼻血、跛行后，读者才知道她已经耗尽体力，以受伤换胜，狙击手错失了机会。她坚持满三十五分钟，是履行对死者的约定。源稚生不正式道谢，却扔给她急救包，两人交换长刀，关系落实在动作上。

第 298—376 段恺撒的镇定既是谈判准备，也因为等得无聊。芬格尔用家主情史施压，风魔却公开承认欲望与荒唐，包括吹牛、私房钱和对年轻女性的迷恋。他的责任意识没有要求先把这些部分删除，叙述也确实尊重他准备为家人与家族赴死的意志；不能把他转述成毫无缺点的长者。

第 377—407 段零扶着风魔既是劫持，也是因为受伤站不住。风魔把放手理解为信义，路明非认为只是因为人质已无用，两种解释并存，读者又知道她刚刚履行过对宫本的约定。芬格尔抢着接人，实际想续挟人质，漂亮救援姿态再次被实际目的改写；风魔以自己也会被射杀的命令证明威胁并非虚言。

第 408—452 段路明非误以为老板娘不知刀枪危险，主动挡在前面，随即被苏恩曦推开。她的威仪、金钱关系与一个电话解决僵局，但前文已经埋下幕后经营。结尾的白莲花形象属于路明非此时的惊艳；下一章会继续改变这一观看距离。

### 第十七章　老板娘

阅读范围：第 1—206 段，章节 ID `dd45c8ba-2d40-463e-9289-f0403713845e`。

第 1—59 段门一关，苏恩曦的女王气场就落回众人的盘问。多重身份和大额资产产生喜剧，也解释她能庇护他们的现实条件；并非纯靠漂亮与气势压服敌人。她怕酒的样子原来是假，醉酒却是真的，背后的麻衣知道她曾经的狂歌痛饮。她留下车钥匙，使受庇护者仍须自己决定去留。

第 60—100 段源稚女提出谈判，不只是因为需要哥哥的力量，更是想重新成为他的同路人。他不否认自己做过的坏事，也不把过去全归给血统，愿承担可能被处决的风险。关于有些人无论如何都想和解的说法，触发路明非对叔婶六年生活的回想；削皮挖核炖梨汤使这份关系具备日常依据。长大与和解的判断有明确人物经历，不能抽出来强迫所有受伤的人原谅。

第 101—117 段讨论选择的代价时，电车难题再次出现，源稚女是否可信仍无保证。昂热的强硬言论帮助他们行动，但恺撒明确承担错误后果，承诺不是替未知结果预先宣布正确。芬格尔只想混饭却被卷入责任，保留了集体举杯中不那么庄严的一面。

第 118—143 段零确认大家不会撤离才请求医生，随后倒下，重伤严重程度终于被揭示。她并非不痛，而是害怕无用便会被抛下。先前的无表情、独自完成任务和持续清醒因此被重新理解为付出与旧伤，不能只当作强者魅力。小说中的手术与饮酒细节属于虚构情节，不应转为现实医疗知识。

第 144—164 段楚子航把安全与爱情区分，指出零信任路明非；路明非看她睡着，又把她想成无悲无喜的木偶，甚至猜测独舞与选舞伴是为了建立威信。读者刚刚知道她会害怕被丢下，也读过冰海经历，因此不能采纳他的全部判断。他拉窗帘、调整被子照顾她，同时承认自己并没有爱情，关心不必被归并成恋爱。

第 165—184 段老板把零称为盾，仍以她会死而路明非安全来解释安排，温情与把人置于牺牲位置的逻辑并存。红井的华丽火光之后，源稚生并不快乐，只想到未能了解便死去的人；巨大成功对他已经失去意义，妹妹不必上战场才带来一点开心。

第 185—206 段樱井七海守着龙马的遗体，使源稚生重新看待此前觉得可笑的情史。他从看不出表情转向感到悲伤，承认平庸者也可能拥有值得眷恋的部分。名誉与赌气在死亡面前退后，遗憾落在没有更多时间说话；正是看见这对旁人的关系，他才决定亲自与弟弟谈。这段把理解他人的变化转成下一步行动。


<a id="chapter-84"></a>

### 第十八章　风与潮之夜（II）

阅读范围：第 1—572 段，章节 ID `d430a0b3-306c-438e-adff-ec6aede7cbab`。

第 1—60 段谈判需要普通客人提供不能随意开火的环境，于是叙述离开主角，耐心写来客的职业、婚姻压力与被牛郎吸引的各自原因。中岛早苗不愿从设计师变成家庭主妇，千夏在政治联姻和私人欲望之间自作选择；她们虽被写得夸张，也有自己的生活。婚约双方的长辈竟同赴一间店，使笑话由关系交叉形成。

第 61—142 段清场被盛大派对破解，真正黑道混在仿黑道的表演中。源稚生明知短剧粗糙、对白滑稽，却被陪伴的主题触动。狂欢不只被揭穿为孤独，也确实让孤独的人感觉暖和；歌词和旧事把他带向自己尚未失去的弟弟。作品中的歌词只作为场景因素分析，不在本记录中复制。

第 143—184 段源稚女化妆是为了撑住谈判者的形象，话说到被哥哥杀死时却哭花了妆。他渴望亲近又有怨恨，两者都不因准备和解而消失。路明非认同亲人不应被轻易舍弃，又无法否定公理的重要。谈到表演之后，他猜诺诺早已看穿自己，进一步把她与陈雯雯等同，这是受伤者的推断；不能因此替两位女孩确定全部动机。关于抢电脑、扔纸团的回忆，使堂弟的烦人又成为曾经有人相伴的证据。

第 185—209 段视点转入哥哥，才揭示他来这里也在寻找和解的机会。此前说要杀弟与此刻想拥抱并不简单互斥：杀人现场与噩梦长年困住他，他害怕恶鬼，又无法舍弃陪伴过自己的人。双方各自练习、抽烟、掩饰紧张，读者因看见两边而比他们更明白重逢的意义。

第 210—295 段灾害摧毁派对与防御秩序，气象局的短暂独立视点让普通工作人员也进入故事。宫本泽制止向年轻接线员追责，命令同事逃生并沿途告警，自己留下记录数据。辱骂式命令背后有具体保护与分工，不只是装作嘴硬。源稚生发现自己无法以皇的力量抗衡海潮；苏恩曦被风魔误认为吓坏的小女孩，后文还会更正这一解释。小说中的灾害与科技细节均属于虚构世界，不据此提供现实避险知识。

第 296—324 段源稚女在受控恐惧中仍用身体替路明非挡伤。路明非先想自己不值得对方这样付出，对方却把他认作能够杀敌的人，托付因此变得沉重。他反过来提出活着是为了幸福与重逢，把眼前目标从杀王将转回楼上的哥哥。愿望使源稚女重新移动，却没有治疗失血，后面的体力耗竭仍会到来。

第 325—354 段苏恩曦的惊恐被重新解释为财务损失与脱身策略，她确实不专精战斗，却能用枪保护自己。老板也承认事态超出预估，但要求只保护路明非。苏恩曦先照顾各方安排，忽然发现自己忘了零；平日过于能干、从不求助的人反而容易被忽略，这一遗漏与前章零害怕无用的自述相连。

第 355—410 段芬格尔贪床、怕死、说荤话，却在零打算损坏膝盖突围时坚持自己充当双腿。零明确说自己不是谁的女人，叙述没有只能以爱情解释救助。互相把命交给对方、狗叫逗笑与身体配合，使她罕见地不排斥接触，并想起曾有人这样逗她。格斗既凶猛又滑稽，枪手视点先把两人认作怪物，后续再解释组合与钢板。最后也交代对普通枪手使用非致命攻击的限制，不能把疯狗式外观等同于毫无边界的杀戮。

第 411—452 段路明非累到想放下源稚女去找人，感到肩上的手仍紧扣，便继续背着他走。细节承担了不抛弃的选择，骂声和混乱音响没有抹掉疲惫。堵耳只能部分减轻梆子声，意志仍须付出实际劳动。到了出口又被死侍拦住，努力与回报不成正比，路明非质问弱小为何不配活着，随后在魔鬼冷笑中接受强者才能生存的念头；这是绝境对他的逼迫，不能抽为整部作品的伦理答案。

第 453—475 段源稚女揭示自己并未一直失神，而是害怕被留下；继而主动取出耳塞，接受恶鬼状态来救路明非。他失去的正是以原本模样见哥哥的机会，牺牲与其此前愿望直接相反。叙述一面强调变身后的残酷可怖，一面让他最后辨认朋友、告别并主动远离，保留两种意志挣扎的过程，不能简单归为从来只有恶鬼。

第 476—550 段哥哥为保护更多人撤离，知道每一分钟有人死去；终于见到弟弟时，所见却足以使他认定一切都是陷阱。读者知道弟弟此前救人的经过，因而不能跟随哥哥抹去那部分。战斗中忠勇者的牺牲未能换来强者反击，使源稚生对自己的资格发生怀疑，力量与正义的旧有连结开始崩坏。

第 551—572 段风魔重新叫出樱井七海旧名，急促说出当年放手的原因。叙述保留他大男子主义、命令式的说话习惯，又让衰老脸上的神情像少年；感情不是洗掉旧性格后才出现。他把自己也列进可被牺牲的人，最后反击失败。七海不回头，可能是坚忍，也可能怕回头便无法离去，叙述明确留下两种解释，没有替她用一个性格标签封口。


<a id="chapter-85"></a>

### 第十九章　达摩克利斯之剑

阅读范围：第 1—752 段，章节 ID `a1fa6c70-33cf-4b5e-9fee-b66a1829b4ae`。

第 1—78 段把知事的怯懦、政党的威胁与后来被援助打动的真情连在一起。他并非一开始就是舍身领袖，但被迫留下也不妨碍他随后流泪。研究员在危险中的宅趣、骂声与技术本领同时成立；昂热把人骗来，副校长当面指出他们也有家庭，幽默没有消除这项强迫。

第 79—178 段救援、技术奇观与庞贝的表演交错。毁灭性武器的模拟影像被写得静谧美丽，继而显露令人战栗的破坏，壮美并不天然意味着正当。庞贝说保护儿子，又以轻浮口吻托人转告爱意；他提前布置的控制力与父亲的动机并存。世界观中的科技说明属于虚构设定，不作为现实技术资料。

第 179—212 段昂热解释自己的正义与仇恨，源稚生则不断追问。寒冬与骤然到来的夏季概括漫长生命，背后已有朋友全部丧失的具体过去。他的话强烈、完整，却仍是一个复仇者的立场；源稚生想到风魔关于普通人爱恨的遗言，使读者同时听见另一个解释。谈话没有以师长作结就获得全书裁决权。

第 213—238 段视野移向堵在道路上的车辆，每个车窗都是一出家庭剧：父母安慰孩子、小夫妻相靠、老人擦泪、少爷开车带保姆逃生。源稚生羡慕的不是这些人安全，而是他们在危险中仍有人相依。叙述说他们都将死去，依托的是源稚生对局势的判断，尚不是已经发生的结局。两位血缘父子在路上多看了一眼却擦肩而过，读者所知超出人物所知。

第 239—276 段交接权力写到名单、密码、钥匙和继任者，承担责任有实际手续。对鬼的政策也由单纯清除转向在保护无辜前提下予以照顾。送绘梨衣离开，则把壁画中征服世界的皇帝与角落里抱膝的女孩相邻放置。哥哥承认照顾她夹杂着替代弟弟的需要，随后交出护照、银行卡，帮她换衣御寒，才把自省落实为自由。早已准备多年却迟迟没有执行的出路，说明爱与控制可以共存；此刻终于不让她充当武器，是明确的选择。

第 277—312 段昂热并非不知道武器的时间弱点，侦察损失加重了无法锁定敌人的困境。源稚生主动承担拖住敌人的任务，昂热向他道歉，修正了此前对不成器学生的判断。学生想交朋友却来不及，想被老师骂一次，师生关系便从战略部署中显露出来；最后关于大义的提问没有得到直接回答。

第 313—401 段白色丝状物远看如积雪，近看却让山林枯死；王将以诗人语气赞颂的诞生，在工程人员眼中是腥臭、恐惧和杀戮。不同观察者给同一景象不同价值。神的测试以连续失败的阻拦抬高力量，直到风间琉璃亲自厮杀。旁人认为他比神更不该存在，叙述却在血肉损坏后留下一句他仿佛在等人，使恐怖外形仍与先前的重逢愿望相接。

第 402—469 段昂热期待上杉越助战，发现他只想逃，先严厉羞辱；体检报告与上杉越关于母亲、法国、小住所的长段自述，才使这位强者成为衰老的普通人。昂热认出父子关系，却没有用尚未相认的孩子逼他留下，而把自己的飞机交给他。随后的告别又有反转：研究员看似敬重英雄，实则准备抢走剩余飞机；昂热识破后毁掉飞机，断其退路。同一个人既能成全老友，也会强迫同事，不能把其中一幕概括成全部人格。

第 470—499 段城市生命被写入失灵的宣传车、无法买到的啤酒和误入街道的小鲸鱼。副校长要漂亮姑娘的轻浮开头，转成师生关于死亡的对话。他担心儿子并准备不合年龄的维尼熊礼物，显示笨拙牵挂；下一刻又决定必要时牺牲城区。亲情没有自动保证其决策温和，Eva甚至用平静口吻指出这种残酷。

第 500—558 段路明非躲在酒窖并非完全没有思考，他借电影经验避开出口、遮掩气味，也知道再次交易的代价。绘梨衣发来的简单话因两人相处的记忆而变得沉重。路明非先为私人飞机兴奋，确认女孩确实喜欢自己，继而拒绝让她绕道冒险；关心与不愿承受过深感情同时成立。他胡诌山路、海棠花与冰淇淋，既敷衍又舍不得结束唯一的陪伴。想象女孩为自己哭的虚荣，也没有被保护她的决定洗掉。

第 559—625 段救援者眼中的路明非近乎失去意识，随后才揭示他是在装死。女客的职业、性格和婚约关系延续前章，成为识破骗局、处理伤口、彼此较劲的具体能力；她们不只供主角欣赏。座头鲸即使在积水中也按职业习惯报酒单、问加冰，以镇定掩护恐惧。轮到向路明非求援时，他既诚恳又撒谎吹捧，叙述明说动机是救客人，并不假称完全信任。路明非的羞愧又由交易需要付出生命的事实承重，不能简单用怂字结束判断。这里涉及的急救和饮酒桥段只作小说场景阅读。

第 626—637 段连续留言把绘梨衣对陪伴的需要具体写出来。路明非认为哥哥已经安排妥当、自己只会提供心理安慰，于是删去回复并关闭定位；这包含保护意图，也包含对情势的误判。地图随即推翻安全判断。不能截取他关于好男人和甜言蜜语的内心结论，作为叙述者已经确认的普遍准则。

第 638—683 段神从威严巨兽变成寄生生命，壮美、丑陋与实际力量不再对应。工程人员欢呼进化，叙述补出他们被家族放逐的生活，使怨恨有来源；但受害经历并没有阻止他们成为施暴者。神被切割时保留注视与金瞳熄灭的过程，暴力的对象也获得短暂的感受位置。随后对寄生宿主的恐怖描写则让追逐力量的人亲见代价。

第 684—752 段兄弟对战间穿入童年篮球、唇语和猴王故事，昔日陪伴成为仍能沟通的通道，也成为怨恨的内容。威力对比与刀光之美确实得到充分展示，不能把全部战斗当作抒情的装饰。直升机下源稚生不退，死亡判定又被龙化归来推翻。源稚女面对哥哥死亡的空白来自被压制的依恋，而非原本毫无感情。斩鬼人终于成为鬼，回想被自己清洗的人，承认此前不懂他们的黑暗；这改变了他的认识，却没有直接清偿过去的杀戮。


<a id="chapter-86"></a>

### 第二十章　漆黑之日

阅读范围：第 1—385 段，章节 ID `73ce821a-31cf-4bbe-9d49-1e4f4dce2688`。

第 1—25 段机场送别把灾难落到有限机票、紧握的手与玻璃上的唇印。叙述先沿上杉越的目光看尽生离死别，再进入绫小路熏的恐惧与职责，修正老人以为她不知道危险的认识。此前短暂出现的海关职员仍记得昂热，希望把自己认为美好的东西送离灾难。女孩不肯舍弃猫，在大人的效率判断中是耽误人命，老人却看见她的生活只有少数相伴之物。关于陪伴的感叹因此有明确的冲突和对象。

第 26—55 段儿子的消息使上杉越失态，随即问出一串旧日女性的名字，引来昂热骂他；激动没有把人物忽然变成清心寡欲的圣人。儿子吃过什么苦、是否被欺负、有没有喜欢的女孩，才是父亲立刻在意的事。叙述明确交代昂热打电话是怕秘密随自己死去，并仍想成全老友回法国的愿望，不应把这次告知解释成已证实的诱敌手段。

第 56—78 段三人的战斗能力分别落实为引诱、火力、耐心和配合，幽默的斯巴达对答发生在彼此承认危险之后。恺撒喜欢宏大热闹，这里对英雄姿态确有欣赏；不是每一次盛大出场都会被取消。昂热愿亲自放血吸引尸守，也使其要求别人承担风险的行为获得另一部分证据。

第 79—111 段知事试图表演可靠领袖，女儿的电话却把假定的市民变成与自己相同的父母。他在直播中说出真实愤怒，也揭穿了政党威逼与高官逃亡，随后失控。真情并未自动变成有效领导：后文机场人群正因这段讲话陷入混乱。樱井秀一知道所谓自愿留下的研究员实际被毁掉退路，这个插入判断保留了公开叙述与实际经历之间的距离。

第 112—171 段临战闲谈谈到婚约、私章和折刀。昂热说自己想活，给出的理由是他还记着死去的朋友；后续内心也确认并非单纯安慰学生。楚子航在布置炸弹时想到夏弥与芬里厄相依的世界，眼前焚毁之景触发的是自己参与造成的另一场毁灭。回忆没有使工作停下，他仍转回去完成任务，悲伤与行动在同一段时间里存在。

第 172—217 段昂热以居合迎战时想到犬山贺，把技巧的美与失去学生的遗憾连在一起。叙述对山海般的刀光、古老敌人的身体和力量都真切着迷，继而通过体能与着力条件让强者失败。恺撒以电影惯例猜测老人准备牺牲，叙述明确修正：昂热确实想杀掉敌人再会合。终于允许认输的瞬间，先前一生不能认输的责任才显出疲惫。上杉越的帝王出场又被急问儿子姓名拉回日常牵挂，威严与焦急互相照亮。

第 218—234 段倒叙返回机场，补齐老人回来的原因。知道自己有儿子，使原本疏离的世界重新与他相连，进而听见别人的悲欢。他帮助女孩、猫与工作人员登机，保护并没有只停留在亲生孩子身上。强吻女孩仍带有作品的男性浪漫化与冒犯，女孩随后品出叉烧味，把庄严觉醒又落回拉面师傅的身体身份。

第 235—261 段两位老人一边抵御尸守一边谈儿子，漂亮、聪明、固执、招女孩喜欢这些普通问题，占据危险中的耐心。昂热知道的悲剧没有全说，既不忍伤父亲，也担心失去战力；同情与利用的考虑同时明示。他想吐槽老友凭空认儿子，最终因理解父亲的心情而没有说出口。叙述继而回望那个被儿子厌弃的棋圣父亲，重新打开此前被单向评判的关系。

第 262—304 段黑日的威严被充分铺陈，价值连城的古刀被用钝即弃，力量有持续消耗。昂热判断老友懂得取舍，会放弃拖累的自己，上杉越却坚持是来救他。不能把前段关于强者必懂舍弃的话当作本章答案。父亲关心有儿子的世界，进而托付能守护这个世界的老友，私人感情具体转向了公共行动；同时，昂热被扛在肩上像个孩子，转换了长期替别人承担的姿态。

第 305—339 段上杉越讲述阴谋判断与信仰，昂热不断以疲惫和玩笑打断，使议论仍是不同性格的人在说话。信仰上的分歧没有妨碍祝祷，他请求神护佑那个注定不肯悔改的复仇者。扔出昂热之后才揭示水下龙蝰，读者重新理解扛人的动作不只有搀扶，也在保护老友。此前看似无损而年轻的身体，并不能证明他没有付出代价。

第 340—374 段刀术写到轻柔、自在与主动反攻，恺撒一度认为老人真能杀出来。等回望背影，才发现龙蝰早已咬住失去保护的后背；超凡美感与不能生还的肉身同时落定。叙述明确赞许他此刻像真正的皇帝，却仍保留前半生的恶与后半生的庸碌。死亡有意义，并没有使旁人不再悲伤：昂热落泪，回忆再次失去朋友，努力把最后一幕记牢。庄严不是用一句无悔就结清伤痛。

第 375—385 段指挥中心庆祝炸弹奏效，读者却已看过胜利所需的个人死亡。副校长以自己不能继任的玩笑表达老友仍可能回来，又把注意转向尚未解除的危险。战场哀悼与远处喜悦错开，结局没有被一种整齐情绪覆盖。


<a id="chapter-87"></a>

### 第二十一章　小丑

阅读范围：第 1—193 段，章节 ID `4a89b5a7-52e6-4ddf-aff5-d59fefa3a758`。

第 1—19 段风间琉璃讲看流星雨的旧事，毡毯、望远镜、登山鞋与留到晚上的梅子饭先写出准备的认真。后来他吃得极慢，是怕吃完便证实再也看不到流星雨；物件因一个孩子的信念获得计时作用。源稚生说小时候也烦他的敏感，弟弟则指出哥哥总在教训、很少听他说话。怀念并非无瑕的童年滤镜，旧日不平等仍在当下对话中重演。

第 20—37 段风间琉璃一面复述强者吞噬弱者的准则，一面亲手毁掉足以成王的圣骸。他要毁灭的欲望与反派要占有的欲望并不相同。对兄弟互为正邪镜像的说法来自角色；接下来的梦境会继续破坏这套整齐划分。极恶形象拥有的言灵却首先表现为空灵歌曲与草木气息，力量不只以外形和杀伤力定性。

第 38—74 段梦中岔路分别通向杀人现场与等待哥哥回家的弟弟，叙述明确两者都真实存在。小镇的长草、石地藏、遮雨树叶、灯笼、体育馆与秘密基地构成具体记忆；极乐馆的地下迷宫也被追溯到这间童年地下室。所谓没有长大，不是抽象性格标签，而是记忆、怨恨与建筑空间持续重复同一个地方。源稚生最后走向杀弟之处，不是轻易选择没有犯罪的另一面来和解。

第 75—85 段哥哥的回忆补出为生日礼物学开直升机的努力，以及当时盼弟弟欢喜的目光。弟弟却因最好日子终会过去而哭，源稚生曾嫌他愚蠢，如今在绝境中才认同这份恐惧。关于幸福额度的说法由特定人物与当下处境产生，不能当成创作必须遵循的世界规律。天空、树林、飞机的童话感先真正成立，失去才有所指。

第 86—113 段梦境由血滴、积水与尸傀儡转为杀戮空间。皇的身体在这里不能保护一颗仍停在十七岁的心。风间琉璃完成复仇后试图离开，楼梯却不断把他送回哥哥被杀的地方；他由控制梦境的施害者变成被梦境困住的孩子。胜利没有解除恐惧，反而让恐惧失去最后的依靠。

第 114—134 段黑屋中哥哥的呼吸声解释了童年安全感，回到染血浴缸后，同一胸膛的寂静便具有不可替代的重量。梦境交叠让弟弟理解哥哥也从未离开杀弟之夜，哥哥一直想象死去的是自己。感情通过认识改变进入剧情：被压制的少年重新出现，恶鬼的人格消退，梦也随之解除。但这次理解来得太晚，现实中哥哥已濒死，不能用心灵突破自动换取圆满。坚硬外骨骼被悲伤撑裂，是幻想身体承载情绪的夸张具象。

第 135—159 段王将的舞步与服饰被写得精确、优雅，欣喜却与兄弟的血泊冲突。叙述直接质问怎会有人在别人的鲜血前这样欢快，评价并不隐退成摄像机。面具反复戴上、摘下，将两个权威身份合成同一个操纵者；之后敲烟与抽烟的动作又使长期隐藏的文化习惯显露。身份揭露通过身体和表演发生，不只有口头宣布。

第 160—179 段博士的长篇讲述同时承担揭谜与炫耀，他甚至主动更正自己是最了解龙之人的说法，承认邦达列夫更胜一筹。此前两种身份相互作证的材料被揭穿，说明阅读时不能把角色提供的历史直接当作全知叙述。绘梨衣的血缘使弟弟的嫉妒重新获得解释，但哥哥曾把她当替代品的矛盾感情没有因此被删除。博士关于养父给孩子吃住的评价也是这个施害者的说法，并不能免除此前虐待。

第 180—186 段对蕾娜塔的回顾把冰海中的照料与舍弃直接接回当下操纵。博士揭示兄弟隔阂与暴戾人格被人为制造，兄弟的悲剧因此不再是简单的血统天性：他们被有意安排为敌。博士以伟大时代、战争和进化作许诺，叙述让这些宏大说法与具体孩子的痛苦相对。有关手术、人格与催眠的说明属于小说世界观，不用作现实心理或医学知识。

第 187—193 段绘梨衣的出现令揭谜转入新的危险。博士以创造者身份把女孩视为可占有和献祭的身体，其性侵行为揭开所谓贵族风度下的欲望；叙述在此明确贬斥贪婪的小人。最后，他发现圣骸被毁，无法理解有人会放弃王座，说明他的聪明仍受自身价值观限制。章节暂止在这个认知裂口，而不是已经解除危机。

### 第二十二章　樱怒之日

阅读范围：第 1—311 段，章节 ID `87ebf645-7737-4638-a936-c751b71e873d`。

第 1—25 段路明非先惊恐起身，酒瓶碎片的伤痛立刻使他意识到身体与能力的限制。他盘算谁值得用生命去救，以玩笑逐个排除，又把绘梨衣的喜欢解释成钱和包装造成的误认。这些泛化为女孩都会离去的句子，紧贴他的自卑与过往经验；不能当作叙述已经证实绘梨衣不懂喜欢。所谓谁也不欠谁的公平，和不断返回的焚烧梦境互相冲突。

第 26—48 段座头鲸锁门被路明非误以为逃跑，随后才发现是独自迎击死侍。高大的背影一度让他相信能赢，力量差距却没有因勇气而消失。路明非先出门送武器，再跳水开枪，并未等到理论上想通所有取舍才行动。救一个刚认识的店长，与此前只愿为极少数人支付代价的清单相矛盾；他回想跳水时根本没来得及计算。重要行为由眼前的人引发，不能只由人物预先声明的原则推导。

第 49—60 段麻衣现身救援时仍冷厉、嫌弃，实际也负责守住通道。她并非没看见此前危险，而是把路明非的安全放在所有人之上，连自己也可被牺牲。这让她的可靠与残酷同时成立。超常救治与战斗方式属于幻想情境，不用作现实急救方法。

第 61—84 段座头鲸在被写作临终的场景中还在讲花道，路明非一面难过，一面嫌他说得太蠢，觉得客人不过来消费。随后店长讲出便宜房租与遗嘱：一个自己早已忘记姓名的客人，记住了他年轻时招揽生意的志气话，并真的帮他获得第一间店。昔日虚言因此变成后来认真兑现的责任。路明非关于一切只是交易的判断被具体经历修正。店长把女人概括为笨、值得爱，仍是这部作品显著的男性情爱观，分析应保留其偏向，不能改写成完全中性的普遍规律。

第 73—95 段溺水中交叠的两次救援，终于让路明非认出海底抱住的是绘梨衣。她的喜欢由一次被迎向、被拥抱的经验开始，不取决于跑车和餐馆。叙述进一步进入女孩当时的感受，使这一点超出路明非单方猜测。在以为店长已经死亡时，他给店长戴回墨镜、安置在符合其身份的沙发上，尊重落实为整理身体和物件。麻衣递来车钥匙，他才发现支持自己的人比想象中多；千军万马先是队友带来的感受，末尾才转为怪物形态的真实景象。

第 96—130 段博士殴打源稚女时显出年老、怕死与失控，其威严部分来自替身和布置。源稚女嘲笑他不能理解自己要的重逢，由此暂时获得不屈服的快乐。但叙述刚说博士无法再伤害他，博士便转而威胁哥哥，使他重新绝望。求死者无所畏惧在本段也是被亲情立即突破的判断；不能摘出来当全书坚不可摧的格言。绘梨衣苏醒打断这场折磨，读者却尚不知道这次苏醒意味着什么。

第 131—152 段天谴的准备与井中苦难交叉。副校长认为井里的人已是怪物、在人类世界没有位置，读者却刚看过他们各自的生活与牵挂，这个距离使一句战略判断显得冷酷。更高权限中断发射，路明非被称为另一套屠龙系统；被援助与被工具化仍在同一人物身上发生。

第 153—205 段救援路上他想听雄壮的歌，车里却只有麻衣的悲伤歌曲，于是又猜到这个强悍女人也可能爱着无法抵达的人。歌曲通过性格反差打开旁人的世界，不只是情绪配乐。本记录不复制歌词。撞车、步行、白丝灼伤与体力衰竭，使赶赴不是一句决心的跳切；体育老师的旧话被记起，又被他吐槽像人生预言。已经出发不意味着犹豫从此消失，他仍害怕交易，也盼自己只是多虑。

第 206—250 段路鸣泽把现实包裹成剧场，路明非以看表演的距离接受暴力和揭谜。熟悉的香味、衣服和手提箱不断破坏这个安全距离。直到女孩哭泣，观众才认出眼前不是可撤回的戏。幻想装置在这里处理的既是信息揭露，也是人物暂时无法承受事实的意识状态；不能只概括为一场华美幻觉。博士用进化、容器和医学类比说明掠夺，叙述同时保留被当成材料的女孩的恐惧，术语并没有覆盖她是人的事实。

第 251—268 段透明墙让认识先到、行动却不能到，悲剧的不可挽回被变成身体碰撞。路明非的假名仍是女孩最后求助的名字，羞愧来自她的真实信任与他的迟到。新的白王被写得完美、优雅，不因此获得道德认可。兄弟最后相拥的原因被保留为两种可能：既可能自己害怕，也可能不愿哥哥害怕；叙述没有把最后姿态解释成唯一正确的牺牲。

第 269—287 段他先用衣服包住身体，再小心取出寄生物，怕死去的人仍会疼，随后疯狂毁掉那截骨头。粗暴报复与细致照料来自同一段悲痛。魔鬼一面帮忙递工具，一面借迟到斥责他不用权力，宣称本可改变结局；这是诱导交易者的讲话，不能直接升格为作者要求主角接受强权。枯骨没有反应，报复甚至不能给他一个被反抗的对象，宣泄无法完成补偿。

第 288—301 段箱中衣物先让远行计划重新出现，再由明信片、拍下的背影与换过的玩具标签层层揭示女孩自己的记录。那些表达朴素，却都有共同经历作为内容。路明非从被另一个人注视的角度看回自己，理解不再只靠对方口头说喜欢。翻到玩具底部才发现共有标签，是一个微小动作引出整个私人世界的证据；豪华生活的公主形象被她实际珍视的少数东西重新解释。最终感叹有前文一整段物件和认识变化支撑。

第 302—311 段他选择把生命交给复仇，既为绘梨衣，也回应源稚女赌他能赢的托付。魔鬼明确说无法复活已死者，力量的出现不提供失而复得。此前想象的拥抱最后变成独自结茧，周围死者的龙化又把千军万马的说法实体化；盛大的力量场面仍以孤身作战作尾声，不能等同于关系已经完整修复。


后文核对：尾声第 71—75 段确认座头鲸在救治后生还，失去一条胳膊。《樱怒之日》的死亡外观是人物当时的认识与悬念，不能当作最终事实。

### 第二十三章　天谴

阅读范围：第 1—275 段，章节 ID `d584da8e-6e07-43de-8f59-10a9bb7b00d6`。

第 1—52 段先由飞行员和地面军官观察无法归类的敌人，依据已知机型、武器与速度不断修正判断。读者知道龙王存在，普通军人的努力和恐惧仍得到展开；他们不是一串用于证明力量的损失数字。接着进入赫尔佐格的感官，展示看见元素与世界版图的狂喜。力量之美确实被写得诱人，但他的享乐以杀人为内容，审美与伦理评价并不合一。航空与武器参数属于小说设定，不作为现实技术结论。

第 53—101 段芬格尔的抢劫叫嚷与零的精确操作构成喜剧，随后的破译能力又修正他只是废物的表象。双方都察觉对方有秘密，一度以枪相对，最后以玩笑说择偶偏好，达成互不揭露的承诺。亲密在这里被明确命名为朋友，不必解释成恋爱。零解析飞机时回到童年第一次摸枪的经验，成长使旧能力获得新的尺度；腿伤并未因任务重要而消失，爬进驾驶舱仍然艰难。

第 102—141 段零凭准备与能力拖住敌人，博士由轻敌转为思考，不是只会反复狂叫的固定靶子。战机燃料与弹射故障终结了优势，胜负仍受具体条件约束。零拿下陪伴多年的小熊佐罗，一面抱紧它，一面努力恢复滑翔；恐惧、依恋和工作同时存在。她想知道自己做得够不够好，承接此前害怕无用便被抛弃的心理。

第 142—174 段怪物的拥抱救下零，与冰海的契约和背负相呼应。她相信不会被弃，条件却始终是努力保持有用，叙述还明确说魔鬼并非天然重信义的人。这段温暖不能改写成从来没有控制的关系。麻衣认为老板会为了零提前破茧，是角色对其偏爱的判断；接着两位女性并不确定绘梨衣之死是否属于计划。与此同时，叔叔婶婶在地面用粗俗、日常的话担心路明非，普通家人不知道天空中的真相，牵挂仍然成立。

第 175—209 段路鸣泽谈女孩还没见过的世界，遗憾不在她没得到王座，而在普通的相爱与生活尚未开始。他对博士语言风格的嫌弃带有居高临下的讥刺，随后展示压倒性力量。博士后半段的狂吼被解释为掩护施术的表演，外表情绪并不总等于全部内心。言灵相互取消之后战斗转向兵刃，幻想规则改变实际打法。

第 210—253 段千军万马被抹杀，路鸣泽并非无所不能的救场装置；武器、血统完整度与伤势使他落入劣势。博士提议平分王座仍在找杀机，路鸣泽则用北极圈曾经发生的馈赠与焚烧戳穿慷慨。关于新王必杀旧王的所谓铁则紧贴这场争夺，不能等同于所有关系的唯一规律。最后他承认曾打算让绘梨衣死，却因不忍而修改安排；这证实先前麻衣的部分猜想，也把此次愤怒同时写成怜惜、兄长的悲伤与自身旨意遭违抗的暴怒，不能净化成单一善意。

第 254—275 段苦战把敌人送到天谴降临的位置，结局由个人代价、时间安排、现代武器与同伴接应共同完成。麻衣认定老板写下的死必然兑现，是她的敬畏；读者已看见计划曾改变且付出意外代价。胜利之后男孩没有高兴，城市灯火进入他的目光，他请求再看一圈东京。麻衣无法明确分辨面前是谁，也不知道该怎样讲话，于是没有说。叙述保留身份的不确定与失去后的沉默，没有用胜利宣言替代感受。


<a id="chapter-90"></a>

### 尾声 さよなら，Friends

阅读范围：第 1—134 段，章节 ID `a8d5707d-69cb-4c1f-bf72-462af7cdd338`。

第 1—24 段结尾先回到演出与领结。楚子航帮路明非系好领结，关照依然具体；路明非仍紧张、歌艺仍普通，并未因经历生死就擅长所有事情。观众所知的英雄故事经过记忆干预，读者知道这场公开表演与真实灾难之间的距离。她们的哭泣却仍包含真实失去的家人朋友，不能因为故事被改编便取消情感。告别用语引出没有约好再见的遗憾，再由歌曲回到雨夜赶路。

第 25—56 段华丽演出把城市重新联结起来，邻居开窗听歌，舞台上鲜花如雪。路明非在能力不匹配的伴奏中仍努力唱，欢呼却主要属于两位同伴。早苗与议员同行，千夏决定如期结婚，也承认恺撒是人生的过客；这些女性继续自己的生活，并非都停留在主角离去的时刻。芬格尔嘴上说大家圆满，后文马上展示这个热闹判断覆盖不了的部分。此处歌词仅作为回忆媒介分析，不在记录中复制。

第 57—64 段昂热代上杉越处理土地捐赠，写清用途、救济比例、监管与挪用后果。友情与纪念转为能持续影响普通人的安排；他仍用威胁的口气，也仍不信老友的宗教，没有因兑现遗愿而被改造成温顺之人。

第 65—84 段观众忽视路明非的花票，诱发他关于自己无人喜欢的旧判断。座头鲸忽然登台，尾声明确推翻此前看似已经死亡的场景：他因包扎和救治活了下来，代价是失去一条胳膊。路明非抱怨浪费感情，店长继续给病人发名片，喜剧允许生活恢复原有习性。死前般的郑重告白没有因此变成假情，活下来也不必改变他夸张的职业姿态。

第 85—104 段花票数字先给出不及格，再揭开额外支票，制造的不是简单逆袭。众人因天价支持欢呼，路明非只看见绘梨衣的签名，世界的热闹与他的寂静发生在同一刻。他扣着胸口确认疼痛，身体动作接住难以言说的情绪。支票证明女孩曾独自导航来找他，并试着用自己能做的事把他留下，补出主角未曾看见的行动。她已经去世，爱意仍以迟到证据抵达；获得最多花票并没有变成成功的补偿。

第 105—120 段临别的防晒油证明源稚生曾认真准备普通人生，不能把卖防晒油当作随口段子。赠给楚子航的旧刀又证明他在纷乱中确实查过朋友的托付；曾经压迫身体的武器，如今因故人的心意有了暖意。同一物件的意义由关系改变。恺撒没有删除与真合影的所有痕迹，而选择让诺诺知道女孩曾救自己，把此前想遮掩的暧昧转为承认救命之恩。

第 121—134 段象龟回到对话，指向源稚生没能抵达想要的生活；动物消息在此是小说的比喻回收，不据此说明真实动物史。芬格尔给零涂药，叙述表面仍调侃谄媚，读者已知两人在危难中形成的朋友关系。路明非看夜行列车，想起小怪兽的承诺和没有做到的保护；明信片上的简单话再次出现，结束于女孩曾经如何看待他。结尾没有替死者补发幸福，也没有让整座城市永远停在哀悼里，继续生活的人与无法填补的缺口同时留下。
