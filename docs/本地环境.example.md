# 本地环境说明模板

这是使用者或协助操作的 AI 可选维护的本机记录。需要保存环境检查结果、实际入口或故障排查信息时，复制为同目录下的 `本地环境.local.md`；已有记录则核实后更新，不覆盖仍有效的信息。该本地文件不提交 Git，首次部署无需先填写本模板。

安装、启动、备份与升级步骤以 [README](../README.md) 和[部署指南](部署指南.md)为准。本文只保存本机实际情况和必要差异，不复制维护者的机器配置，也不覆盖项目规格、依赖声明或锁文件。应用读取 `.env` 和进程环境变量，独立 embedding 入口读取 `embedding.local.toml`；二者均不读取本 Markdown，修改记录不等于修改实际配置。

未知项填写“未检查”，未执行的验证填写“未验证”，不适用项填写“不适用”。区分实机检测、用户提供的信息和待验证方案；记录日期不保证环境持续有效。密码、密钥、完整环境变量和含凭据的连接串不写入本文，只记录文件位置或配置来源。

可用内存、显存和磁盘空间是检查时的瞬时值。当前业务服务不依赖 embedding，无需 GPU；不因模板包含 GPU 字段就安装驱动或下载模型。用户要求准备独立 embedding 时，由 AI 按[部署指南](部署指南.md#ai-协助准备-embedding)检查环境、选择参数、试运行并告知用户，不由自动探测或调参器决定配置。

## 验证与限制

- 已执行的检查、日期和结果：未验证
- 尚未执行的检查：未验证
- 已知差异、阻塞与待准备事项：未检查

普通部署记录依赖安装、数据库连接与迁移、HTTP 作品读取、首次导入或搜索，以及所需 MCP 调用的结果；`/health` 成功仅表示进程可响应。开发时再按改动范围记录测试与静态检查，不要求普通使用者运行完整开发测试。

每项验证注明执行环境、日期、命令或接口、结果及限制；未执行或跳过不算通过。验证记录过期或与当前观察不符时更新当前结论，必要的升级、备份及回退记录可单独保留。
