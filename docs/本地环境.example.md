# 本地环境说明模板

复制为同目录下的 `本地环境.local.md` 后填写；该本地文件不提交 Git。只记录影响开发的环境差异，通用安装、配置和测试步骤引用 README，不重复维护。

此文件描述本机实际情况，不覆盖项目规格、依赖声明或锁文件。未知项填写“未检查”，未执行的验证填写“未验证”；记录日期仅表示检查时间，不保证工具或服务持续可用。密码、密钥和包含凭据的连接串不写入文档，只记录配置来源或文件位置。
