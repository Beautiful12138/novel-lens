# WebUI PC 阅读与标注视觉样稿

新的作品库单页视觉提案位于 [`studio/index.html`](studio/index.html)，启动下述预览后访问 `http://127.0.0.1:8765/studio/`。该页采用独立的中性浅色与钴蓝设计，展示两部虚构作品及图形/文字两类封面，可搜索、筛选与展开预览；视觉待用户确认。其余页面仍保留既有原型，不代表全站已经换版。

对应 [Spec 15](../../../specs/15-WebUI阅读与标注工作区.md)。沿用第二版交互结构，用于评审阅读、修订、标签库与标注库的排版和交互；视觉方案尚待用户评审。根目录、`studio/` 和 `experience/demo.html` 使用演示数据；`experience/` 通过本机业务服务读取真实数据。当前均不是生产 WebUI。

在项目根目录使用已有 Python 运行时启动仅监听本机的预览，例如 Windows 项目虚拟环境：

```powershell
& ./.venv/Scripts/python.exe scripts/preview_webui.py
```

打开 <http://127.0.0.1:8765/experience/> 查看真实数据，需要已有 NovelLens 应用运行在 `127.0.0.1:8000`。预览代理仅转发 `/library/browse` 和 `/source/read` 两个读取接口，不支持写入；不将数据库凭据或小说全文打包到前端。原文每页 40 段、标注每页 12 条，支持章节选择、完整标注说明与多处引用切换。停止预览使用运行它的终端 Ctrl+C。

以下操作属于 <http://127.0.0.1:8765/> 的内存演示，不调用业务服务。

## 可体验的操作

- 标签库独立浏览名称、定义、别名及分组，查看关联标注和每处原文位置。
- 标注库按作品、章节、标签、状态及说明文字筛选，查看完整说明与全部引用。
- 从任一引用跳到对应原文并高亮，返回保留条件、选中项、引用展开状态及滚动位置。
- 点击段落旁的标注入口或右侧标注，查看引用及说明。
- 修订说明、起止段落和关联标签；创建或修订共享标签。
- 新建标注，或拖选正文后建立覆盖完整自然段的引用。
- 撤回、显示撤回项并恢复；修改不改变小说原文。
- 通过“演示情境”体验保存失败、版本冲突、删除占用。
- 从作品库或阅读页删除演示作品；输入完整名称后确认。
- 检索固定样例候选，打开原文后返回结果；收起目录扩大阅读空间。

内容和状态均为演示数据，只在当前页内存保存。刷新或“重置演示”恢复。标签在演示中独立创建，因此取消标注草稿仍保留已创建标签。两部样例作品中的小说文字为本轮专门编写，无真实小说素材。

仅面向 PC。视觉样稿检查过 1440 × 900 与 1024 × 720 桌面窗口；生产框架尚未选定。本轮多引用修订只改变当前引用并保留其他引用；引用增删、真实分页和网络恢复等边界见 Spec，不将当前模拟操作视为业务验收。


原型以逐条核验分析为默认流程。正文与标注独立滚动，进入编辑收起目录并加宽右栏，保存/取消固定显示；已选标签、候选选择与共享标签维护分开，删除通过“作品管理”进入。只有实际内容变化才提示放弃草稿。阅读以鼠标点击、滚轮、拖选完成，不开发专门的键盘翻页。
