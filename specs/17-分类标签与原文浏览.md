# 17 分类标签与原文浏览

状态：已实现并完成工程验证。取代 Spec 13–14 的统一召回链路，修订 Spec 04、08、15、16 的标签和浏览契约。原文、标注、标签身份与分析进度保留；历史迁移不重写。

## 目标与边界

创作参考通过作品范围、分类、标签与标注找到原文。服务提供可浏览的阅读入口，不判断文学适用性，不以接口成功或阅读数量证明创作改善。移除 reference_query 的语义/字面融合、排名和搜索快照；创作不再依赖 embedding。

六个固定分类：content（内容选择与展开）、perspective（视角与信息）、interaction（人物与互动）、language（语言与声音）、structure（节奏与结构）、emotion（情绪与氛围）。分类不能由 AI 新建；一个标签可以属于多个分类。未分类是 categories=[] 的查询条件，不是第七个可写分类。全部标签不限分类。

作品整体与跨片段比较按 Spec 18 单独通过 kind=comparison 定位标注，不把观察范围混入写法分类。不要求每条标注、每段原文覆盖所有分类；已有标签没有归类仍可查找和读取。

## 标签与写入

标签继续全库共享，categories 保存去重、排序的固定分类 ID。标签创建与 prepare_batch 创建新标签接受分类；精确复用已有标签不隐式改写共享定义或分类。修订通过 tag_update 的当前版本和请求键完成，分类、别名与定义在同一事务内保存。默认业务 MCP 开放 tag_update，保留版本竞争和幂等规则。

迁移增加分类字段及约束，并关闭旧统一召回的派生索引触发器，避免产生无人消费的待办。旧标签初始化为未分类，不猜测归属。现有标签分类先生成预览，运行库归类与部署另行执行；不删除模型文件、原文、分析成果或共享数据库索引数据。

Spec 09 的独立关键词接口继续保留；Spec 10 的语义维护接口和模型运行依赖按 Spec 19 退役。0017 清理旧派生检索数据，不改变标签与分析成果。

## 浏览契约

扩展 library_browse：categories、tags、annotations 支持 work_id（单作品）或 work_ids（非空多作品），互斥；省略表示全部可见作品。分部/章节筛选须指定单作品，且核验归属。分页绑定全部过滤条件，compact/full 不改变成员。

- categories 返回当前范围有有效标注使用的分类及去重标签数、标注数，另提供未分类计数。一个标签可在多个分类出现，身份不变。
- tags 可按 category、namespace、query（名称、定义、别名字面子串）过滤；category=unclassified 只取空分类。默认可浏览共享词表，包括尚未使用的标签；指定作品范围时只返回该范围有效标注使用的标签。每项的 annotation_count 仅统计请求范围内有效标注，不包含屏蔽作品。保留全库词表是分析 AI 查旧复用的必要能力。
- annotations 默认 status=active，可不选标签直接浏览；tag_match=any 默认命中任一标签，all 同时命中全部，结果去重；列表返回作品名、部章名、标签、观察摘要和第一处引用，详情返回所有引用及人类可读位置。有效标注、撤回标注与屏蔽作品按明确规则过滤。
- 作品认识入口在 annotations 视图按 kind=comparison 查询有效标注；与 observation 共用资产，不依赖特殊标签。
- 原文始终通过 source_read 按稳定坐标读取，并按内容补上下文；多处引用不拼接为一个场景。

Spec 20 为标注列表增加 title、scope_note、note 字面 query，原文读取与引用支持章节内段号寻址，并提供普通 HTTP 对等入口；原有作品隔离、状态过滤和引用范围相交规则保持有效。

## 界面与 Skill

WebUI 沿用现有阅读和资产库风格，移除自然语言原文召回页；浏览页提供作品范围、六类/全部/未分类、标签选择和标注列表，点击引用进入原文。分类数量不是文学质量排名。

分析 Skill 复用标签、必要时创建并归类，不为了填分类制造标注。创作 Skill 先按任务探索适用材料，阅读后确定依赖参考的方案；允许返回换标签、直接浏览标注和沿目录连续阅读。标签和标注不能变成创作公式，原文仍是理解依据。
