# 15 WebUI 阅读与标注工作区

状态：正式 WebUI 已实现阅读工作区、标签库与独立标注库；沿用早期三栏布局，视觉统一打磨后置。既有原型保留供对照，不作为正式功能验收。

依据：[需求基线](../docs/小说分析与创作知识服务_需求与设计基线.md)第 21 章、[标注与标签契约](04-分析标注与标签管理.md)、[作品删除](11-作品屏蔽与物理删除.md)、[自动准备](13-自动准备与统一原文参考.md)、[阅读与召回](14-阅读返回与多作品召回续查.md)。


## 0. 正式实现第一期

- 前端使用 React、TypeScript、Vite，源码放在 `web/`，npm 锁文件固定依赖；生产构建输出到 Python 包内 `webui/`，由现有业务服务同源提供 `/ui/`，不依赖 8765 预览代理。仅本机 PC 使用。
- 本期入口为作品库与阅读工作区。作品、目录、正文、标注均读取真实 HTTP 服务，不包含演示数据、模拟保存或占位管理按钮。独立标签库、标注库、检索及写操作后续逐步实现，不因首期范围取消整体目标。
- 作品列表分页；分部和章节目录按需分页展开。正文每页最多 40 个完整自然段，可前后翻页；章节切换和引用跳转具有稳定 ID，刷新可重新打开当前作品与章节。
- 标注侧栏默认列出当前原文页引用相交的有效标注，可切为全书；列表每页 12 条，明确页内范围，选择后展示完整说明、真实标签与有序的全部引用。不同章节标题相同时同时显示分部名称。
- 从标注打开引用时显示真实引用范围并分页读取，不将首段或首处引用代表全部依据；可返回跳转前的原文页和滚动位置。目录、正文、标注独立滚动，收起目录或标注不改变阅读段落。
- 加载、空作品、空章节、无标注、服务失败有明确状态与重试；过期响应不得覆盖当前作品、章节或引用。失败不回退演示内容，网页不把浏览行为写为 AI 分析进度。
- 沿用现有随机独立 PostgreSQL 测试库进行写入造数及清理；共享开发库仅做真实规模的读取验收。本期不复制整库。将来涉及修改、删除的真实内容联调，可复制数据库并启动隔离服务。
- 验收：生产构建由 `/ui/` 加载；作品/目录/正文真实分页、跨章多引用、返回位置、切换请求竞态与失败重试可用；真实 PostgreSQL 测试验证目录和引用的作品隔离，前端类型检查、构建、行为测试通过。不影响现有 HTTP/MCP 入口。

## 0.1 正式实现第二期

- 新增正式标签库与独立标注库，沿用现有浅色界面，继续以浏览为主。创建、修订、撤回和删除不属于本期；分类浏览增量见 Spec 17。
- 标签库分页搜索共享标签的名称、定义、别名，支持精确命名空间筛选；选中后显示完整定义与别名、跨可见作品的关联标注。未使用标签仍可查看，未关联有效标注不能表述为标签不存在。
- 标注库默认跨全部可见作品浏览有效标注，可按作品、作品内章节、标签、有效/已撤回/全部状态以及说明文字的字面子串过滤；所有筛选在服务端执行，并绑定分页游标。屏蔽作品不进入全库结果，显式选择屏蔽作品返回明确错误。
- 新增 HTTP 只读 `POST /assets/annotations/browse` 复用资产摘要、关联和游标规则；不增加默认 MCP 工具。标签目录继续使用现有接口，`POST /assets/annotations/detail` 在同一快照内返回完整说明、标签及所有引用的分部、章节、起止段号，避免逐处下载正文解析位置。列表显示作品及第一处引用的分部/章节身份，详情完整展示全部引用并逐处读取原文。
- 从资产页打开引用，阅读页显示相应标注、正确作品/章节和完整引用页；保留明确的返回入口。返回时保留资产页筛选、页码、选中项和两栏滚动位置。通过主导航进入阅读不携带无关的返回来源；刷新页面保留作品/章节，资产页筛选和返回上下文仅在当前页面会话保留。
- 验收：真实接口跨作品筛选、字面搜索、撤回状态、隐藏作品排除、分页身份校验；共享标签与同名章节区分；浏览器标签→标注→引用→返回流程、空结果与失败重试、第一期阅读回归通过。写入造数仍使用随机独立 PostgreSQL 测试库。

## 作品认识与连续阅读增量

按 [Spec 18](18-连续阅读与叙述选择.md) 增加正式作品认识入口，作品页可直接查看本作品 kind=comparison 标注；独立标注库支持全部、具体观察、作品认识的用途筛选。列表显示标题、用途和适用范围，详情展示 note 及各引用 role_note。

默认引用动作打开 references.reading_range，另提供精确 evidence_range 定位，均保持现有完整自然段分页与返回列表规则。选中标注本身不移动正文。页边覆盖仍以证据范围为准，不把额外阅读上下文全部显示成被分析证据。作品认识不是文学评分或全书完成认证。

## 0.2 连续阅读与页边标注

- 日常入口以顺着小说阅读为主：打开作品/章节显示目录，默认关闭分析栏；目录、分析栏独立展开/收起。当前作品阅读会话中保留目录开合状态，正文保持有限行宽。资产页引用入口仍默认打开对应分析。
- 正文不整段铺色。有有效标注的段落显示页边按钮及准确的关联标注数量；同一标注的重叠引用只计一次。没有标记的段落保持清爽。计数来自服务对本页完整范围的查询，不根据候选列表的 12 条推算。
- 点击页边按钮保持正文位置并展开分析；仅一条关联时直接显示详情，多条时列出该段关联候选并支持翻页。选择分析不移动正文，显式点击引用才定位。所选分析在当前章节的依据以细页边范围线表示，并说明完整起止段号及跨页状态；不把说明中的关键词猜成字符级标注。
- 收起分析或退出详情清除选中范围强调；若已从正文跳去另一引用，收起分析返回跳转前的阅读页和位置。普通章节翻页/切章清除过时段落选择；引用范围内翻页保留对应分析和依据范围提示；手动切章关闭分析栏，但不重开已收起的目录。
- 页边关联使用 `POST /assets/annotations/coverage`，输入同章 SourceRange，最多 200 个连续段落，返回每段有效标注的去重计数；失败明确提示并可重试，不把失败伪装成无标注。不新增默认 MCP 工具，不修改任何分析资产。
- 验收包含超过 12 条关联、交叠引用去重、撤回排除、无标注段落、跨作品拒绝、默认侧栏状态、点击标记不跳文、长范围页边显示、收起两栏保持段落位置、资产页进入与返回不回归。

## 1. 已确认目标与边界

WebUI 面向用户，展示以原文为依据的分析结构。用户可查看和纠正 AI 已保存的标注，创建自己的标签和分析标注，也可以删除整部作品。用户不必介入，AI 原有准备流程继续自动执行。

外部 AI 负责导入、分析及创作；网页不接管 AI 执行，不增加聊天、模型调度、自动唤醒或逐条人工审批。后端继续提供同一套原文、资产、索引和进度规则。网页调用 HTTP 业务入口，不向普通用户暴露 MCP 维护工具列表。

用户操作的是既有 Annotation / Tag 资产；有效资产按 Spec 13 自动进入线索索引。人工作业不推进 Coverage，不把“用户浏览过”计作“AI 已处理”。当前无账号系统，“用户可修改”指现有本机实例中的操作能力，不承诺账号、角色或远程多人鉴权。

## 2. 首版页面提案

| 页面 | 主要任务 | 操作与信息 |
| --- | --- | --- |
| 作品库 | 选择和管理作品 | 名称、分部/章节入口、阅读处理与检索就绪分别显示；作品管理提供屏蔽、恢复、删除 |

| 标注库 | 跨作品浏览分析观察 | 作品/章节/标签/状态筛选、说明文字搜索、完整详情及全部原文引用；进入阅读修订后返回 |
| 分类标签浏览 | 按写法入口发现原文 | 全库／多作品范围、六类／全部／未分类、标签多选、any/all 匹配、标注各处引用回读 |

阅读与标注以连续阅读和按需查看分析为中心，也承载可选的核验与修订；标签库与标注库提供独立全库浏览入口，共用已有标签维护及标注编辑能力，不增加另一套资产规则。实体和关系不作为首版独立页面，作品认识按 Spec 18 提供独立入口；已有资产不得因网页修订而丢失，包含多处引用的标注必须完整呈现。

### 2.1 标签库与标注库的当前样稿设计

两页沿用现有 PC 视觉样式，模式为 Operate / Read：左侧列表负责选择，右侧详情负责理解和进入原文。主导航保留作品库、阅读与标注、标签库、标注库；当前阅读工作区可以继续直接访问。

- 标签库：搜索名称、完整名称、定义与别名，并按标签分组过滤。选中后显示完整定义、别名、共享属性及维护入口；下方按标注列出使用位置，支持作品与标注状态过滤。标签不直接挂接某个原文位置，引用入口始终来自关联标注。未使用标签仍展示定义并允许维护。
- 标注库：按作品、章节、单个标签、有效/已撤回/全部状态筛选，文字搜索仅匹配说明，不冒充语义召回。列表显示作品、位置摘要、说明摘要、标签和撤回状态；详情完整展示说明、标签与全部引用，不把每条结果都展开为阅读器。
- 每处引用分别显示作品、章节、段落范围及原文预览；可展开完整引用并进入阅读。点击后选中对应标注、切到正确章节、高亮所选引用。多引用保持原始顺序，不合并为第一处引用。
- 从资产页进入阅读，保留明确的返回入口；返回恢复查询、筛选、选中项和两栏滚动位置。保存或撤回后返回以现有数据重算结果，不恢复过时的结果对象。主导航和从作品库进入阅读不携带无关返回来源。
- 既有单处范围编辑扩展为编辑当前引用：说明与标签属于整条标注，当前章端点只修改选中的引用，其余引用完整展示并保留。新增/移除引用及跨章节选择新范围仍待后续设计，不伪装成本轮已有能力。
- 空库、筛选无匹配、标签未关联标注分别解释。删除作品后相关标注和原文入口消失，共享标签仍可浏览；失效作品筛选恢复到全部作品。

本轮全部为内存样例。现有 `annotation_list` 要求指定单作品，跨作品聚合浏览及标签使用位置查询的生产 HTTP 契约仍需设计，不能把本页演示当作接口已实现。

## 3. 阅读工作区与信息层级

### 观看与探索优先的视觉提案

用户明确页面优先服务于观看、理解 AI 分析成果，人工修订为低频能力；视觉冲击、空间层次与交互动态为本轮设计重点。新增 `docs/prototypes/webui/experience/` 独立样稿，保留此前原型作为对照。首屏由作品名称、实际原文与已有标注共同构成；鼠标悬停或选择标注联动引用，进入阅读时将原文由透视展示平展为可滚动阅读面。支持切换两部演示作品、切换标注及返回概览。

样稿只使用既有虚构原文、标注及标签，连接线仅表示真实引用，不推断人物关系，不增加网页 AI 执行器或修改后端。过渡须连续且可中断；减少动态效果时直接呈现最终状态。视觉设计允许重新构图和配色，不受既有浅绿及双封面列表约束。仅验收 PC 的实际画面、鼠标联动、引用一致性、作品切换和减少动态效果分支；不表示整个 WebUI 已重做。

探索与阅读分工：探索状态保留已确认的大书名、空间展示和作品切换；进入阅读后，大书名收为顶部紧凑栏，背景装饰、引用连接线及底部作品切换栏退场。正文使用 19px 中文字号、约 32–36 字行宽，当前章连续滚动；右侧标注可收起、重新展开。切换标注栏时保持正在阅读的段落位置；返回探索保留所选标注，再次进入阅读恢复该作品阅读位置，显式“在原文中查看”才重新定位引用。阅读中选择标注以点击为准，避免悬停造成正文跳动。本轮不增加章节切换或全库浏览。

### 真实数据只读接入

用户要求用共享库的真实规模验证样稿。`experience/` 默认改为实时读取服务；原两部虚构样例保留在 `demo.html`。通过本机预览服务转发固定的 `/library/browse` 与 `/source/read` 只读接口，页面不持有数据库凭据，不开放通用代理或写入端点。本次不增加 CRUD；后续写入测试允许使用数据库副本及临时服务。

作品按服务游标分页加载；章节只读取目录元数据，正文每页最多 40 段。标注列表每页 12 条，显示真实标签与预览，选中后单独读取完整说明及有序的全部引用；多引用逐处回读，跨章引用显示实际归属。支持整部标注及当前原文页引用相交的标注范围，正文续页不丢弃未显示段落，不把当前页数量称为全库数量。作品、章节与引用切换中拒绝过期响应，加载与失败必须显式呈现；失败不回退成虚构内容。原文、长标注在独立阅读区域滚动，不用截断隐藏全文。界面以真实作品名排版，不按四字书名拆分。

本期仅面向 PC 浏览器，以鼠标点击、滚轮及拖选完成阅读操作；不开发专门的键盘翻页，不设计或验收手机端。桌面布局提案为“分部目录 | 原文 | 标注面板”。正文保持可阅读宽度，目录可收起以扩大阅读空间；按桌面窗口宽度调整列宽。中文正文建议约 28–36 字一行、适当行距，属于阅读参数；当前视觉样稿参数见下文，不视为最终视觉已获确认。

正式阅读默认顺着小说读，遇到页边标记再展开分析，正文始终是主体。作品与章节栏保留在工作区上方，目录、正文、标注区域分别滚动；目录和分析栏独立收起。点击标记、选择标注和侧栏滚动不移动正文，显式点击引用才定位；所选依据用细页边线表示，不整段铺色。以下修订交互保留为后续写操作的设计：编辑时收起目录并适度扩大右栏，退出后恢复目录设置。保存/取消固定在侧栏底部；说明、范围、已选标签优先显示，引用预览、候选标签和共享词表维护按需展开。作品删除移入作品管理入口。只有实际改动才触发放弃草稿确认。

初次打开作品进入可读章节。当前章节、原文位置和标注引用联动：点击标注定位引用，点击段旁标注入口列出交叠标注。多条标注重叠时分别选择，不合并说明；不以不同颜色暗示分析质量。

原文保持只读。段落 UUID、检索分数和诊断默认隐藏，需要定位/诊断时展开。编辑期间显示人类可读的起止段落与引用预览。原文、说明、标签和操作反馈分别有明确区域。

长篇目录、正文、标注和搜索结果沿接口分页读取；不一次下载整部小说。章节显示“本页无标注”不能被误写为“本章无标注”，分页结束后才能宣称完整。

### 3.1 当前视觉样稿

#### 作品库独立视觉提案

作品库新增独立的 PC 高保真样稿 `docs/prototypes/webui/studio/`，用于评审新的视觉方向，尚不替换阅读、标签与标注页。采用中性浅色、墨黑文字和少量钴蓝操作色，以作品封面和中文排版为中心；不使用全页怀旧材质或独立气氛横幅。两部既有演示作品分别展示图形封面和无图文字封面，真实文字保持可选择。封面仅为样稿展示，不增加上传、生成或持久化封面的业务要求。

本轮只提供作品库：搜索与准备状态筛选、本页作品展开预览、准备说明。状态与原文来自既有虚构样例，不访问数据库；不新增导入入口或制造推荐、最近阅读记录。验收包括 PC 宽屏及较窄窗口的完整构图、鼠标交互、无匹配与无图封面，以及无横向溢出。最终视觉仍由用户评审确定。

#### 既有阅读工作区样稿

阅读工作区采用暖白正文、浅绿灰侧栏和深绿色强调。强调色用于当前导航、引用范围和主要动作，不区分分析质量。保留三栏、独立滚动、编辑时收起目录和固定保存操作栏。

| 角色 | 当前样稿参数 |
| --- | --- |
| 小说正文 | Noto Serif SC，19px / 1.9，常规字重；段落上下各 6px，不额外缩进 |
| 章节标题 | 同正文衬线字体，24px / 1.5，600 字重 |
| 界面与分析说明 | Noto Sans SC；侧栏标题 18px / 1.5，说明及编辑文本 16px；常用控件 14px |

| 原文行长 | 段落连同定位栏最大 688px，正文约 32 个汉字；窄 PC 允许较短行，不缩小正文字号 |
| 主要颜色 | 正文底色 #fffef9，侧栏 #f8faf5，文字 #29352f，辅助文字 #58645c，强调色 #285943，范围底色 #e0eae2 |

## 4. 用户操作流程

### 4.1 查看与修订标注

1. 在原文或标注列表选择标注，读取当前完整详情与版本。
2. 展示所有引用、说明、标签；范围可以位于同一作品的不同章节。每处引用单独回读，禁止截掉隐藏引用后保存。
3. 点击修订，在当前面板编辑说明、标签和引用；取消保留原数据。
4. 保存采用请求键、expected_version 与完整字段替换。未在网页编辑的 entity_ids 省略以保留既有关联，不默认清空。
5. 仅收到提交成功后更新界面，并提示“标注已保存；检索线索同步中”。通过当前状态检查确认同步，不用定时器假定成功。

版本冲突保留本地草稿，展示最新版本并允许用户重新比较后提交；不得自动覆盖。超时结果未知时查询回执或原键原输入重试，不能直接换键重复创建。校验/保存失败保留草稿、定位错误。导航离开有改动的编辑面板时提供继续编辑或放弃。

### 4.2 新建标注与原文范围

用户选择原文后发起“新建标注”。现有契约是完整自然段：选中段内几字也扩展为对应完整段落，保存前展示真实引用范围，不承诺字符级标注。提供起止段落选择作为拖选的替代。

每条标注至少一处引用，单处引用不得跨章节；可以追加同一作品的其他引用，保留输入顺序。编辑范围不改变原文。说明和标签均可选，空白说明转换为无说明，不能强制文学模板或字数配额。

本轮样稿支持同作品跨章多引用展示、分别跳转和编辑当前引用时保留其他引用。引用新增/移除、跨章选择新范围、分页选择和长篇目录属于生产实现前须补齐的交互，不因线框简化而取消现有数据能力。

### 4.3 标签选择、创建与修订

先查询已有标签，按名称、定义及别名判断是否复用；新建需要命名空间、名称、定义，可附别名。标签与标注是独立资产：标签创建成功后即保存，取消标注不删除已创建标签；界面须说明这一点。

同命名空间同名称冲突时展示已有标签供选择，不能自动覆盖定义。修订标签名称、定义、别名沿用版本约束，命名空间不可改。标签是全库共享：保存前明确提示对所有关联作品生效，不把全局修改显示为当前标注局部修改。不伪造尚无接口支持的精确引用总数。

用户只想改变当前标注分类时，修改标签关联即可。不得把移除关联误作删除全库标签。

### 4.4 撤回与恢复

不合适的标注可撤回；保留记录，退出默认检索。原文仍可召回，不承诺“撤回标注后再也不会检索到这些段落”。撤回项通过筛选查看并可恢复；恢复后索引状态按实际检查显示。不提供单条标注物理删除或历史版本一键还原。

### 4.5 删除作品

从作品管理打开独立确认框，展示作品名称及删除范围：原文、上传字节、作品内分析资产、任务、索引及有关回执。全库共享标签、外部 TXT、备份和其他作品保留。明确不可撤销；输入完整作品名称后才能提交，确认是 UI 设计，不宣称现有 DELETE API 自带名称校验。

收到 204 后返回作品库并清除该作品在界面的缓存。WORK_BUSY 提示当前数据操作占用，稍后重试，不强制终止索引进程。网络结果未知时可重试同一删除目标或重新查询；失败不能先把作品从界面永久移走。

## 5. 检索、状态与异常

- 默认浏览复用 library_browse 和资产浏览接口。按作品、分类和标签筛选标注，点击各处引用进入原文，返回保留选择；不提供旧自然语言统一召回页。
- compact 用于浏览，full 提供完整维护字段；返回列表保留筛选、页位置和选中项，改变范围或筛选从第一页重新查询。
- 摘要与预览不计作充分阅读；原文范围按实际返回段落表达，不自动记录浏览即理解。
- 无匹配、请求失败和游标失效分别显示。旧搜索快照和模型就绪状态不再出现在默认浏览页面。
- 阅读进度和准备完成分别表达，任务状态不是外部 AI 心跳；完成不代表文学质量。服务断开显示连接失败及重试，未来写入界面须保留正在编辑的草稿。
- 空库说明如何由外部 AI 准备作品，不显示目前不能兑现的“网页一键分析”。读取中、空标注、保存中、失败、版本冲突、撤回、删除占用均有对应反馈。
