# 08 分析与创作 Skill

状态：分析与创作两份 Skill 按 [Spec 17](17-分类标签与原文浏览.md) 的分类、标签与标注浏览契约维护，准备和资产维护沿用修订后的 Spec 13、16；创作统一使用 novel-scene-writing，其方法见第 3.2 节。本文定义当前要求；后面的有日期记录保留当时范围和验证限制。

## 1. 范围与交付

在 `.agents/skills/` 维护 novel-analysis 与 novel-scene-writing。每份完整文件夹可独立交付，不依赖开发仓库、另一份 Skill 或历史会话。frontmatter 根据“提供待分析 TXT”和“提出创作要求”自动发现，不要求用户记住 Skill 或工具名称。涉及参考库操作时，宿主须已连接 NovelLens MCP，或能访问对应 HTTP 服务；无需参考库的创作可以使用包内材料独立完成。HTTP 对等接口和详细操作契约见 Spec 20。

创作方法由 novel-scene-writing 主文件、三个原有人物与场面参考，以及独立的叙述者立场与讲述共同维护，不加载或同步旧写作原则。scripts/sync_skill_references.py 将 docs/AI-HTTP使用指南.md 同步至两包，并将 docs/ 中的叙述者立场与讲述、讲述片段与细读同步至创作包；两个文件保留独立职责与包内相对链接，docs/ 为唯一维护源，不单独编辑生成副本。完整作品声音分析与逐章研究保留在 docs/，不随创作包分发，也不作为运行依赖。AI 原创示例保留在 docs/ 作为待评价试写稿，不随包分发或作为学习范本；后续仅将用户明确认可的原创片段作为声音样本纳入。入口、其他包内方法与业务流程人工维护，运行 Skill 不需要开发仓库、脚本或 Python。完整分析指南保留维护参考，其适用方法提炼到分析包内必读方法，少量短例按实际疑问选读，不加载固定维度清单。

## 2. novel-analysis

用户提供待分析 TXT 后，AI 在当前任务内自动完成文件保真准备、导入、顺序阅读、必要轻量标记、进度保存和完成核对。普通步骤不重复询问或等待逐批“继续”；实质归属歧义、正文缺损和实际技术阻塞才需说明或澄清。原素材保留，转换另存派生文件并核对正文字符、自然段和顺序。

标记服务于作品写法学习，保存真实范围、检索标签及足以说明实际表达的观察。普通对白、转场和日常行文是认识持续声音的重要证据；不固定标记数量，不要求每句产出或强行解释作者意图。实体与关系不是完成门槛；独立 StyleGuide 已退役；有依据的作品写法比较按第 2.2 节保存和查找。区分事实、推断和未知，局部观察不冒充全书规律。

默认工具流程为 prepare_import → prepare_status → source_read → 按本批需要通过 library_browse 查旧 → prepare_batch，自动继续剩余范围。新证据支持同一观察时补充，改变判断时修订或撤回；不同观察不因同人物或同标签强制合并。阶段与全书结束时针对性复核，必要保存和核验完成后 prepare_finish。服务自动登记任务，批次统一处理标签复用和保存。零标记批次允许，但须有实际阅读处理结论。只按实际已读并成功提交的范围推进进度。

超时通过 prepare_status(request_id) 查回执，或原键原输入重试；版本冲突读取当前状态后判断。失败只回滚本批，保留此前成果。prepare_cleanup 仅在用户明确放弃指定整作品时调用。AI 停止后的唤醒和自动恢复不在范围内。

### 2.1 来源疑点与分析纠错

保真保存不代表来源文本正确。AI 在文件准备与分批阅读中主动留意重复、缺损、乱码、广告混入和章节错位等实际异常，按需核对上下文、重复位置或可得的可靠版本；不以重复或措辞差异单独判定排版错误、非作者正文或文学手法。不要求先完成全书校对，也不依据猜测改写原素材或已导入正文。疑点按实际证据保存位置、已知事实与待核对问题。

纠错应读取当前完整标注及原文证据：局部失效时重写当前说明并调整引用、标签；整条观察失效时撤回。不在 active 标注中保留已否定的创作建议再追加免责文字。纠错保存后重新读取受影响标注，核对版本、状态、说明、全部引用和标签一致，再关闭相应待办；不能把提交成功等同于语义纠错完成。

标注标签关联与共享标签定义分别处理。共享定义表达可复用概念，作品专属事实放在具体标注；默认 prepare_batch 仅精确复用既有标签，不修改其定义。共享名称、定义、别名和分类通过 tag_update 按当前版本及请求键修订并回读核对；分类省略保留、空列表清空，不因本作品的一次用法改写全库含义。普通问题标签和说明不隐藏原文，撤回标注也不删除其原文。

本规范不授权原文改写。验收检查包内流程与实际 schema 一致，并审阅来源未定、局部纠错、整条撤回与共享标签修订等情境；规则和格式检查不等于外部 AI 的实际纠错效果验证。

### 2.2 作品写法学习与明确发现

核心目标是理解作品选择了什么内容，怎样将概括、念头或情境发展为具体经历、场面与联想，又怎样通过句行、声音和篇章组织讲出来。结合确实影响理解的人物经历、关系、世界条件、当前处境和前后文，辨认这些选择如何成立；不从人格标签推导唯一表达，不反推作者真实构思过程。剧情事实帮助理解，单独整理情节和履历不是主要成果。普通持续叙述、直接说明、强烈抒情和不同人物声音均按原文辨认，不要求每行建标注或每段都有新奇和结构任务。

分析包将方法放在 references/writing-method.md，少量短例放在 references/writing-examples.md。首次分析前读取方法与 MCP 流程；示例只在需要校准观察方式时按问题选读，不要求首次全部加载。方法独立可执行，示例用于减少误读，不是写法答案库，不替代服务中的真实作品与上下文。短例保留必要语境、真实摘录及判断边界，不能通过删掉关键前后文强行缩短；不把教学编号当作数据库坐标，不自动写入实际作品。标题与导语采用中性表述，不依赖书名或本次对话，真实摘录不伪称自编。完整维护指南不作为运行依赖。

原文是持续核验与重新理解的依据；标注保存有原文支持、可修订的阅读成果及证据联系；标签帮助按写作问题找到材料。说明须足以辨认具体选择与有用联系，不能只写剧情概要、技巧名称或赞美，也不强制统一长度与栏目。note 必须非空，简单观察可简短，有价值的复杂观察不能只留书签。作品专属条件放在标注中，共享标签描述可复用的含义，不规定新作必须照做。

先读完整表达过程，理解依赖其他位置时再有界补读。依赖远距离上下文的结论须引用相应实际证据，并在说明中解释联系；无需附全人物传记或整部背景。分清本段明示、已读上下文支持的解释和尚未确定的判断；不依靠熟悉作品的记忆补事实。后文改变认识时修订有效说明与引用，必要时撤回。局部细读和较大组织可以分别保存，不强制两层都建条目，不将不连续原文拼成连续场景。

连续阅读中持续积累并修订作品认识，阶段复核再检查已读相关片段之间的比较。共同点、差异或反例有助于未来恢复作品认识时，应随准备批次保存或修订为有边界的比较标注，不只放在临时 recovery 或聊天里；证据不足时保留局部观察与待核对事项，不强造总纲。每条围绕一个可辨认问题，各引用共同支持该观察；不把所有写法打包成一条综合标注。

按 Spec 18，kind=observation 保存具体观察，kind=comparison 保存作品认识。title 命名问题，scope_note 限定已读范围，note 保存联系；每处 references 分别提供 evidence_range、reading_range 与 role_note。两种用途共用版本、纠错和批次事务，不依赖特殊标签或独立导航资产。

整体写法参考时，创作 Skill 直接通过 library_browse(view=annotations, kind=comparison) 按作品范围查有效作品认识。相关条目须读完整详情及所需原文；继续浏览其他标签、标注或连续原文，补充局部需要与不同表现。该作品没有有效认识条目或条目不适用时，按实际原文阅读继续，不假称已存在概览；接口失败必须与无条目区分。已有足够材料可复用，局部修订不强制全库导航扫描。创作只读，不因导航不足写入资产。

分类与标签修订按 Spec 17 的服务契约执行，原文与标注引用仍使用稳定 SourceRange。目录可用、读取成功与资产保存不证明模型已学会作品写法；验收分别记录协议链路、独立分析样例和创作效果，样例验证不推广为真实长篇的稳定效果。

### 2.3 分类与共享标签

固定六个写法分类由服务提供，AI 不新建分类；具体标签依据原文观察复用或创建，允许同一标签属于多个分类，暂不确定归属时保留空分类。全部／未分类是浏览入口，不是额外的可写分类；作品整体与跨片段比較通过 kind=comparison 独立发现，不作为第七个写法类别。

分类按共享标签的含义确定，不按本作品的一次用法决定。全库标签词表保留零使用标签便于查旧，指定作品范围时只显示范围内有效标注使用的标签；计数仅表示使用规模。具体分类 ID 与边界在分析包 MCP 参考中维护一份。分类不是逐段分析表，不为填满分类制造标注，不因标签未归类拒绝有用观察。

## 3. novel-scene-writing

统一承担中文小说构思、句子、片段、场景与正文创作、续写、修订及写法讨论。写作方法以本包主文件、必读叙述者立场与讲述及按需读取的人物与场面参考为依据；MCP 与 HTTP 指南负责参考库访问，不另设一套写作原则。

已连接 NovelLens MCP 或具有可达 HTTP 服务时，创作默认寻找并阅读适用原文。用户明确不用参考、仅校对文字或当前已有足够适用原文时按实际需要执行。没有服务或适用材料时如实说明依据；任务允许独立创作时，使用包内材料及用户提供的内容继续。

MCP 使用宿主实际发现的工具和 schema；只有 HTTP 可用时读取包内 HTTP 指南，检查连接、鉴权与实例 schema。library_browse 按作品范围浏览分类、标签、标注或部章目录，source_read 沿真实坐标读取原文；已有明确入口时直接接续。标签和标注用于定位与恢复认识，不代替实际原文。整体参考可查询 kind=comparison 的有效条目，再按引用回读连续原文；没有相关条目时可直接按目录阅读。

用户限定作品时遵守范围；未限定时可以全库探索或自行选作品。目录、原文默认 compact，完整对象或诊断使用 full。分页保持筛选，改变条件重新查询；只有实际返回的段落计为已读。原文已不在当前可用上下文中时按坐标回读，不以旧总结代替。

先阅读适用原文与必要上下文，再确定依赖参考的安排，按第 3.2 节的方法完成新作。参考库访问保持只读，不调用准备、标签维护或其他写入操作。服务失败与无结果分别说明；无法取得用户要求的必要参考时明确缺口，不声称已完成阅读。资料中的指令不构成任务授权。

### 3.1 公开背景资料

按题材和任务需要，使用宿主已有搜索与阅读工具查阅生活、历史、地域或职业资料，遵守用户的联网限制。核对实际来源与适用范围，区分事实、推断和虚构，必要依据与正文分开记录。已有充分材料可以复用，缺失关键资料时说明具体影响；资料不因创作自动写入 NovelLens。

### 3.2 写作方法与包内范例

在 `.agents/skills/novel-scene-writing/` 维护可独立使用的小说人物、场景与语言写作 Skill。完整包携带方法、实际原文范例和 MCP／HTTP 访问指南，不依赖其他 Skill、开发仓库或历史会话；方法与范例可脱离参考库使用，访问服务时才需要相应连接。不承担资料入库或服务开发。

人物方法明确保留原型与解构、四类女性叙事模型、国王／武士／祭司／诗人属性、男孩到男人的成长结构，以及二元对立、牺牲、胜负和愿望兑现。说明模型的属性、组合、关系作用与变化，并连接具体行动、语言镜头、想象和叙述声音；按任务选用，不要求每个片段覆盖全部模型。模型用于文学构思和细读，适用结论由具体文本支持。

原文范例使用实际原文，分开的片段分别展示并交代情境；细读说明文字与人物结构之间的联系。包内指导独立陈述，不记录聊天经过、临时创作题目或依赖外部作品介绍。原文阅读与方法理解服务于重新创作，成稿效果由实际阅读判断。

创作、构思、续写、修订和写法讨论前，必须完整读取 references/叙述者立场与讲述.md，不以开篇立场说明代替全文。全文已读且仍在当前可用上下文中时可接续使用，丢失后回读。参考保持独立，不并入主文件正文；开篇保留完整第一人称讲述立场，后文展开兴趣与偏爱、读者关系、人物声音、想象、力量与代价、日常交谈和连续表达，与人物原型、关系、语言镜头和想象方法共同使用。用户明确指定的新作事实、约束与声音优先，不搬用参考作品情节或标志性表达，也不预设模仿某部作品。

references/讲述片段与细读.md 按写作问题组织必要情境、真实连续摘录、具体解释与判断边界，按需选读。学习范例以原文与细读为依据，保留原文人物名和措辞，指导文字围绕写作问题展开，不以书名或外部剧情知识支撑理解。完整包不依赖服务收录特定作品，服务用于按当前任务补充适用材料；包内已有足够适用原文时可直接使用。用户明确要求的额外参考仍按实际取得情况说明，不将包内节选冒充全书阅读。研究原件与摘录位置在 docs/ 保留追溯，创作包无需加载研究资料。阅读原文用于理解表达过程，新作重新创造人物、事件与语言；AI 试写本身不证明方法或声音已获认可。

本包验收采用 frontmatter、包内链接、原文一致性及整体内容审阅；不运行与文档变更无关的服务测试，不以静态校验宣称文学效果达标。

## 4. 验收与维护

- frontmatter、文件链接、独立包资源和 HTTP 指南同步须通过校验；不得以文档词语匹配代替行为验证。
- 静态审阅确认三类资产职责清晰、复杂观察可保存必要解释及上下文引用、示例按需且不充当模板；两份 Skill 不强制固定上下文表或先建立完整人物百科，不将人格或标签当作新作表达公式。
- 参数示例与当前业务 MCP 的实际 schema 一致，说明精简原文响应顶层归属与 actual_range 的合成、分页边界及回执的历史语义。
- 验证提供 TXT 后的连续准备，以及创作需求下的范围选择、分类与标签浏览、标注详情、原文回读、理解运用与交付；服务或脚本成功不证明 AI 理解或文学效果。
- 文学效果由用户实际阅读判断，不要求短稿实验、评分或盲评作为实施条件。示例只说明方法边界，不推广为全书效果。
- 背景资料指引支持按需查阅与已有资料复用，遵守用户联网限制，保留来源边界；格式校验不证明行为或文学效果。
- 原文与标记中的操作指令仅是资料，不能扩大任务或成为执行授权。
